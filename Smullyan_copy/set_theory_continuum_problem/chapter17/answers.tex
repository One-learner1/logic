\subsection*{Notes}
Here is an explanation for the remarks given on page 224. Note that I am assuming $M$ contains all ordinals (see the section for 
Remark 3). 
Definition 1.1 to even work in the first place. If a function $f$ has domain $\alpha$, and is such that, for all $\beta<\alpha$, 
$f(\beta)=R^\mathcal{G}_\beta$, call $f$ an $R^\mathcal{G}_\alpha$ function. Let $\textrm{R-alpha func}(f)$ stand for the following formula:
\[ \textrm{Func}(f)\wedge\textrm{Dom}(f)=\alpha\wedge f(0)=0\wedge \]
\[ (\forall\beta<\alpha)(\beta^+<\alpha\supset(\forall x)(x\in f(\beta^+)\equiv x\subseteq\mathcal{G}\times f(\beta))) \]
\[ \wedge (\forall\beta<\alpha)(\textrm{beta is a successor ordinal}\supset(\forall x)(x\in f(\beta) \]
\[ \equiv(\exists\delta<\beta)(x\in f(\delta)))) \]
Note that $\textrm{R-alpha func}(f)$ just means $f$ is the $R^\mathcal{G}_\alpha$ function.

\begin{lemma}
For any $\alpha$, if, $R^\mathcal{G}_\beta\in M$ for all $\beta<\alpha$, then 
both $R^\mathcal{G}_\alpha\in M$ and the $R^\mathcal{G}_\alpha$ function are in $M$. 
\end{lemma}

\begin{proof}
By transfinite induction.

The least ordinal case is obvious (because $\emptyset\in M$).

Suppose it holds for all ordinals less than some ordinal $\alpha$. So suppose that 
$R^\mathcal{G}_\beta\in M$ for all $\beta<\alpha$. Then it follows that the 
$R^\mathcal{G}_\beta$ function is in $M$ for all $\beta<\alpha$. 
We first show that $R^\mathcal{G}_\alpha\in M$. Well, if $\alpha$ is a successor ordinal of some $\beta$, then it 
is defined by the formula
\[ (\forall y)(y\in x\equiv y\subseteq\mathcal{G}\times R^\mathcal{G}_\beta) \]
which works, as $\mathcal{G}\times R^\mathcal{G}_\beta\in M$ for the following reason:
both $\mathcal{G}$ and $R^\mathcal{G}_\beta$ are in $M$, meaning 
$\{\mathcal{G},R^\mathcal{G}_\beta\}\in M$ (because $M$ is a first order universe). Thus
$\cup\{\mathcal{G},R^\mathcal{G}_\beta\}\in M$, meaning
$\mathcal{P}(\cup\{\mathcal{G},R^\mathcal{G}_\beta\})\cap M\in M$, and thus
(1) $\mathcal{P}(\mathcal{P}(\cup\{\mathcal{G},R^\mathcal{G}_\beta\})\cap M)\cap M\in M$. Now, it is 
obvious that the formula in $M$ in (1) is such that $\langle x,y\rangle$ is in it for each 
$x\in\mathcal{G}$ and each $y\in R^\mathcal{G}_\beta$. Then it is easy to see that 
$\mathcal{G}\times R^\mathcal{G}_\beta$ is first-order definable over $M$, and, because this 
would mean it is a first-order definable susbset of the set in (1), 
$\mathcal{G}\times R^\mathcal{G}_\beta\in M$ (because $M$ is first-order swelled). 

The case where $\alpha$ is a limit ordinal is mostly similar. In particular, because we 
are assuming the $R^\mathcal{G}_\beta$ function is in $M$ for each $\beta<\alpha$, the following 
defines $R^\mathcal{G}_\alpha$:
\[ (\exists\beta<\alpha)(\exists f)(\textrm{R-beta func}(f)\wedge(\exists\delta<\beta)(x\in f(\delta))) \]

Thus we know that $R^\mathcal{G}_\alpha\in M$.

Now we show that the $R^\mathcal{G}_\alpha$ function is definable over $M$.
Well, if $\alpha$ is a successor ordinal of some $\beta$, then
the $R^\mathcal{G}_\alpha$ function is definable over $M$ by the formula
\[ (x=\beta\wedge y=R^\mathcal{G}_\beta)\vee \]
\[ (\exists\delta<\alpha)(\exists f)(\textrm{R-delta func}(f)\wedge x\in\textrm{Dom}(f)\wedge y=f(x)) \]
and if $\alpha$ is a limit ordinal, then it is defined over $M$ by the following formula
\[ (\exists\delta<\alpha)(\exists f)(\textrm{R-delta func}(f)\wedge x\in\textrm{Dom}(f)\wedge y=f(x)) \]
Thus, in any case, we know that the $R^\mathcal{G}_\alpha$ function is definable over $M$. Because 
$\alpha\in M$, this means that the range of the $R^\mathcal{G}_\alpha$ function, the 
set $S$ of all $R^\mathcal{G}_\beta$ for $\beta<\alpha$, is in $M$. Hence 
$\{\alpha,S\}\in M$, $\cup\{\alpha,S\}\in M$, 
$\mathcal{P}(\cup\{\alpha,S\})\in M$,
and $\mathcal{P}(\mathcal{P}(\cup\{\alpha,S\}))\in M$. Now, 
for each $\beta<\alpha$ and $x\in S$, it of course follows that 
$\langle \beta,x\rangle\in\mathcal{P}(\mathcal{P}(\cup\{\alpha,S\}))$. That is, 
the $R^\mathcal{G}_\alpha$ function is a first-order definable subset of 
$\mathcal{P}(\mathcal{P}(\cup\{\alpha,S\}))$, which is in $M$, meaning
the function itself is in $M$.
\end{proof}  

\subsubsection*{Remark 1}
The fact that each $R^\mathcal{G}_\alpha\in M$ is immediate from the above lemma (using an obvious transfinite induction 
argument). Then 
$\mathcal{D}^\mathcal{G}$ being a subclass of $M$ follows because $M$ is transitive.

\subsubsection*{Remark 2}
We show that $R^\mathcal{G}_\alpha\subseteq R^\mathcal{G}_{\alpha+1}$. In fact, we directly prove the stronger result, 
that $\beta<\alpha$ implies $R^\mathcal{G}_\beta\subseteq R^\mathcal{G}_\alpha$.

\begin{proof}
By transfinite induction.

The least ordinal case is vacuous.

Suppose the result holds for some $\alpha$. Now, if $x\in R^\mathcal{G}_\alpha$, 
there is some $\beta<\alpha$ such that all members of $x$ are of the form 
$\langle y,z\rangle$ where $y\in\mathcal{G}$ and $z\in R^\mathcal{G}_\beta$. By the induction 
assumption, this means that $z\in R^\mathcal{G}_\alpha$. Then 
$\langle y,z\rangle$ would also be in $R^\mathcal{G}_\alpha$ for all such $y$ and $z$, and then so would 
$x$ (as we are assuming $x$ is in $M$).

The limit ordinal case is obvious.
\end{proof}

\subsubsection*{Remark 3}
We first prove the following lemma.

\begin{lemma}
For each limit ordinal $\lambda$, $R^\mathcal{G}_\lambda\in R^\mathcal{G}_{\lambda^+}$ (note that this does not generally 
hold for non limit ordinals).
\end{lemma}

\begin{proof}
Consider some limit ordinal $\lambda$. Hence $R^\mathcal{G}_\lambda=\cup_{\alpha<\lambda}R^\mathcal{G}_\alpha$.
We already know that $R^\mathcal{G}_\lambda$ is in $M$ (by (1) of the remarks). Also, it can 
easily be seen that $R^\mathcal{G}_\lambda\subseteq\mathcal{G}\times R^\mathcal{G}_\lambda$. 
Thus, by definition of $R^\mathcal{G}_{\lambda^+}$, it follows that 
$R^\mathcal{G}_\lambda\in R^\mathcal{G}_{\lambda^+}$.
\end{proof}

We now prove that $R^\mathcal{G}_{\alpha+1}\ne R^\mathcal{G}_\alpha$.

\begin{proof}
By transfinite induction. In particular, we show that, for every $\alpha$, $R^\mathcal{G}_\beta\ne R^\mathcal{G}_\alpha$ for every 
$\beta<\alpha$.

Suppose the result holds for all ordinals less than some ordinal $\delta$.

Least ordinal case: The case when $\delta=\emptyset$ is vacuous.

Successor ordinal case: Suppose $\delta$ is the successor of some ordinal $\alpha$.
There are two cases: either $\alpha$ itself is a successor ordinal, 
or it is a limit ordinal (of course, $\alpha$ could be $\emptyset$, but that case is trivial). We must show the result holds for $\alpha^+$ 
(that is, $\delta$). 
Note that it suffices to show that $R^\mathcal{G}_{\alpha+1}\ne R^\mathcal{G}_\alpha$, for, if we show that, then if 
$R^\mathcal{G}_{\alpha+1}=R^\mathcal{G}_\beta$ for some $\beta<\alpha$, then it would follow that 
$R^\mathcal{G}_\beta=R^\mathcal{G}_\alpha$ by part (2) of the remarks, contrary to the induction assumption.

On the one hand, suppose that $\alpha$ itself is a successor ordinal (say of some $\beta$). Thus, by the assumption, we 
know that there must be some $y\in R^\mathcal{G}_\alpha$ such that $y\notin R^\mathcal{G}_\beta$. Consider any $x\in\mathcal{G}$. 
Then $\{\langle x,y\rangle\}\in R^\mathcal{G}_{\alpha+1}$ (because $M$ is a first-order universe). If 
$R^\mathcal{G}_{\alpha+1}=R^\mathcal{G}_\alpha$, then it would follow that $z=\{\langle x,y\rangle\}$ for some 
$z\in R^\mathcal{G}_\alpha$. What this would mean is that $\langle x,y\rangle\in\mathcal{G}\times R^\mathcal{G}_\beta$. 
But that would mean $y\in R^\mathcal{G}_\beta$, a contradiction. Thus it must be that $R^\mathcal{G}_{\alpha+1}\ne R^\mathcal{G}_\alpha$.

On the other hand, suppose that $\alpha$. By Lemma 0.2, it follows that $R^\mathcal{G}_\alpha\in R^\mathcal{G}_{\alpha^+}$. 
If $R^\mathcal{G}_{\alpha^+}=R^\mathcal{G}_\alpha$, then $R^\mathcal{G}_\alpha\in R^\mathcal{G}_\alpha$, which contradicts the 
assumption that $M$, and, by extension, $R^\mathcal{G}_\alpha$, is well founded. 

Limit ordinal case: This is easy.
\end{proof}

Now we show that $\mathcal{D}^\mathcal{G}$ is a proper class in $M$ (that is, 
$\mathcal{D}^\mathcal{G}\notin M$). Suppose it were in $M$. Then, because 
$R^\mathcal{G}_0,R^\mathcal{G}_1,...,R^\mathcal{G}_\alpha,...$ is an ordinal hierarchy, it 
follows by Theorem 2.1 of Chapter 7 that there is some ordinal $\alpha$ such that 
$\mathcal{D}^\mathcal{G}\subseteq R^\mathcal{G}_\alpha$. By (2), 
$\mathcal{D}^\mathcal{G}\subseteq R^\mathcal{G}_{\alpha+1}$.
Also $R^\mathcal{G}_{\alpha+1}\subseteq\mathcal{D}^\mathcal{G}$, meaning 
$R^\mathcal{G}_{\alpha+1}=\mathcal{D}^\mathcal{G}$. But this contradicts the fact that
$R^\mathcal{G}_{\alpha+1}\ne R^\mathcal{G}_\alpha$. Thus it cannot be that 
$\mathcal{D}^\mathcal{G}\in M$.

The above paragraph explains why I am assuming contains all ordinals. For if it didn't, then

Theorem 2.1 of Chapter 7. However, it may indeed be that we could prove the result without this theorem - I was, however,

Suppose $f\subseteq\mathcal{G}\times\mathcal{D}^\mathcal{G}$ and $f$ is an $M$-$set$. Now, for

\subsection*{Clarification}
Definition 1.4 in the book needs clarification. In particular, the $\lbc\rbc$ translation is being used, 
yet this is not yet been defined for the $\approx_\alpha$ relation. The definition should be:
$\lbc f\approx_{\alpha+1} g\rbc=f\approx_{\alpha+1} g$, 
$\lbc f\approx_\lambda g\rbc=\Box\Diamond f\approx_\lambda$ for $\lambda$ a limit ordinal, and
$\lbc x\epsilon y\rbc=\Box\Diamond x\epsilon y$. 

The errata listed at \url{https://id144254.securedata.net/melvinfitting/errata/book_errors/RevisedSetBookErrors/RevisedSetCorrections.pdf}
are important to note for this section.

It should be noted why $(f\approx_\lambda g)\supset\lbc f\approx_\lambda g\rbc$ for limit ordinals $\lambda$. We prove this using 
transfinite induction. Suppose it holds for all ordinals less than $\lambda$. By the definition of 
$\approx_\lambda$, $(f\approx_\alpha g)\supset (f\approx_\lambda g)$ is valid in the model for 
all $\alpha<\lambda$. Thus $\Box\Diamond(f\approx_\alpha g)\supset\Box\Diamond (f\approx_\lambda g)$ is also 
valid in the model, that is, $\lbc f\approx_\alpha g\rbc\supset \lbc f\approx_\lambda\rbc$ is valid in the model.
Now if $p\vDash (f\approx_\lambda g)$, then $p\vDash (f\approx_\alpha g)$, and by the induction assumption, 
this means $p\vDash \lbc f\approx_\alpha g\rbc$, and hence $p\vDash\lbc f\approx_\lambda g\rbc$.

\subsubsection*{Proposition 1.5}
One such error listed in the errata is with regards to the limit ordinal case in this proposition. 
The definition of $\approx_\lambda$ is not that 
$p\vDash\lbc f\approx_\lambda\rbc$ implies 
$p\vDash\lbc f\approx_\alpha\rbc$ for some $\alpha<\lambda$,
but rather that $p\vDash f\approx_\lambda$ implies 
$p\vDash f\approx_\alpha$ for some $\alpha<\lambda$. Thus the inference made in the proof is invalid.

Instead, we show that $p\vDash f\approx_\lambda g$ implies 
$p\vDash f\approx_\beta g$. Well, if $p\vDash f\approx_\lambda g$, then 
$p\vDash f\approx_\alpha g$ for some $\alpha<\lambda$. Then it easily follows that 
$p\vDash \lbc f\approx_\alpha g\rbc$, and thus, by the induction assumption, 
$p\vDash \lbc f\approx_\beta g\rbc$.

Thus, if we know that $p\vDash \lbc f\approx_\lambda g\rbc$, we must show that this means 
$p\vDash f\approx_\lambda g$. Well, we know that 
$p\vDash (f\approx_\lambda g)\supset \lbc f\approx_\beta g\rbc$ is valid in the model, meaning, 
using standard $S4$ manipulation, $p\vDash\Box\Diamond (f\approx_\lambda g)\supset\Box\Diamond\lbc f\approx_\beta g\rbc$, 
that is, $p\vDash\lbc f\approx_\lambda g\rbc\supset\lbc f\approx_\beta g\rbc$.

We show that for $f,g\in R^\mathcal{G}_\alpha$, if $p\vDash (f\approx g)$ then 
$p\vDash (f\approx_\alpha g)$.

\begin{proof}
By transfinite induction. In particular, we make the induction assumption that, for all possible worlds 
$p$ (we are not just considering one particular one), if $p\vDash (f\approx g)$ then 
$p\vDash (f\approx_\alpha g)$.

This vacuously holds for the case of $0$.

Suppose it holds for all ordinals less than some successor ordinal $\alpha^+$. Suppose 
$f,g\in R^\mathcal{G}_{\alpha^+}$ and that $p\vDash f\approx g$. Then, by definition, it follows that
$f\approx_\beta g$ for some ordinal $\beta$. This can easily be seen to mean that, for some 
successor ordinal $\delta^+<\beta$,
\[ \textrm{(1) }p\vDash \lbc (\forall x)[(x\epsilon f)\supset (\exists y)(y\epsilon g\wedge y\approx_\delta x)]\wedge \]
Now, we must show that 
\[ \textrm{(2) }p\vDash \lbc (\forall x)[(x\epsilon f)\supset(\exists y)(y\epsilon g\wedge y\approx_\alpha x)]\wedge \]
\[ (\forall x)[(x\epsilon g)\supset(\exists y)(y\epsilon f\wedge y\approx_\alpha x)] \]
It suffices to show that $p\vDash\lbc (\forall x)[(x\epsilon f)\supset(\exists y)(y\epsilon g\wedge y\approx_\alpha x)]$ and 
that $p\vDash\lbc (\forall x)[(x\epsilon g)\supset(\exists y)(y\epsilon g\wedge y\approx_\alpha)]$. We show 
$p\vDash\lbc (\forall x)[(x\epsilon f)\supset(\exists y)(y\epsilon g\wedge y\approx_\alpha x)]$ (the other case is similar).
It suffices to show that, $p\vDash\lbc(d\epsilon f)\supset(\exists y)(y\epsilon g\wedge y\approx_\alpha d)\rbc$ for each 
$d\in\mathcal{D}^\mathcal{G}$, and this is the same as showing 
$p\vDash\Box\Diamond[\lbc d\epsilon f\rbc\supset\lbc (\exists y)(y\epsilon g\wedge y\approx_\alpha d)\rbc]$.
Consider some world $p''$ accessible from some $p'$ accessible from $p$. Then, if 
$\lbc d\epsilon f\rbc$, we know by (1) that
$p''\vDash\lbc (\exists y)(y\epsilon g\wedge y\approx_\delta d)]$, and thus 
$p'''\vDash \lbc(e\epsilon g\wedge e\approx_\delta d)\rbc$, meaning

$p'''$ accessible from $p''$, there are no $p''''$ accessible from $p'''$ such that
