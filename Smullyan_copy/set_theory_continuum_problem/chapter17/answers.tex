Here is an explanation for the remarks given on page 224. Note that I am assuming $M$ contains all ordinals (see the section for 
Remark 3). 
Definition 1.1 to even work in the first place. If a function $f$ has domain $\alpha$, and is such that, for all $\beta<\alpha$, 
$f(\beta)=R^\mathcal{G}_\beta$, call $f$ an $R^\mathcal{G}_\alpha$ function. Let $\textrm{R-alpha func}(f)$ stand for the following formula:
\[ \textrm{Func}(f)\wedge\textrm{Dom}(f)=\alpha\wedge f(0)=0\wedge \]
\[ (\forall\beta<\alpha)(\beta^+<\alpha\supset(\forall x)(x\in f(\beta^+)\equiv x\subseteq\mathcal{G}\times f(\beta))) \]
\[ \wedge (\forall\beta<\alpha)(\textrm{beta is a limit ordinal}\supset(\forall x)(x\in f(\beta) \]
\[ \equiv(\exists\delta<\beta)(x\in f(\delta)))) \]
Note that $\textrm{R-alpha func}(f)$ just means $f$ is the $R^\mathcal{G}_\alpha$ function.

\begin{lemma}
For any $\alpha$ ($\alpha\in M$), if, $R^\mathcal{G}_\beta\in M$ for all $\beta<\alpha$, then 
both $R^\mathcal{G}_\alpha\in M$ and the $R^\mathcal{G}_\alpha$ function are in $M$. 
\end{lemma}

\begin{proof}
By transfinite induction.

The least ordinal case is obvious (because $\emptyset\in M$).

Suppose it holds for all ordinals less than some ordinal $\alpha$. So suppose that 
$R^\mathcal{G}_\beta\in M$ for all $\beta<\alpha$. Then it follows that the 
$R^\mathcal{G}_\beta$ function is in $M$ for all $\beta<\alpha$. 
We first show that $R^\mathcal{G}_\alpha\in M$. Well, if $\alpha$ is a successor ordinal of some $\beta$, then it 
is defined by the formula
\[ (\forall y)(y\in x\equiv y\subseteq\mathcal{G}\times R^\mathcal{G}_\beta) \]
which works, as $\mathcal{G}\times R^\mathcal{G}_\beta\in M$ for the following reason:
both $\mathcal{G}$ and $R^\mathcal{G}_\beta$ are in $M$, meaning 
$\{\mathcal{G},R^\mathcal{G}_\beta\}\in M$ (because $M$ is a first order universe). Thus
$\cup\{\mathcal{G},R^\mathcal{G}_\beta\}\in M$, meaning
$\mathcal{P}(\cup\{\mathcal{G},R^\mathcal{G}_\beta\})\cap M\in M$, and thus
(1) $\mathcal{P}(\mathcal{P}(\cup\{\mathcal{G},R^\mathcal{G}_\beta\})\cap M)\cap M\in M$. Now, it is 
obvious that the formula in $M$ in (1) is such that $\langle x,y\rangle$ is in it for each 
$x\in\mathcal{G}$ and each $y\in R^\mathcal{G}_\beta$. Then it is easy to see that 
$\mathcal{G}\times R^\mathcal{G}_\beta$ is first-order definable over $M$, and, because this 
would mean it is a first-order definable susbset of the set in (1), 
$\mathcal{G}\times R^\mathcal{G}_\beta\in M$ (because $M$ is first-order swelled). 

The case where $\alpha$ is a limit ordinal is mostly similar. In particular, because we 
are assuming the $R^\mathcal{G}_\beta$ function is in $M$ for each $\beta<\alpha$, the following 
defines $R^\mathcal{G}_\alpha$:
\[ (\exists\beta<\alpha)(\exists f)(\textrm{R-beta func}(f)\wedge(\exists\delta<\beta)(x\in f(\delta))) \]

Thus we know that $R^\mathcal{G}_\alpha\in M$.

Now we show that the $R^\mathcal{G}_\alpha$ function is definable over $M$.
Well, if $\alpha$ is a successor ordinal of some $\beta$, then
the $R^\mathcal{G}_\alpha$ function is definable over $M$ by the formula
\[ (x=\beta\wedge y=R^\mathcal{G}_\beta)\vee \]
\[ (\exists\delta<\alpha)(\exists f)(\textrm{R-delta func}(f)\wedge x\in\textrm{Dom}(f)\wedge y=f(x)) \]
and if $\alpha$ is a limit ordinal, then it is defined over $M$ by the following formula
\[ (\exists\delta<\alpha)(\exists f)(\textrm{R-delta func}(f)\wedge x\in\textrm{Dom}(f)\wedge y=f(x)) \]
Thus, in any case, we know that the $R^\mathcal{G}_\alpha$ function is definable over $M$. Because 
$\alpha\in M$, this means that the range of the $R^\mathcal{G}_\alpha$ function, the 
set $S$ of all $R^\mathcal{G}_\beta$ for $\beta<\alpha$, is in $M$. Hence 
$\{\alpha,S\}\in M$, $\cup\{\alpha,S\}\in M$, 
$\mathcal{P}(\cup\{\alpha,S\})\in M$,
and $\mathcal{P}(\mathcal{P}(\cup\{\alpha,S\}))\in M$. Now, 
for each $\beta<\alpha$ and $x\in S$, it of course follows that 
$\langle \beta,x\rangle\in\mathcal{P}(\mathcal{P}(\cup\{\alpha,S\}))$. That is, 
the $R^\mathcal{G}_\alpha$ function is a first-order definable subset of 
$\mathcal{P}(\mathcal{P}(\cup\{\alpha,S\}))$, which is in $M$, meaning
the function itself is in $M$.
\end{proof}

\subsubsection*{Remark 2}
We show that $R^\mathcal{G}_\alpha\subseteq R^\mathcal{G}_{\alpha+1}$. In fact, we directly prove the stronger result, 
that $\beta<\alpha$ implies $R^\mathcal{G}_\beta\subseteq R^\mathcal{G}_\alpha$.

\begin{proof}
By transfinite induction.

The least ordinal case is vacuous.

Suppose the result holds for some $\alpha$. Now, if $x\in R^\mathcal{G}_\alpha$, 
there is some $\beta<\alpha$ such that all members of $x$ are of the form 
$\langle y,z\rangle$ where $y\in\mathcal{G}$ and $z\in R^\mathcal{G}_\beta$. By the induction 
assumption, this means that $z\in R^\mathcal{G}_\alpha$. Then 
$\langle y,z\rangle$ would also be in $R^\mathcal{G}_\alpha$ for all such $y$ and $z$, and then so would 
$x$ (as we are assuming $x$ is in $M$).

The limit ordinal case is obvious.
\end{proof}

\subsubsection*{Remark 3}
We first prove the following lemma.

\begin{lemma}
For each ordinal $\alpha$, if $\alpha$ is the least ordinal or a limit ordinal, 
$R^\mathcal{G}_\alpha\in R^\mathcal{G}_{\alpha^+}$ (note, however, that $R^\mathcal{G}_{\alpha^+}\notin R^\mathcal{G}_{\alpha^{++}}$ in 
general for successor ordinals $\alpha^+$). 
\end{lemma}

\begin{proof}
The least ordinal case is obvious, as $R^\mathcal{G}_0\in R^\mathcal{G}_1$ because 
$R^\mathcal{G}_0=\emptyset$ and $R^\mathcal{G}_1=\{\emptyset\}$.

Consider some limit ordinal $\lambda$. Hence $R^\mathcal{G}_\lambda=\cup_{\alpha<\lambda}R^\mathcal{G}_\alpha$.
We already know that $R^\mathcal{G}_\lambda$ is in $M$ (by (1) of the remarks). Also, it can 
easily be seen that $R^\mathcal{G}_\lambda\subseteq\mathcal{G}\times R^\mathcal{G}_\lambda$. 
Thus, by definition of $R^\mathcal{G}_{\lambda^+}$, it follows that 
$R^\mathcal{G}_\lambda\in R^\mathcal{G}_{\lambda^+}$.
\end{proof}

We now prove that $R^\mathcal{G}_{\alpha+1}\ne R^\mathcal{G}_\alpha$.

\begin{proof}
By transfinite induction. In particular, we show that, for every $\alpha$, $R^\mathcal{G}_\beta\ne R^\mathcal{G}_\alpha$ for every 
$\beta<\alpha$.

Suppose the result holds for all ordinals less than some ordinal $\delta$.

Least ordinal case: The case when $\delta=\emptyset$ is vacuous.

Successor ordinal case: Suppose $\delta$ is the successor of some ordinal $\alpha$.
There are two cases: either $\alpha$ itself is a successor ordinal, 
or it is a limit ordinal (of course, $\alpha$ could be $\emptyset$, but that case is trivial). We must show the result holds for $\alpha^+$ 
(that is, $\delta$). 
Note that it suffices to show that $R^\mathcal{G}_{\alpha+1}\ne R^\mathcal{G}_\alpha$, for, if we show that, then if 
$R^\mathcal{G}_{\alpha+1}=R^\mathcal{G}_\beta$ for some $\beta<\alpha$, then it would follow that 
$R^\mathcal{G}_\beta=R^\mathcal{G}_\alpha$ by part (2) of the remarks, contrary to the induction assumption.

On the one hand, suppose that $\alpha$ itself is a successor ordinal (say of some $\beta$). Thus, by the assumption, we 
know that there must be some $y\in R^\mathcal{G}_\alpha$ such that $y\notin R^\mathcal{G}_\beta$. Consider any $x\in\mathcal{G}$. 
Then $\{\langle x,y\rangle\}\in R^\mathcal{G}_{\alpha+1}$ (because $M$ is a first-order universe). If 
$R^\mathcal{G}_{\alpha+1}=R^\mathcal{G}_\alpha$, then it would follow that $z=\{\langle x,y\rangle\}$ for some 
$z\in R^\mathcal{G}_\alpha$. What this would mean is that $\langle x,y\rangle\in\mathcal{G}\times R^\mathcal{G}_\beta$. 
But that would mean $y\in R^\mathcal{G}_\beta$, a contradiction. Thus it must be that $R^\mathcal{G}_{\alpha+1}\ne R^\mathcal{G}_\alpha$.

On the other hand, suppose that $\alpha$ is a limit ordinal. By Lemma 0.2, it follows that $R^\mathcal{G}_\alpha\in R^\mathcal{G}_{\alpha^+}$. 
If $R^\mathcal{G}_{\alpha^+}=R^\mathcal{G}_\alpha$, then $R^\mathcal{G}_\alpha\in R^\mathcal{G}_\alpha$, which contradicts the 
assumption that $M$, and, by extension, $R^\mathcal{G}_\alpha$, is well founded. 

Limit ordinal case: This is easy.
\end{proof}

\subsection*{Clarification}
Definition 1.4 in the book needs clarification. In particular, the $\lbc\rbc$ translation is being used, 
yet this has not yet been defined for the $\approx_\alpha$ relation. The definition should be:
$\lbc f\approx_{\alpha+1} g\rbc=f\approx_{\alpha+1} g$, 
$\lbc f\approx_\lambda g\rbc=\Box\Diamond f\approx_\lambda$ for $\lambda$ a limit ordinal, and
$\lbc x\epsilon y\rbc=\Box\Diamond x\epsilon y$. 

The errata listed at \url{https://id144254.securedata.net/melvinfitting/errata/book_errors/RevisedSetBookErrors/RevisedSetCorrections.pdf}
are important to note for this section.

It should be noted why $(f\approx_\lambda g)\supset\lbc f\approx_\lambda g\rbc$ for limit ordinals $\lambda$. We prove this using 
transfinite induction. Suppose it holds for all ordinals less than $\lambda$. By the definition of 
$\approx_\lambda$, $(f\approx_\alpha g)\supset (f\approx_\lambda g)$ is valid in the model for 
all $\alpha<\lambda$. Thus $\Box\Diamond(f\approx_\alpha g)\supset\Box\Diamond (f\approx_\lambda g)$ is also 
valid in the model, that is, $\lbc f\approx_\alpha g\rbc\supset \lbc f\approx_\lambda\rbc$ is valid in the model.
Now if $p\vDash (f\approx_\lambda g)$, then $p\vDash (f\approx_\alpha g)$ for some $\alpha<\lambda$, and by the induction assumption, 
this means $p\vDash \lbc f\approx_\alpha g\rbc$, hence $p\vDash\lbc f\approx_\lambda g\rbc$.

\subsubsection*{Proposition 1.5}
One such error listed in the errata is with regards to the limit ordinal case in this proposition. 
The definition of $\approx_\lambda$ is not that 
$p\vDash\lbc f\approx_\lambda\rbc$ implies 
$p\vDash\lbc f\approx_\alpha\rbc$ for some $\alpha<\lambda$,
but rather that $p\vDash f\approx_\lambda$ implies 
$p\vDash f\approx_\alpha$ for some $\alpha<\lambda$. Thus the inference made in the proof is invalid.

Instead, we show that $p\vDash f\approx_\lambda g$ implies 
$p\vDash \lbc f\approx_\beta g\rbc$. Well, if $p\vDash f\approx_\lambda g$, then 
$p\vDash f\approx_\alpha g$ for some $\alpha<\lambda$. Then it easily follows that 
$p\vDash \lbc f\approx_\alpha g\rbc$, and thus, by the induction assumption, 
$p\vDash \lbc f\approx_\beta g\rbc$.

Thus $p\vDash (f\approx_\lambda g)\supset\lbc f\approx_\beta g\rbc$ is valid in the model.
Hence, using standard $S4$ manipulation, 
$p\vDash\Box\Diamond(f\approx_\lambda g)\supset\Box\Diamond\lbc f\approx_\beta g\rbc$, that is, 
$p\vDash \lbc f\approx_\lambda g\rbc\supset\lbc f\approx_\beta g\rbc$, is valid in the model. 

\subsection*{Exercise 1.3}
We show that for $f,g\in R^\mathcal{G}_\alpha$, if $p\vDash (f\approx g)$, then 
$p\vDash (f\approx_\alpha g)$.

\begin{proof}
By transfinite induction. In particular, we make the induction assumption that, for all possible worlds 
$p$ (we are not just considering one particular one), if $p\vDash (f\approx g)$ for 
$f,g\in R^\mathcal{G}_\alpha$, then $p\vDash (f\approx_\alpha g)$.

This vacuously holds for the case of $0$, and the limit ordinal case is obvious.

The successor ordinal case is where the real work is required. Suppose the result holds for all 
ordinals less than some successor ordinal $\alpha^+$. Suppose $f,g\in R^\mathcal{G}_{\alpha^+}$, and 
$p\vDash (f\approx g)$. 
Now, this means $p\vDash (f\approx_\beta g)$ for some $\beta$. This means $p\vDash (f\approx_{\delta^+} g)$ for some 
successor ordinal $\delta^+\le\beta$. Thus we have
\[ p\vDash\lbc(\forall x)[(x\epsilon f)\supset(\exists y)(y\epsilon g\wedge y\approx_\delta x)]\wedge \]
\[ (\forall x)[(x\epsilon g)\supset(\exists y)(y\epsilon f\wedge y\approx_\delta x)]\rbc \]
meaning we have
\[ p\vDash\lbc(\forall x)[(x\epsilon f)\supset(\exists y)(y\epsilon g\wedge y\approx_\delta x)]\rbc \]
which means we have, for each $d\in\mathcal{D}^\mathcal{G}$,
\[ p\vDash\lbc(x\epsilon f)\supset(\exists y)(y\epsilon g\wedge y\approx_\delta x)\rbc \]
meaning we have
\[ \textrm{(1) }p\vDash\Box\Diamond(\lbc x\epsilon f\rbc\supset\lbc(\exists y)(y\epsilon g\wedge y\approx_\delta d))\rbc \]
Because we want to show $p\vDash (f\approx_{\alpha^+} g)$, what we aim to show is
\[ p\vDash\lbc(\forall x)[(x\epsilon f)\supset(\exists y)(y\epsilon g\wedge y\approx_\alpha x)]\wedge \]
\[ (\forall x)[(x\epsilon g)\supset(\exists y)(y\epsilon f\wedge y\approx_\alpha x)]\rbc \]
It suffices to show both $p\vDash\lbc(\forall x)[(x\epsilon f)\supset(\exists y)(y\epsilon g\wedge y\approx_\alpha x)]\rbc$ and 
$p\vDash\lbc(\forall x)[(x\epsilon g)\supset(\exists y)(y\epsilon f\wedge y\approx_\alpha x)]\rbc$. We give the proof of 
(2) $p\vDash\lbc(\forall x)[(x\epsilon f)\supset(\exists y)(y\epsilon g\wedge y\approx_\alpha x)]\rbc$ - the other case is similar. Now, (2) 
is the same as saying $p\vDash(\forall x)\lbc(x\epsilon f)\supset(\exists y)(y\epsilon g\wedge y\approx_\alpha x)\rbc$. It suffices to show that, 
for all $d\in\mathcal{D}^\mathcal{G}$, $p\vDash\lbc(d\epsilon f)\supset(\exists y)(y\epsilon g\wedge y\approx_\alpha d)\rbc$. So consider any 
$d\in\mathcal{D}^\mathcal{G}$. We must show that
$p\vDash\lbc(d\epsilon f)\supset(\exists y)(y\epsilon g\wedge y\approx_\alpha d)\rbc$, which is equivalent to
$p\vDash\Box\Diamond(\lbc d\epsilon f\rbc\supset\lbc(\exists y)(y\epsilon g\wedge y\approx_\alpha d)\rbc)$, which is equivalent to
(2$'$) $p\vDash\Box\Diamond(\lbc d\epsilon f\rbc\supset\Box\Diamond(\exists y)\lbc y\epsilon g\wedge y\approx_\alpha d\rbc)$. To show this,
consider any $p'$ accessible from $p$. By (1), there is some $p''$ accessible from $p'$ such that 
$p''\vDash \lbc x\epsilon f\rbc\supset\lbc(\exists y)(y\epsilon g\wedge y\approx_\delta d)\rbc$, which is equivalent to
(3) $p''\vDash\lbc d\epsilon f\rbc\supset\Box\Diamond\lbc(\exists y)(y\epsilon g\wedge y\approx_\delta d)\rbc$. We show that
(4) $p''\vDash \lbc d\epsilon f\rbc\supset\Box\Diamond(\exists y)\lbc y\epsilon g\wedge y\approx_\alpha d\rbc$
(which would imply (2$'$)). So suppose that 
$p''\vDash\lbc d\epsilon f\rbc$. By (3), this means that 
(5) $p''\vDash\Box\Diamond\lbc(\exists y)(y\epsilon g\wedge y\approx_\delta d)\rbc$. To show that (4) holds, consider any 
$q$ accessible from $p''$. By (5), there is some $q'$ accessible from $q$ such that
$q'\vDash\lbc(\exists y)(y\epsilon g\wedge y\approx_\delta d)\rbc$. Then there is some $q''$ accessible from $q'$
such that there is some $k\in\mathcal{D}^\mathcal{G}$ with
$q''\vDash\lbc k\epsilon g\wedge k\approx_\delta d\rbc$, which implies both
$q''\vDash\lbc k\epsilon g\rbc$ and $q''\vDash\lbc k\approx_\delta d\rbc$. Note that $d,k\in R^\mathcal{G}_\alpha$. 
Because $q''\vDash\lbc k\approx_\delta d\rbc$, it follows that 
$q''\vDash\Box\Diamond (k\approx_\delta d)$. Thus there is some $r'$ accessible from some $r$ accessible from $q''$ such 
that $r'\vDash (k\approx_\delta d)$. Now, this implies $r'\vDash (k\approx d)$. By the induction assumption, this tells us 
that $r'\vDash (k\approx_\alpha d)$, which implies $r'\vDash\lbc k\approx_\alpha\rbc$. 
Also, because $r$ is accessibe from $q''$ (by the transitivity of the accessibility relation), and $q''\vDash\lbc k\epsilon g\rbc$, 
$r'\vDash\lbc k\epsilon g\rbc$. Now, because $r'$ is accessible from $q$, the fact that we have shown both 
$r'\vDash\lbc k\approx_\alpha\rbc$ and $r'\vDash\lbc k\epsilon g\rbc$ proves that 
$p''\vDash\Box\Diamond(\exists y)\lbc(y\epsilon g)\wedge (y\approx_\alpha d)$, which completes the proof in this case.
\end{proof}

\subsection*{Lemma 2.1}
It is claimed that $(f\approx_\alpha g)\equiv\lbc f\approx_\alpha g\rbc$, yet this is incorrect. In particular, if 
$\lbc (f\approx_\alpha g)\rbc$ for $\alpha$ a limit ordinal, it does not necessarily follow that $(f\approx_\alpha g)$.

The proof of this lemma leaves out the limit ordinal case. Here is an explanation for that case. Suppose the 
result holds for all $\alpha<\lambda$ for some limit ordinal $\lambda$. Now suppose that 
$p\vDash\lbc f\approx_\lambda g\rbc$ and $p\vDash\lbc g\approx_\lambda h\rbc$, which imply both 
(1) $p\vDash\Box\Diamond(f\approx_\lambda g)$ and (2) $p\vDash\Box\Diamond(g\approx_\lambda h)$. To prove 
$p\vDash\lbc f\approx_\lambda h\rbc$, it suffices to show that 
$p\vDash\Box\Diamond(f\approx_\lambda h)$. So consider any $p'$ accessible from $p$. By (1), this means there is some 
$p''$ accessible from $p'$ such that $p''\vDash f\approx_\lambda g$, meaning 
$p''\vDash f\approx_\alpha g$ for some $\alpha<\lambda$, and thus (3) $p''\vDash\lbc f\approx_\alpha g\rbc$.
Because $p''$ is itself accessible from $p$, it follows by (2) that there is some $p'''$ accessible from $p''$ such 
that $p'''\vDash g\approx_\lambda h$, which implies $p'''\vDash g\approx_\beta h$ for some $\beta<\lambda$, which implies 
$p'''\vDash \lbc g\approx_\beta h\rbc$. Now, by (3), and the fact that $p'''$ is accessible from $p''$, 
$p'''\vDash\lbc f\approx_\alpha g\rbc$. Pick the greater of $\alpha$ and $\beta$ (say it is $\alpha$).
Then, by cumulativity, $p'''\vDash \lbc g\approx_\alpha h\rbc$. Hence, by the induction assumption, it follows that 
$p'''\vDash\lbc f\approx_\alpha h\rbc$. What this means is that for some $q'$ accessible from some $q$ accessible from 
$p'''$, $q'\vDash f\approx_\alpha h$, which implies $q'\vDash f\approx_\lambda h$ (because $\alpha<\lambda$). 
But $q'$ is accessible from $p'$. Thus we have shown, for every world 
$p'$ accessible from $p$, there is some world $q'$ such that $q'\vDash f\approx_\lambda h$ holds, and this proves 
$p\vDash\Box\Diamond (f\approx_\lambda h)$, that is, $p\vDash\lbc f\approx_\lambda h\rbc$.

The proof of this theorem is incorrect. It is claimed that $p\vDash\lbc f\approx g\rbc$ implies

\section*{Definition 3.1}
It is not explained in the book, but here is why $\hat{x}\in\mathcal{D}^\mathcal{G}$ in the first place.

First, define the following ordinal hierarchy:

$R^M_0=\emptyset$

$R^M_{\alpha^+}=\mathcal{P}(R^M_\alpha)\cap M$

$R^M_\lambda=\cup_{\alpha<\lambda}R^M_\alpha$ for limit ordinals $\lambda$

Each $R^M_\alpha$ is just the set of all members of $R_\alpha$ that happen to be in $M$.
An obvious transfinite induction argument (using the fact that $M$ is a first-order universe) shows that 
each $R^M_\alpha$ is in $M$ (for $\alpha\in M$). Let $R^M=\cup_\alpha R_\alpha$. By Theorem 3.3 of Chapter 8 (and the fact 
that $M$ is transitive and well founded), each element of $M$ has a rank. It follows 
that, in fact, $R^M=M$. Thus if we can show that there is a function satisfying the requirenments of Definition 3.1 
for $R^M$, it also satisfies the requirenments for $M$ itself. In particular, we want an $f$ such that 
$f(x)=\{\langle p,f(y)\rangle|p\in\mathcal{G}\wedge y\in x\}$. To show this, we show that there is a function 
$f_\alpha$ for each $\alpha$, whose domain is $R^M_\alpha$, and such that 
$f_\alpha(x)=\{\langle p,f_\alpha(y)\rangle|p\in\mathcal{G}\wedge y\in x\}$. This is of course immediate by 
any of the transfinite recursion theorems.

Call a function an $M_\alpha$ function if it satisfies the following conditons: its domain is 
$\alpha$, and for each $\alpha$, $f(\alpha)=f_\alpha$.

Let $\textrm{M-func}_\alpha(x)$ stand for the following:
\[ \textrm{Func}(x)\wedge\textrm{Dom}(x)=R^M_\alpha\wedge f(0)=0\wedge \]
\[ (\forall\beta<\alpha)[\beta^+<\alpha\supset \]
\[ (\forall y)(y\in f(\beta^+)\equiv(y\in f(\beta)\vee(\exists v)(\exists w)(y=\langle w,v\rangle\wedge \]
\[ w\in(R^M_{\beta^+}-R^M_\beta)\wedge(\forall z)(z\in v\equiv(\exists p)(\exists s)(p\in\mathcal{G}\wedge s\in w\wedge z=\langle p,f(\beta)(s))))))] \]
\[ \wedge(\forall\lambda<\alpha)[\textrm{lambda is a limit ordinal}\supset(\forall y)(y\in f(\lambda)\equiv(\exists\beta<\lambda)(y\in f(\beta))]) \]
If the $M_\alpha$ function happens to be in $M$, then $\textrm{M-func}_\alpha(f)$ will be true in $M$ for that function $f$. 

We first prove that each $f_\alpha$ is in $M$ (for all $\alpha$ in $M$), and each $M_\alpha$ function is in $M$.

\begin{theorem}
For all $\alpha\in M$, $f_\alpha\in M$, and the $M_\alpha$ function is in $M$.
\end{theorem}

\begin{proof}
By transfinite induction.

The least ordinal case is given by the empty set axiom holding over $M$.

Suppose the result holds for some $\alpha$. Thus we know that $f_\alpha\in M$ and 
the $M_\alpha$ function is in $M$. Let $M_\alpha$ stand for the $M_\alpha$ function. 
The $f_{\alpha^+}$ function is defined over $M$ by:
\[ (x\in\textrm{Dom}(f_\alpha)\wedge f_\alpha(x)=y)\vee \]
\[ [x\in(R^M_{\alpha^+}-R^M_\alpha)\wedge(\forall z)(z\in y\equiv(\exists w)(\exists v)(z=\langle w,v\rangle\wedge \]
\[ w\in\mathcal{G}\wedge(\exists s)(s\in x\wedge v=f_\alpha(s))))] \] 
Because the domain of the $f_{\alpha^+}$ function, $R^M_{\alpha^+}$, is in $M$, it follows 
by the axiom of substitution (over $M$) that the range is also in $M$. Then the set 
$S:\mathcal{P}(\mathcal{P}(\cup\{\textrm{Dom}(f_{\alpha^+}),\textrm{Ran}(f_{\alpha^+})\})\cap M)\cap M$ is in $M$. Then, 
because $f_{\alpha^+}$ is a first-order definable (over $M$) subset of $S$, it follows that $f_{\alpha^+}\in M$.

Next we show that $M_{\alpha^+}\in M$. This function is definable by
\[ (x\in\textrm{Dom}(M_\alpha)\wedge M_\alpha(x)=y)\vee (x=\alpha\wedge y=f_\alpha) \]
and because the domain of the function, $\alpha^+$, is in $M$, it follows that so is the range. Then by an 
argument similar in nature to the one in the previous paragraph, it follows that $M_{\alpha^+}\in M$

Now we consider the limit ordinal case. Suppose the result holds for all $\alpha<\lambda$ for some limit ordinal 
$\lambda$. First, the $M_\lambda$ function is definable over $M$ by
\[ (\exists\alpha<\lambda)(\exists f)(\textrm{M-func}_\alpha(f)\wedge x\in\textrm{Dom}(f)\wedge f(x)=y) \]
Because the domain of this function, $\lambda$, is in $M$, it follows that so is the range, that is, 
the set $S$ of all $f_\alpha$ for $\alpha<\lambda$. But then $\cup S$, that is, $f_\lambda$, is in $M$. Also, because 
both $\lambda$ and $S$ are in $M$, it easily follows that the $M_\lambda$ function is also in $M$. 

\end{proof}

Because we have shown each $f_\alpha$ to be in $M$, it follows by the transitivity of $M$ that 
$f_\alpha(x)\in M$ for each $x\in R^M_\alpha$. 
Next, we show that if $x\in R^M_\alpha$, then $\hat{x}\in R^\mathcal{G}_\alpha$, that is, 
$f_\alpha(x)\in R^\mathcal{G}_\alpha$.

\begin{proof}

The least ordinal case is vacuous, and the limit ordinal case is obvious.

Suppose the result holds for some $\alpha$, that is, for 
each $x\in R^M_\alpha$, $f_\alpha\in R^\mathcal{G}_\alpha$. Now consider any 
$x\in R^M_{\alpha^+}$. We already have shown that $f_{\alpha^+}(x)\in M$. Thus, if we can

by definition of the $f_{\alpha^+}$ function, each member of $f_{\alpha^+}(x)$ is of the form

for some $p'''$ with $p''\mathcal{R}p'''$, $p'''\vDash a'\epsilon h$, and it then follows by the definition of $h$ that 
$p'''\vDash\lbc a'\in\{f,g\}\rbc$. Then by substitutivity, $p'''\vDash\lbc a\in\{f,g\}\rbc$, and this is impossible 
since $\lbc\oldneg(a\in\{f,g\})\rbc$ is true at $p'$, hence at $p'''$. 

(2) Suppose for some $a$, $p\nvDash\lbc a\in\{f,g\}\supset a\in h\rbc$. Then for some $p'$ with $p\mathcal{R}p'$, 
$p'\vDash\lbc a\in\{f,g\}\rbc$ and $p'\vDash\lbc\oldneg(a\in h)\rbc$. Since $p'\vDash\lbc a\in\{f,g\}\rbc$, 
$p'\vDash\lbc a\approx f\vee a\approx g\rbc$, meaning, at some world $p''$ accessible from $p'$, either 
$p''\vDash\lbc a\approx f\rbc$ or $p''\vDash\lbc a\approx g\rbc$ holds. Without loss of generality, suppose 
it is the former that is true, that is, $p''\vDash\lbc a\approx f\rbc$. By substitutivity, we would then know that 
$p''\vDash\lbc\oldneg(f\in h)\rbc$, which contradicts the fact that 
$(f\in h)$ is true at all possible worlds. 

\section*{Exercise 4.2}
Suppose $p\nvDash\lbc(\forall y)(\forall z)(\exists w)(\forall x)(x\in w\equiv x\in\{y,z\})\rbc$. Then for some 
$f,g\in\mathcal{D}^\mathcal{G}$, (1) $p\nvDash\lbc(\exists w)(\forall x)(x\in w\equiv x\in\{f,g\})$. By 
Theorem 4.3, there is some $h\in\mathcal{D}^\mathcal{G}$ such that 
$p\vDash\lbc(\forall x)(x\in h\equiv x\in\{f,g\})\rbc$. But by (1), 
$p\nvDash\lbc(\forall x)(x\in h\equiv x\in\{f,g\})$, a contradiction.

\section*{Exercise 4.3}
Suppose $p\nvDash\lbc(\exists y)(y\in a)\supset(\exists y)(y\in a\wedge(\forall z)(z\in a\supset\oldneg(z\in y))\rbc$. 
Then, for some $p'$ with $p\mathcal{R}p'$,
$p'\vDash\lbc(\exists y)(y\in a)\rbc$ and $p'\vDash\lbc\oldneg(\exists y)(y\in a\wedge(\forall z)(z\in a\supset\oldneg(z\in y)))\rbc$.
Thus, for some $p''$ with $p'\mathcal{R}p''$ and for some $g\in\mathcal{D}^\mathcal{G}$, we have
$p''\vDash\lbc g\in a\rbc$ and (1) $p''\vDash\lbc\oldneg(\exists y)(y\in a\wedge(\forall z)(z\in a\supset\oldneg(z\in y)))\rbc$. By Lemma 4.6, 
there is some $p'''$ with $p''\mathcal{R}p'''$ and some $c$ such that 
(2) $p'''\vDash\lbc c\in a\rbc$ and $p'''\vDash(\forall z)\lbc(z\in a\supset\oldneg(z\in c))\rbc$, which is equivalent to
$p'''\vDash\lbc(\forall z)(z\in a\supset\oldneg (z\in c))\rbc$. By (1), 
$p'''\vDash\lbc(c\in a)\supset\oldneg(\forall z)(z\in a\supset\oldneg(z\in c))\rbc$, meaning, by (2), 
$p'''\vdash\lbc\oldneg(\forall z)(z\in a\supset\oldneg(z\in c))\rbc$, a contradiction.

\section*{Sets in Theorems of Section 4}
In Theorem 4.1, it is claimed that it is obvious that $g\in R^\mathcal{G}_{\alpha+1}$, and this is similarly claimed for similar sets in many 
other proofs in section 4. In reality, the result does follow, but much work is required. In Theorem 4.1, we indeed do know that 
all members of $g$ are of the form $\langle p,a\rangle$ for $p\in\mathcal{G}$ and $a\in R^\mathcal{G}_\alpha$, but we do not yet know that 
$g\in M$, which is required to conclude that $g\in R^\mathcal{G}_{\alpha^+}$. One method to show that $g$ is in $M$ is to first show that it is 
definable over $M$, and, because $g\subseteq\mathcal{G}\times R^\mathcal{G}_\alpha$ (and $\mathcal{G}\times R^\mathcal{G}_\alpha$ is in 
$M$), it would then follow that $g$ would also be in $M$.

First, an encoding of formulas with $\Box$, $\Diamond$, $\epsilon$, and $\lbc\rbc$ would be required. This is fairly straightforward to do, 
as we know that $\mathcal{R}\in M$, and thus we can represent the notion of accessible worlds in modal formulas.
Next, one would need to introduce a relation $t^p(x)$ for the code of some formula $x$ meaning $x$ is true at world $p$. After this, 
it would next be necessary to encode the $\approx_\alpha$ relations, and then the $\approx$ relation itself. This would require transfinite induction, and, 
ultimately, a variant $t^p_\alpha (x)$ of the relation $t^p(x)$ to also give truth values for formulas containing $\approx_\alpha$. Once 
$\approx$ has been properly encoded, and there is a valuation function for codes of formulas including it, the notion of 
$f\in g$ being true at $p$ would have to be acocunted for in the valuation function.

It should be noted that, if \textquote{definable over $M$} allows the use of formulas involving the various new relations introduced in this 
chapter, then none of the encoding work is needed, and it is obvious that the sets in the theorems are in $M$.
