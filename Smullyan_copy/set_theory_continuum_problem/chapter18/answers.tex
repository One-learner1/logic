\subsection*{Lemma 2.2}
Here is why $\cup_{q_0\in\mathcal{G}}S(q_0)$ is an $M$-set (and hence so is $S$). Let 
$G(x,q)$ stand for the formula
\[ (\forall y\in x)(\textrm{Ordinal}(y)\wedge(\exists g\in R^\mathcal{G}_\beta)(q\vDash\lbc\hat{y}\approx g\rbc)) \]
(this can be expanded to a real first-order formula by results in the previous chapter).
If $S(q_0)$ happens to be in $M$, then $G(S(q_0),q_0)$ will be true in $M$. Now, we already know that each 
$S(q_0)\in M$. Then consider the following function which is definable over $M$:
\[ x\in\mathcal{G}\wedge G(y,x) \]
Because the domain, $\mathcal{G}$, is in $M$, so is the range, and because we have shown each $S(q_0)$ to be in $M$, the 
range is the set of all $S(q_0)$ (for $q_0\in\mathcal{G}$). Then the union of this, which is also in $M$, 
is just $S$ itself.

\subsection*{Notes}
It should be noted why both $\mathcal{G}\in M$ and $\mathcal{R}\in M$ (which are both conditions we need to have).
$\mathcal{G}$ is a subset of $(\mathcal{P}\cap M)\times(\mathcal{P}\cap M)$, which is in $M$. Also, 
$\mathcal{G}$ is definable over $M$ by
\[ (\exists P)(\exists N)(\exists n)(\exists m)(\exists f)(\exists g)(x=\langle P,N\rangle\wedge \textrm{Num}(n)\wedge\textrm{Num}(m)\wedge \]
\[ \textrm{f is 1-1 func}(n,N)\wedge\textrm{g is 1-1 func}(m,P)\wedge P\cap N=\emptyset) \]
(this works because, for each 1-1 function from a number $n$ to some $N$ or $P$, it is finite, so it 
is in $M$). Thus $\mathcal{G}\in M$. As for $\mathcal{R}$, it is a subset of 
$\mathcal{G}\times\mathcal{G}$, which is in $M$, and is defined over $M$ by the formula:
\[ (\exists P_1,P_2)(\exists N_1,N_2)(x=\langle P_1,N_1\rangle\wedge y=\langle P_2,N_2\rangle\wedge x\in\mathcal{G}\wedge y\in\mathcal{G} \]
\[ \wedge P_1\subseteq P_2\wedge N_1\subseteq N_2) \]
and thus $\mathcal{R}\in M$.

\subsection*{Exercise 4.1}
Suppose $n\in N$. We show that $\langle P,N\rangle\vDash\lbc\oldneg(\hat{n}\epsilon f_0)\rbc$. 
Because $n\in N$, $n\notin P$. Thus $\langle P,N\rangle\vDash\oldneg(\hat{n}\epsilon f_0)$. Now, if 
$\langle P,N\rangle\mathcal{R}\langle P_1,N_1\rangle$, then $N\subseteq N_1$, and thus $n\in N_1$, but 
$n\notin P_1$, which would mean $\langle P_1,N_1\rangle\vDash\oldneg(\hat{n}\epsilon f_0)$. This explains 
why $\langle P,N\rangle\vDash\Box\oldneg(\hat{n}\epsilon f_0)$, and thus 
$\langle P,N\rangle\vDash\lbc\oldneg(\hat{n}\epsilon f_0)\rbc$.

\subsection*{Notes}
Here is why the negation of the formula on page 253 is $\Sigma$ formula. Its negation is
\[ \oldneg(\textrm{Ordinal}(\alpha)\wedge(\forall\beta\in\alpha)\oldneg(\exists f)(\textrm{1-1 onto}(f,\beta,\alpha))) \]
\[ \oldneg\textrm{Ordinal}(\alpha)\vee\oldneg(\forall\beta\in\alpha)\oldneg(\exists f)(\textrm{1-1 onto}(f,\beta,\alpha)) \]
\[ \oldneg\textrm{Ordina}(\alpha)\vee(\exists\beta\in\alpha)(\exists f)(\textrm{1-1 onto}(f,\beta,\alpha)) \]
and this is $\Sigma$ because $\textrm{Ordinal}(\alpha)$ and $\textrm{1-1 onto}(f,\beta,\alpha)$ are both $\Sigma_0$.

Also, in Lemma 5.3, note why the choice of $q$ works. That is, when, for each $d\in F(c)$, we associate some

\subsection*{Lemma 5.4}
Here is why, in the second paragraph, we can conlclude that 
$p\vDash\Diamond\lbc\hat{\delta}\textrm{ is }f(\hat{\gamma})\rbc$ for some $\gamma\in\beta$. We know that 
$p\vDash\lbc(\exists y)(y\in\hat{\beta}\wedge\hat{\delta}\textrm{ is }f(y))\rbc$, meaning, at some world 
$p'$ accessible from $p$, there is some $d$ such that 
$p'\vDash\lbc d\in\hat{\beta}\rbc$ and $p'\vDash\lbc\hat{\delta}\textrm{ is }f(d)\rbc$. Because 
$p'\vDash\lbc d\in\hat{\beta}\rbc$, $p''\vDash\lbc d\approx e\rbc$ and $p''\vDash e\epsilon\hat{\beta}$. But this means 
$e$ is $\hat{\gamma}$ for some $\gamma\in\beta$. Also, $p''\vDash\lbc\hat{\delta}\textrm{ is }f(d)\rbc$, and 
by substitutivity, it follows that $p''\vDash\lbc\hat{\delta}\textrm{ is }f(\hat{\gamma})$. Thus, because $p\mathcal{R}p''$, 
$p\vDash\Diamond\lbc\hat{\delta}\textrm{ is }f(\hat{\gamma})\rbc$ for some $\gamma\in\beta$.

Note that, in general, it does not follow that, if $f\in\mathcal{D}^\mathcal{G}$, then $f=\hat{x}$ for some $x\in M$. This is because, 
if this were the case, $f$ would need to have ordered pairs of the form $\langle p,y\rangle$ (for some $y$) for every possible world 
$p$, and this certainly is not the case for all $f\in\mathcal{D}^\mathcal{G}$.

It should be noted why Lemma 5.4 does not immediately follow from Proposition 3.3 of the last chapter. For instance, one might argue that, 
by that result of the last chapter, $p\vDash\lbc\textrm{1-1 onto}(f,\hat{\beta},\hat{\alpha})\rbc$ would immediately imply 
$\textrm{1-1 onto}(f,\beta,\alpha)$ being true in $M$, a contradiction to the asusmption that $\beta<\alpha$. However, 
this cannot be concluded - to do that we would need to know that $f=\hat{x}$ for some $x\in M$, which we do not know.

\subsection*{Theorem 5.5}
Note why $p'\vDash\lbc b\in\hat{\alpha}\rbc$ implies 
$p''\vdash\lbc b\approx\hat{\beta}\rbc$ for some $p''$ with $p'\mathcal{R}p''$ and $\beta\in\alpha$. 
Because $p'\vDash\lbc b\in\hat{\alpha}\rbc$, $p''\vDash\lbc b\approx x\rbc$ and $p''\vDash\lbc x\in\hat{\alpha}\rbc$ for some 
$p''$ with $p'\mathcal{R}p''$. Then $x$ is some $\hat{\beta}$ for $\beta\in\alpha$, and thus $p''\vDash\lbc b\approx\hat{\beta}\rbc$.

There is an error in this proof. When the contradiction arises with $p''\vDash\lbc\textrm{1-1 onto}(f,\hat{\beta},\hat{\alpha})\rbc$, 
by using Lemma 5.4, this inference is not actually correct. For, it could be that $\beta$ is finite - yet Lemma 5.4 requires $\beta$ 
to be infinite.

\subsection*{Exercise 5.1}
We show that $\aleph_0\times\overline{\overline{A}}\ge\overline{\overline{\cup A}}$. By Lemma 5.3, 
$\aleph_0$ is an upper bound on the size for members of $A$. Then an upper bound on the size of 
$\overline{\overline{\cup A}}$ is obviously $\aleph_0\times\overline{\overline{A}}$ (because in the 
case of the upper bound, it could be 1-1 mapped onto $\aleph_0\times\overline{\overline{A}}$) from 
whence it follows that $\aleph_0\times\overline{\overline{A}}\ge\overline{\overline{\cup A}}$.
