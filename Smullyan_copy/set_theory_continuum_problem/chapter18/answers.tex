\subsection*{Lemma 2.2}
Here is why $\cup_{q_0\in\mathcal{G}}S(q_0)$ is an $M$-set (and hence so is $S$). Let 
$G(x,q)$ stand for the formula
\[ (\forall y\in x)(\textrm{Ordinal}(y)\wedge(\exists g\in R^\mathcal{G}_\beta)(q\vDash\lbc\hat{y}\approx g\rbc)) \]
(this can be expanded to a real first-order formula by results in the previous chapter).
If $S(q_0)$ happens to be in $M$, then $G(S(q_0),q_0)$ will be true in $M$. Now, we already know that each 
$S(q_0)\in M$. Then consider the following function which is definable over $M$:
\[ x\in\mathcal{G}\wedge G(y,x) \]
Because the domain, $\mathcal{G}$, is in $M$, so is the range, and because we have shown each $S(q_0)$ to be in $M$, the 
range is the set of all $S(q_0)$ (for $q_0\in\mathcal{G}$). Then the union of this, which is also in $M$, 
is just $S$ itself.

\subsection*{Lemma 5.4}
Here is why, in the second paragraph, we can conlclude that 
$p\vDash\Diamond\lbc\hat{\delta}\textrm{ is }f(\hat{\gamma})\rbc$ for some $\gamma\in\beta$. We know that 
$p\vDash\lbc(\exists y)(y\in\hat{\beta}\wedge\hat{\delta}\textrm{ is }f(y))\rbc$, meaning, at some world 
$p'$ accessible from $p$, there is some $d$ such that 
$p'\vDash\lbc d\in\hat{\beta}\rbc$ and $p'\vDash\lbc\hat{\delta}\textrm{ is }f(d)\rbc$. Because 
$p'\vDash\lbc d\in\hat{\beta}\rbc$, $p''\vDash\lbc d\approx e\rbc$ and $p''\vDash e\epsilon\hat{\beta}$ for some $p''$ with 
$p'\mathcal{R}p''$. But this means 
$e$ is $\hat{\gamma}$ for some $\gamma\in\beta$. Also, $p''\vDash\lbc\hat{\delta}\textrm{ is }f(d)\rbc$, and 
by substitutivity, it follows that $p''\vDash\lbc\hat{\delta}\textrm{ is }f(\hat{\gamma})\rbc$. Thus, because $p\mathcal{R}p''$, 
$p\vDash\Diamond\lbc\hat{\delta}\textrm{ is }f(\hat{\gamma})\rbc$ for some $\gamma\in\beta$.

Note that, in general, it does not follow that, if $f\in\mathcal{D}^\mathcal{G}$, then $f=\hat{x}$ for some $x\in M$. This is because, 
if this were the case, $f$ would need to have ordered pairs of the form $\langle p,y\rangle$ (for some $y$) for every possible world 
$p$, and this certainly is not the case for all $f\in\mathcal{D}^\mathcal{G}$.

It should be noted why Lemma 5.4 does not immediately follow from Proposition 3.3 of the last chapter. For instance, one might argue that, 
by that result of the last chapter, $p\vDash\lbc\textrm{1-1 onto}(f,\hat{\beta},\hat{\alpha})\rbc$ would immediately imply 
$\textrm{1-1 onto}(f,\beta,\alpha)$ being true in $M$, a contradiction to the asusmption that $\beta<\alpha$ and $\alpha$ is a cardinal. 
However, this cannot be concluded - to do that we would need to know that $f=\hat{x}$ for some $x\in M$, which we do not know.

\subsection*{Theorem 5.5}
Note why $p'\vDash\lbc b\in\hat{\alpha}\rbc$ implies 
$p''\vdash\lbc b\approx\hat{\beta}\rbc$ for some $p''$ with $p'\mathcal{R}p''$ and $\beta\in\alpha$. 
Because $p'\vDash\lbc b\in\hat{\alpha}\rbc$, $p''\vDash\lbc b\approx x\rbc$ and $p''\vDash\lbc x\epsilon\hat{\alpha}\rbc$ for some 
$p''$ with $p'\mathcal{R}p''$. Then $x$ is some $\hat{\beta}$ for $\beta\in\alpha$, and thus $p''\vDash\lbc b\approx\hat{\beta}\rbc$.

There is an error in this proof. When the contradiction arises with $p''\vDash\lbc\textrm{1-1 onto}(f,\hat{\beta},\hat{\alpha})\rbc$, 
by using Lemma 5.4, this inference is not actually correct. For, it could be that $\beta$ is finite - yet Lemma 5.4 requires $\beta$ 
to be infinite. Whether or not Lemma 5.4 can be proven if $\beta$ is finite is not fully clear to me - it depends upon what 
the relation \textquote{is} means, but this has not been defined. If we suppose that $p\vDash\lbc x\textrm{ is }y\rbc$ implies 
$p\vDash\lbc x\approx y\rbc$, then Lemma 5.4 certainly follows if $\beta$ is finite.

\begin{proof}
We show the result of Lemma 5.4, but in the case that $\beta$ is finite. This is actually really easy - we don't even need to 
define the function $F$. We aim to derive a contradiction by showing that $\beta$ cannot $n$ elements for any finite $n$.
Suppose that $\beta$ contained $n$ elements. Because $\alpha$ is infinite, we can choose $n+1$ (distinct) elements from it, 
say $a_1,...,a_n,a_{n+1}$. Because $p\vDash\lbc\textrm{1-1 onto}(f,\hat{\beta},\hat{\alpha})\rbc$, we know that 
$p\vDash\lbc(\hat{a_i}\in\hat{\alpha}\supset(\exists y)(y\in\hat{\beta}\wedge\hat{a_i}\textrm{ is }f(y)))\rbc$ for 
each $a_i$ (for $i\le n+1$). It can easily
be seen (by induction on $n$) that this means there exist $c_1,c_2,...,c_n,c_{n+1}\in\beta$ and some 
$p'$ with $p\mathcal{R}p'$ such that $p'\vDash\lbc\hat{c_i}\in\hat{\beta}\rbc$ and 
$p'\vDash\lbc\hat{a_i}\textrm{ is }f(\hat{c_i})\rbc$ (for each $i\le n+1$). Because 
$\beta$ was assumed to have only $n$ members, it must be that $c_i=c_j$ for some 
$i$ and $j$. Then $p'\vDash\lbc\hat{c_i}\approx\hat{c_j}\rbc$, meaning 
$p'\vDash\lbc f(\hat{c_i)}\approx f(\hat{c_j})\rbc$ (because $c_i=c_j\supset f(c_i)=f(c_j)$ is true over $M$). Because we have 
both $p'\vDash\lbc \hat{a_i}\textrm{ is }f(\hat{c_i})\rbc$ and
$p'\vDash\lbc\hat{a_j}\textrm{ is }f(\hat{c_j})\rbc$, and we are assuming
$p'\vDash\lbc x\textrm{ is }y\rbc$ implies $p'\vDash\lbc x\approx y\rbc$ (we are assuming that this is 
what \textquote{is} means), it follows by transitivity that 
$p'\vDash\lbc\hat{a_i}\approx\hat{a_j}\rbc$, meaning $p'\vDash\lbc\hat{a_i}=\hat{a_j}\rbc$. This 
means $a_i=a_j$, contrary to the assumption that $a_i$ and $a_j$ are distinct. 

Thus, no matter what size $\beta$ is (assuming $\beta$ is finite), assuming 
$p\vDash\lbc\textrm{1-1 onto}(f,\hat{\beta},\hat{\alpha})\rbc$ led to a contradiction, therefore completing the proof.
\end{proof}

\subsection*{Lemma 6.1}
Note that, if $p\vDash\lbc x\approx x'\rbc$, it follows that 
$p\vDash\lbc x=x'\rbc$ (we prove this below). This explains why $\gamma_1\ne\gamma_2$ implies 
$\lbc\oldneg(\hat{\gamma_1}\approx\hat{\gamma_2})\rbc$ being valid in the $S4$ model. 

\begin{proof}
We prove that, if $p\vDash\lbc f\approx f'\rbc$ (for some $f,f'\in\mathcal{D}^\mathcal{G}$), then 
$p\vDash\lbc f=f'\rbc$. But suppose not. That is, $p\nvDash\lbc f=f'\rbc$. Then either 
(1) $p\nvDash\lbc(\forall x)(x\in f\supset x\in f')\rbc$ or $p\nvDash\lbc(\forall x)(x\in f'\supset x\in f)\rbc$. Without 
loss of generality, suppose that it is the former case. Now, because $p\vDash\lbc f\approx f'\rbc$, we know that 
(2) $p\vDash\lbc(\forall x)[(x\epsilon f)\supset(\exists y)(y\epsilon f'\wedge y\approx x)]\rbc$ (by Proposition 2.12 
of Chapter 17). By (1), there is some $d$ and some $p'$ with $p\mathcal{R}p'$ such that
$p'\vDash\lbc d\in f\rbc$ and $p'\vDash\lbc\oldneg(d\in f')\rbc$. We derive a contradiction by showing that 
$p'\vDash\lbc d\in f'\rbc$. We do this by showing $p'\vDash\Box\Diamond(d\in f')$.

Consider any $p''$ with $p'\mathcal{R}p''$. Because $p'\vDash\lbc d\in f\rbc$, there is some 
$p'''$ with $p''\mathcal{R}p'''$ and some $b$ such that 
$p'''\vDash\lbc b\epsilon f\rbc$ and $p'''\vDash\lbc d\approx b\rbc$.
By (2), it follows that there is some $c$ and some $q$ with $p'''\mathcal{R}q$ such that 
$q\vDash\lbc c\epsilon f'\rbc$ and $q\vDash\lbc c\approx b\rbc$. Because $p'''\mathcal{R}q$, 
$q\vDash\lbc d\approx b\rbc$, meaning, by transitivity, 
$q\vDash\lbc d\approx c\rbc$, and thus, by definition of $\in$, $q\vDash d\in f'$. Hence, because 
$p''\mathcal{R}q$, $p''\vDash\Diamond(d\in f')$. Because $p''$ was arbitrary, it follows that
$p'\vDash\Box\Diamond(d\in f')$, that is, 
$p'\vDash\lbc(d\in f')\rbc$, a contradiction.
\end{proof}
