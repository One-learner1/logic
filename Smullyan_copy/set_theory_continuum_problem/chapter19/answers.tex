\subsection*{Notes}
For the model in this section to work, we need $\omega_2\in M$. However, it is not clear to my why this is.

If we assume that $\omega_2\in M$, here is why $\langle\mathcal{G},\mathcal{R}\rangle$ is an $M$-set. It 
is easy to see that each particular forcing condition is in $M$ - each particular one can be explicitly defined, 
as it is assumed that $p(\alpha)=\langle\emptyset,\emptyset\rangle$ for all but a finite number of $\alpha\in\omega_2$. 
The set $\mathcal{G}$ of all forcing conditions is a subset of 
$\mathcal{P}(\mathcal{P}(\omega_2\times(\mathcal{P}(\omega\times\omega)\cap M))\cap M)\cap M$, which is in $M$.
$\mathcal{G}$ is also easily seen to be definable over $M$, and consequently, $\mathcal{G}\in M$. Then 
$\mathcal{R}$ is also easily seen to be in $M$, as it is definable over $M$, and is a subset of $\mathcal{G}\times\mathcal{G}$, which 
is in $M$ (as we have shown $\mathcal{G}$ to be in $M$).

\subsection*{Exercise 2.1}
This is basically the same proof as that of Theorem 4.1 of Chapter 18.

\begin{proof}

We prove that, for each $\alpha\in\omega_2$, $\lbc\oldneg\textrm{Const}(f_\alpha)\rbc$ is valid in the model
$M$. Suppose, to the contrary, that $p\nvDash\lbc\oldneg\textrm{Const}(f_\alpha)\rbc$ for some $p$. 
Then for some $p'$ with $p\mathcal{R}p'$, $p'\vDash\lbc\textrm{Const}(f_\alpha)\rbc$. By Theorem 3.2 of 
Chapter 18, it follows that $p\vDash\Diamond\lbc f_\alpha\approx\hat{c}\rbc$ for some contrsuctible set $c\in M$.
This means that, for some $r$ with $p'\mathcal{R}r$, $r\vDash\lbc f_\alpha\approx\hat{c}\rbc$. We derive a 
contradiction from this. $r$ is some forcing condition, so 
suppose that $r(\alpha)=\langle P,N\rangle$. There are then two cases.

Case 1) $c\subseteq P$. Because both $P$ and $N$ are finite, we can pick some integer $n$ 
such that $n\notin P\cup N$ (thus also $n\notin c$). Let $P'=P\cup\{n\}$. Then there is some 
forcing condition $q$ such that, for all $\beta\in\omega_2$, if $\beta\ne\alpha$, then 
$q(\beta)=r(\beta)$, and if $\beta=\alpha$, then $q(\beta)=\langle P',N\rangle$. Obviously 
$r\mathcal{R}q$. Because $c\in P'$, it follows that 
$q\vDash\lbc\hat{n}\in f_\alpha\rbc$. But because $n\notin c$, $q\vDash\lbc\oldneg(\hat{n}\in\hat{c})\rbc$. 
These two things jointly imply $q\nvDash\lbc f_\alpha\approx\hat{c}\rbc$. But 
also $q\vDash\lbc f_\alpha\approx\hat{c}\rbc$, as $r\vDash\lbc f_\alpha\approx\hat{c}\rbc$ and 
$r\mathcal{R}q$. Thus we have our contradiction in this case.

Case 2) $c\nsubseteq P$. Pick some $n$ in $c$ but not in $P$. Let $N'=N\cup\{n\}$. 
Then there is some forcing condition $q$ such that, for all $\beta\in\omega_2$, if 
$\beta\ne\alpha$, then $q(\beta)=r(\beta)$, and if $\beta=\alpha$, then $q(\beta)=\langle P,N'\rangle$. Obviously 
$r\mathcal{R}q$. Because $n\in c$, it follows that 
$q\vDash\lbc\hat{n}\in\hat{c}\rbc$. But because $n\in N'$, it follows that $q\vDash\lbc\oldneg(\hat{n}\in f_\alpha)\rbc$ (Reason: 
Suppose, for some $q'$ with $q\mathcal{R}q'$, that $q'\vDash\hat{n}\in f_\alpha$. Then for some 
$x$, $q'\vDash\lbc x\epsilon f_\alpha\rbc$ and $q'\vDash\lbc x\approx\hat{n}\rbc$. This means 
$x$ is $\hat{a}$ for some $a$, and thus, by Lemma 3.2 of Chapter 17, $a$ and $n$ are the same set. But 
this means $q'\vDash\lbc\hat{n}\epsilon f_\alpha\rbc$, which cannot happen, as $n\in N'$). These 
two things imply that $q\nvDash\lbc f_\alpha\approx\hat{c}\rbc$. But also $q\vDash\lbc f_\alpha\approx\hat{c}\rbc$ (for the 
same reason as in the first case), which is our contradiction.

\end{proof}

\section*{Section 3}

\subsection*{Exercise 3.1}
We prove that $\lbc f:\hat{\omega}\xrightarrow[\textrm{onto}]{\text{1-1}}\hat{\omega_2}\rbc$ is 
valid in the described $S4$-regular model described. Consider any artibrary world $p$. It suffices to show that 
the following four things hold:
\[\textrm{(1) }p\vDash\lbc(\forall x)(\forall y)(\forall z)((\langle x,y\rangle\in f\wedge\langle x,z\rangle\in f)\supset y=z)\rbc \]
(this is the translate of the formula saying $f$ is a function)
\[\textrm{(2) }p\vDash\lbc(\forall x)(\forall y)(\forall z)((\langle x,z\rangle\in f\wedge\langle y,z\rangle\in f)\supset x=y)\rbc \]
(this is the translate of the formula saying that $f$ is 1-1)
\[\textrm{(3) }p\vDash\lbc(\forall x)(x\in\hat{\omega}\supset(\exists y)(y\in\hat{\omega_2}\wedge\langle x,y\rangle\in f))\rbc \]
(this is the translate of the formula which says that, for each $y\in\omega$, there is some $x\in\omega_2$ such that 
$f(x)=y$)
\[\textrm{(4) }p\vDash\lbc(\forall x)(x\in\hat{\omega_2}\supset(\exists y)(y\in\hat{\omega}\wedge\langle x,y\rangle\in f))\rbc \]
(this is the translate of the formula which says that, for each $x\in\omega_2$, there is some $y\in\omega$ such that 
$f(x)=y$)

(1) We first show that formula (1) is true at $p$. It suffices to consider any $a,b,c$, and show that
$p\vDash\lbc((\langle a,b\rangle\in f\wedge\langle a,c\rangle\in f)\supset b=c)\rbc$. Suppose, on the contrary, that 
$p\nvDash\lbc((\langle a,b\rangle\in f\wedge\langle a,c\rangle\in f)\supset b=c)\rbc$. Then, for some $q$ with 
$p\mathcal{R}q$, $q\vDash\lbc\langle a,b\rangle\in f\rbc$, $q\vDash\lbc\langle a,c\rangle\in f\rbc$, 
and $q\vDash\lbc\oldneg (b=c)\rbc$. Because $q\vDash\lbc\langle a,b\rangle\in f\rbc$, it follows that for some 
$g$ and some $q'$ with $q\mathcal{R}q'$, $q'\vDash\lbc\langle a,b\rangle\approx g\rangle$, 
$q'\vDash\lbc\langle g\epsilon f\rangle\rbc$. Then it is easily seen that $g=\widehat{\langle n,\alpha\rangle}$ for 
some $n$ and $\alpha$. Because $q\vDash\lbc\langle a,c\rangle\in f\rbc$ (and hence also $q'\vDash\lbc a,c\rangle\in f\rbc$), 
similar reasoning will yield $q''\vDash\lbc\langle a,c\rangle\approx\widehat{\langle m,\beta\rangle}\rbc$ and 
$q''\vDash\lbc\widehat{\langle m,\beta\rangle}\epsilon f\rbc$ for some $q''$ with $q'\mathcal{R}q''$ and some 
$m$ and $\beta$. From this it easily follows that $q''\vDash\lbc\hat{n}\approx\hat{m}\rbc$. This is because 
$(\forall x)(\forall y)((\langle x,y\rangle=\langle a,b\rangle)\supset x=a)$ is classically true in $M$, hence its translate is valid 
in the model. Then we can use this translate twice to get both $q''\vDash\lbc a\approx\hat{n}\rbc$ and 
$q''\vDash\lbc a\approx\hat{m}\rbc$, from which it follows that $q''\vDash\lbc\hat{m}=\hat{n}\rbc$. Similar reasoning shows that 
$q''\vDash\lbc\hat{\alpha}\approx b\rbc$, and $q''\vDash\lbc\hat{\beta}\approx c\rbc$. 
Then it follows (by Lemma 3.2 of Chapter 17) that $n$ and $m$ are the same set. 
Thus both $q''\vDash\lbc\widehat{\langle n,\alpha\rangle}\epsilon f\rbc$ and 
$q''\vDash\lbc\widehat{\langle n,\beta\rangle}\epsilon f\rbc$, which can easily be seen to imply 
$r\vDash\widehat{\langle n,\beta\rangle}\epsilon f$ and $s\vDash\widehat{\langle n,\alpha\rangle}\epsilon f$ 
for some $r$ and $s$ with $r\mathcal{R}s$. But, by the definition of the accessibility relation, 
$s$ is an extension of $r$. Also, by the definition of $f$, $n\in\textrm{Dom}(r)$ and 
$r(n)=\alpha$. Because $s$ is an extension of $r$, and $n\in\textrm{Dom}(s)$, it follows that 
$s(n)=\beta=\alpha$. Thus $\alpha=\beta$, meaning $q''\vDash\lbc\hat{\alpha}=\hat{\beta}\rbc$, meaning 
$q''\vDash\lbc\hat{\alpha}\approx\hat{\beta}\rbc$. This implies $q''\vDash\lbc b\approx c\rbc$, that is, 
$q''\vDash\lbc b=c\rbc$. But we also have 
$q\vDash\lbc\oldneg (b=c)\rbc$ (by assumption), hence also $q''\vDash\lbc\oldneg (b=c)\rbc$, a contradiction.

(2) Now we move on to showing that formula (2) is true at $p$. It suffices to consider any $a,b,c$, and show that
$p\vDash\lbc((\langle a,c\rangle\in f\wedge\langle b,c\rangle\in f)\supset a=b)\rbc$. Suppose, on the contrary, that 
$p\nvDash\lbc((\langle a,c\rangle\in f\wedge\langle b,c\rangle\in f)\supset a=b)\rbc$. Then, for some $q$ with 
$p\mathcal{R}q$, $q\vDash\lbc\langle a,c\rangle\in f\rbc$, $q\vDash\lbc\langle b,c\rangle\in f\rbc$, 
and $q\vDash\lbc\oldneg(a=b)\rbc$. Using near identical reasoning as in part (1) of this proof, it follows that for 
some $r$ with $q\mathcal{R}r$ and some $s$ with $r\mathcal{R}s$, $r\vDash\widehat{\langle n,\alpha\rangle}\epsilon f$ and 
$s\vDash\widehat{\langle m,\alpha\rangle }\epsilon f$ for some $n,m$, and $\alpha$, where 
$r\vDash\lbc a\approx\hat{n}\rbc$ and $r\vDash\lbc b\approx\hat{m}\rbc$. Because 
$r\vDash\widehat{\langle n,\alpha\rangle}\epsilon f$, it follows, by the definition of $f$, that 
$n\in\textrm{Dom}(r)$ and $r(n)=\alpha$. Similarly, 
$n\in\textrm{Dom}(s)$ and $s(m)=\alpha$. But $s$ is an extension of $r$, and because 
both $r$ and $s$ are 1-1 (all forcing conditions under consideration here are 1-1 functions), 
it follows that $n=m$. Hence $r\vDash\lbc\hat{n}=\hat{m}\rbc$, implying $r\vDash\lbc\hat{n}\approx\hat{m}\rbc$. Because 
$r\vDash\lbc a\approx\hat{n}\rbc$ and $r\vDash\lbc b\approx\hat{m}\rbc$, it then follows that 
$r\vDash\lbc a\approx b\rbc$, that is, $r\vDash\lbc a=b\rbc$. But 
$q\vDash\lbc\oldneg(a=b)\rbc$, meaning $r\vDash\lbc\oldneg(a=b)\rbc$, which is a contradiction.
