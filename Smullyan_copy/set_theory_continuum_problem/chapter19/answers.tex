\section*{Sections 3 and 4}
There are multiple issues with these two sections. First, Exercise 3.1, with the given definition of $f$, is simply incorrect. Second, 
the definition of $F$ in section 4 is incorrect. However, both of these issues can be fixed by altering the definitions.

First, in order to fix Exercise 3.1, the definition of $f$ needs to be altered to: $p\vDash\textrm{Op}(\hat{n},\hat{\alpha})\epsilon f$ 
iff $n\in\textrm{Dom}(p)$ and $p(n)=\alpha$. This is shown to fix the problem in the succeeding section of these notes, titled 
\textquote{Section 3}. The problem of the given definition 
lies in the fact that, if we were to show that 
$\lbc f:\hat{\omega}\xrightarrow[\textrm{onto}]{\text{1-1}}\hat{\omega_2}\rbc$ is valid
over $\mathcal{M}$, we would need to show that
\[\textrm{(3) }p\vDash\lbc(\forall x)(x\in\hat{\omega}\supset(\exists y)(y\in\widehat{\omega_2}\wedge\langle x,y\rangle\in f))\rbc \]
But the $\langle x,y\rangle\in f$ is the problem: we only have 
$p\vDash\widehat{\langle n,\alpha\rangle}\epsilon f$, and $\widehat{\langle n,\alpha\rangle}$ does not act like an ordered pair ($p$, 
nor any other world, for that matter, necesarily thinks it does). This is we why instead use 
$p\vDash\textrm{Op}(\hat{n},\hat{\alpha})\epsilon f$. This works, as $p$ (and any other world, for that matter), 
thinks that $\textrm{Op}(\hat{n},\hat{\alpha})$ is an ordered pair (this will be shown below).

Second, the $F$ in section 4 has an incorrect definition. $F$ as currently defined isn't even a member of $\mathcal{D}^\mathcal{G}$, let alone 
$R^\mathcal{G}_{\omega_2+3}$. In order to fix this, change the definition of $F$ to the following:
\[ F=\{\langle p,\textrm{Op}(\hat{\alpha},f_\alpha)\rangle|p\in\mathcal{G},\alpha\in\omega_2\} \]

In order to show why these two fixes actually work, we prove some preliminary results. The main thing we need to show is that for 
any $f,g\in\mathcal{D}^\mathcal{G}$, $\lbc\langle f,g\rangle =\textrm{Op}(f,g)\rbc$ is valid over the model. This is just an 
abbreviation for:
\[ \lbc (\forall x)(x\in\textrm{Op}(f,g)\equiv (x=\{f\}\vee x=\{f,g\}))\rbc \]
which is in turn an abbreviation for:
\[ \lbc(\forall x)(x\in\textrm{Op}(f,g)\equiv[(\forall z)(z\in x\equiv z=f)\vee(\forall z)(z\in x\equiv (z=f\vee z=g))])\rbc \] 
Proving this would establish that all possible worlds think $\textrm{Op}(x,y)$ is just $\langle x,y\rangle$.

First, here is a starter result (though not actually necessary for the proof). We prove that 
if $\textrm{Op}(a,b)=\textrm{Op}(c,d)$, then $a=c$ and $b=d$.

\begin{proof}
Suppose $\textrm{Op}(a,b)=\textrm{Op}(c,d)$. For simplicity's sake, let $S_1=\mathcal{G}\times\{a\}$, 
$S_2=\mathcal{G}\times\{a,b\}$, $S_3=\mathcal{G}\times\{c\}$ and $S_4=\mathcal{G}\times\{c,d\}$. Then 
$\textrm{Up}(a,a)=S_1$, $\textrm{Up}(a,b)=S_2$, $\textrm{Up}(c,c)=S_3$ and $\textrm{Up}(c,d)=S_4$.
Also, $\textrm{Op}(a,b)=\textrm{Up}(S_1,S_2)=\mathcal{G}\times\{S_1,S_2\}$ and 
$\textrm{Op}(c,d)=\textrm{Up}(S_3,S_4)=\mathcal{G}\times\{S_3,S_4\}$.

Because $\mathcal{G}\times\{S_1,S_2\}=\mathcal{G}\times\{S_3,S_4\}$, it 
follows that either $S_1=S_3$ or $S_1=S_4$, and either $S_2=S_4$ or $S_2=S_3$. 

Suppose, on the one hand, that $S_1=S_3$. Then $a=c$. If $S_2\ne S_4$, then 
$S_2=S_3$ and $S_4=S_1$, and then $a=b=c=d$. If $S_2=S_4$, then 
either $b=d$ or $b=a$, and either $d=a$ or $d=b$; these two things obviously imply $b=d$. Hence we have both 
$a=c$ and $b=d$, and this completes the proof in this case.

On the other hand, suppose that $S_1=S_4$. Then $a=c=d$. If $S_2=S_3$, then 
$b=c=d$, and we are done. If $S_2=S_4$, then, because $c=d$, $b=d$ also follows easily. Hence we also 
have $a=c$ and $b=d$ in this case, therefore completing the proof.

\end{proof}

\begin{lemma}
\[ \lbc(\forall x)[x\in\textrm{Up}(f,g)\equiv (x\approx f\vee x\approx g)]\rbc \]
is valid in $\mathcal{M}$ (this is just Exercise 4.1).
\end{lemma}

\begin{proof}
Suppose that $p\nvDash\lbc(\forall x)[x\in\textrm{Up}(f,g)\equiv (x\approx f\vee x\approx g)]\rbc$ for some $p$. We 
derive a contradiction. There must be some $d$ such that 
$p\nvDash\lbc[d\in\textrm{Up}(f,g)\equiv (d\approx f\vee d\approx g)]\rbc$. There are then two cases.

Case 1) $p\nvDash\lbc[d\in\textrm{Up}(f,g)\supset (d\approx f\vee d\approx g)]\rbc$. Then it follows that 
for some $p'$ with $p\mathcal{R}p'$, 
$p'\vDash\lbc d\in\textrm{Up}(f,g)\rbc$ and $p'\vDash\lbc\oldneg(d\approx f\vee d\approx g)\rbc$. Because 
$p'\vDash\lbc d\in\textrm{Up}(f,g)\rbc$, $p''\vDash\lbc d\approx c\rbc$ and $p''\vDash\lbc c\epsilon\textrm{Up}(f,g)\rbc$ 
for some $c$ and some $p''$ with $p'\mathcal{R}p''$. But by the definition of $\textrm{Up}(f,g)$, it easily follows that 
$p''\vDash\lbc c\epsilon\textrm{Up}(f,g)\rbc$ implies either $c=f$ or $c=g$. Thus either 
$p''\vDash\lbc d\approx f\rbc$ or $p''\vDash\lbc d\approx g\rbc$, meaning
$p''\vDash\lbc (d\approx f\vee d\approx g)\rbc$, contradicting the assumption that 
$p''\vDash\lbc\oldneg(d\approx f\vee d\approx g)\rbc$.

Case 2) $p\nvDash\lbc[(d\approx f\vee d\approx g)\supset d\in\textrm{Up}(f,g)]\rbc$. Then it follows that 
for some $p'$ with $p\mathcal{R}p'$,
$p'\vDash\lbc (d\approx f\vee d\approx g)\rbc$ and $p'\vDash\lbc\oldneg (d\in\textrm{Up}(f,g))\rbc$. 
Because $p'\vDash\lbc (d\approx f\vee d\approx g)\rbc$, there is some $p''$ with $p'\mathcal{R}p''$ such that 
at least one of $p''\lbc d\approx f\rbc$ or $p''\lbc d\approx g\rbc$ is true at $p''$. Suppose, without loss of generality, that the 
former is true, that is, $p''\vDash\lbc d\approx f\rbc$. Now, $p''\vDash\lbc f\epsilon\textrm{Up}(f,g)\rbc$ can easily be seen to be 
true. This means that $p''\vDash\lbc d\in\textrm{Up}(f,g)\rbc$. But this contradicts the assumption that 
$p''\vDash\lbc\oldneg (d\in\textrm{Up}(f,g))\rbc$.

\end{proof}

Now we prove the main preliminary result.

\begin{theorem}
\[ \lbc(\forall x)(x\in\textrm{Op}(f,g)\equiv[(\forall z)(z\in x\equiv z=f)\vee(\forall z)(z\in x\equiv (z=f\vee z=g))])\rbc \]
is valid over $\mathcal{M}$.
\end{theorem}

\begin{proof}
Suppose that
\[ p\nvDash\lbc(\forall x)(x\in\textrm{Op}(f,g)\equiv[(\forall z)(z\in x\equiv z=f)\vee(\forall z)(z\in x\equiv (z=f\vee z=g))])\rbc \]
We derive a contradiction. There must be some $d$ such that 
\[ p\nvDash\lbc(d\in\textrm{Op}(f,g)\equiv[(\forall z)(z\in x\equiv z=f)\vee(\forall z)(z\in x\equiv (z=f\vee z=g))])\rbc \]
There are then two cases.

Case 1) \[ p\nvDash\lbc(d\in\textrm{Op}(f,g)\supset[(\forall z)(z\in d\equiv z=f)\vee(\forall z)(z\in d\equiv (z=f\vee z=g))])\rbc \]
Then there is some $p'$ with $p\mathcal{R}p'$ such that 
$p'\vDash\lbc (d\in\textrm{Op}(f,g))\rbc$ and $p'\vDash\lbc\oldneg[(\forall z)(z\in d\equiv z=f)\vee(\forall z)(z\in d\equiv (z=f\vee z=g))]\rbc$.
Because $p'\vDash\lbc (d\in\textrm{Op}(f,g))\rbc$, it follows, by the above lemma and the definition of 
$\textrm{Op}(f,g)$, that either (1) $p'\vDash\lbc d\approx\textrm{Up}(f,f)\rbc$ or 
(2) $p'\vDash\lbc d\approx\textrm{Up}(f,g)\rbc$. Also, by the above lemma, we know that both 
$p'\vDash\lbc (\forall z)(z\in\textrm{Up}(f,f)\equiv x=f)\rbc$ and 
$p'\vDash\lbc (\forall z)(z\in\textrm{Up}(f,g)\equiv (x=f\vee x=g))\rbc$. These two things imply that, whether (1) or (2) holds,
$p'\vDash\lbc [(\forall z)(z\in d\equiv z=f)\vee(\forall z)(z\in d\equiv (z=f\vee z=g))]\rbc$ must hold, a contradiction to the assumption that 
$p'\vDash\lbc\oldneg[(\forall z)(z\in d\equiv z=f)\vee(\forall z)(z\in d\equiv (z=f\vee z=g))]\rbc$. 

Case 2) \[ p\nvDash\lbc[(\forall z)(z\in d\equiv z=f)\vee(\forall z)(z\in d\equiv (z=f\vee z=g))]\supset d\in\textrm{Op}(f,g))\rbc \] 
Then there is some $p'$ with $p\mathcal{R}p'$ such that
(1) $p'\vDash\lbc [(\forall z)(z\in d\equiv z=f)\vee(\forall z)(z\in d\equiv (z=f\vee z=g))]\rbc$ and 
$p'\vDash\lbc\oldneg d\in\textrm{Op}(f,g)\rbc$. By (1), there is some $p''$ with $p'\mathcal{R}p''$ such that at least one of 
$p''\vDash\lbc(\forall z)(z\in d\equiv z=f)\rbc$ and $p''\vDash\lbc(\forall z)(z\in d\equiv(z=f\vee z=g))\rbc$ hold. Suppose, without loss of generality, that 
the former holds, that is, $p''\vDash\lbc(\forall z)(z\in d\equiv z=f)\rbc$. Then, by the above lemma, it easily follows that 
$p''\vDash\lbc d=\textrm{Op}(f,f)\rbc$. Again by the above lemma, it follows that 
$p''\vDash\lbc (\forall x)[x\in\textrm{Op}(f,g)\equiv (x\approx\textrm{Up}(f,f)\vee x\approx\textrm{Up}(f,g))]\rbc$, and this can easily be seen to imply 
that $p''\vDash\lbc (d\in\textrm{Op}(f,g)\rbc$. But this contradicts the assumption that $p'\vDash\lbc\oldneg(d\in\textrm{Up}(f,g))\rbc$
(and hence also $p''\vDash\lbc\oldneg(d\in\textrm{Up}(f,g))\rbc$).

\end{proof}

\subsection*{Exercise 3.1}
We prove that $\lbc f:\hat{\omega}\xrightarrow[\textrm{onto}]{\text{1-1}}\hat{\omega_2}\rbc$ is 
valid in the described $S4$-regular model described. Consider any artibrary world $p$. It suffices to show that

\[\textrm{(1) }p\vDash\lbc(\forall x)(\forall y)(\forall z)((\langle x,y\rangle\in f\wedge\langle x,z\rangle\in f)\supset y=z)\rbc \]
(this is the translate of the formula saying $f$ is a function)
\[\textrm{(2) }p\vDash\lbc(\forall x)(\forall y)(\forall z)((\langle x,z\rangle\in f\wedge\langle y,z\rangle\in f)\supset x=y)\rbc \]
(this is the translate of the formula saying that $f$ is 1-1)
\[\textrm{(3) }p\vDash\lbc(\forall x)(x\in\hat{\omega}\supset(\exists y)(y\in\widehat{\omega_2}\wedge\langle x,y\rangle\in f))\rbc \]
(this is the translate of the formula which says that, for each $y\in\omega$, there is some $x\in\omega_2$ such that 
$f(x)=y$)
\[\textrm{(4) }p\vDash\lbc(\forall x)(x\in\widehat{\omega_2}\supset(\exists y)(y\in\hat{\omega}\wedge\langle y,x\rangle\in f))\rbc \]
(this is the translate of the formula which says that, for each $x\in\omega_2$, there is some $y\in\omega$ such that 
$f(y)=x$)

(1) We first show that (1) holds. It suffices to consider any $a,b,c$, and show that
$p\vDash\lbc((\langle a,b\rangle\in f\wedge\langle a,c\rangle\in f)\supset b=c)\rbc$. Suppose, on the contrary, that 
$p\nvDash\lbc((\langle a,b\rangle\in f\wedge\langle a,c\rangle\in f)\supset b=c)\rbc$. Then, for some $q$ with 
$p\mathcal{R}q$, $q\vDash\lbc\langle a,b\rangle\in f\rbc$, $q\vDash\lbc\langle a,c\rangle\in f\rbc$, 
and $q\vDash\lbc\oldneg (b=c)\rbc$. Because $q\vDash\lbc\langle a,b\rangle\in f\rbc$, it follows that for some 
$g$ and some $q'$ with $q\mathcal{R}q'$, $q'\vDash\lbc\langle a,b\rangle\approx g\rbc$ and 
$q'\vDash\lbc g\epsilon f\rbc$. Then it is easily seen that $g=\textrm{Op}(\hat{n},\hat{\alpha})$ for 
some $n$ and $\alpha$. Because $q\vDash\lbc\langle a,c\rangle\in f\rbc$ (and hence also $q'\vDash\lbc\langle a,c\rangle\in f\rbc$), 
similar reasoning will yield $q''\vDash\lbc\langle a,c\rangle\approx\textrm{Op}(\hat{m},\hat{\beta})\rbc$ and 
$q''\vDash\lbc\textrm{Op}(\hat{m},\hat{\beta})\epsilon f\rbc$ for some $q''$ with $q'\mathcal{R}q''$ and some 
$m$ and $\beta$. From this it can easily be seen to follow that $q''\vDash\lbc\hat{n}\approx\hat{m}\rbc$ (because, for all 
$v$ and $w$, $\textrm{Op}(v,w)$ is thought to be $\langle v,w\rangle$ at every possible world of the model).
Then it follows (by Lemma 3.2 of Chapter 17) that $n$ and $m$ are the same set. 
Thus both $q''\vDash\lbc\textrm{Op}(\hat{n},\hat{\alpha})\epsilon f\rbc$ and 
$q''\vDash\lbc\textrm{Op}(\hat{n},\hat{\beta})\epsilon f\rbc$, which can easily be seen to imply 
$r\vDash\textrm{Op}(\hat{n},\hat{\beta})\epsilon f$ and $s\vDash\textrm{Op}(\hat{n},\hat{\alpha})\epsilon f$ 
for some $r$ and $s$ with $r\mathcal{R}s$. But, by the definition of the accessibility relation, 
$s$ is an extension of $r$. Also, by the definition of $f$, $n\in\textrm{Dom}(r)$ and 
$r(n)=\alpha$. Because $s$ is an extension of $r$, and $n\in\textrm{Dom}(s)$, it follows that 
$s(n)=\beta=\alpha$. Thus $\alpha=\beta$, meaning $q''\vDash\lbc\hat{\alpha}=\hat{\beta}\rbc$, meaning 
$q''\vDash\lbc\hat{\alpha}\approx\hat{\beta}\rbc$. This implies $q''\vDash\lbc b\approx c\rbc$, that is, 
$q''\vDash\lbc b=c\rbc$. But we also have 
$q\vDash\lbc\oldneg (b=c)\rbc$ (by assumption), hence also $q''\vDash\lbc\oldneg (b=c)\rbc$, a contradiction.

(2) Now we move on to showing that (2) holds. It suffices to consider any $a,b,c$, and show that
$p\vDash\lbc((\langle a,c\rangle\in f\wedge\langle b,c\rangle\in f)\supset a=b)\rbc$. Suppose, on the contrary, that 
$p\nvDash\lbc((\langle a,c\rangle\in f\wedge\langle b,c\rangle\in f)\supset a=b)\rbc$. Then, for some $q$ with 
$p\mathcal{R}q$, $q\vDash\lbc\langle a,c\rangle\in f\rbc$, $q\vDash\lbc\langle b,c\rangle\in f\rbc$, 
and $q\vDash\lbc\oldneg(a=b)\rbc$. Using near identical reasoning as in part (1) of this proof, it follows that for 
some $r$ with $q\mathcal{R}r$ and some $s$ with $r\mathcal{R}s$, $r\vDash\textrm{Op}(\hat{n},\hat{\alpha})\epsilon f$ and 
$s\vDash\textrm{Op}(\hat{m},\hat{\alpha})\epsilon f$ for some $n,m$, and $\alpha$, where 
$r\vDash\lbc a\approx\hat{n}\rbc$ and $r\vDash\lbc b\approx\hat{m}\rbc$. Because 
$r\vDash\textrm{Op}(\hat{n},\hat{\alpha})\epsilon f$, it follows, by the definition of $f$, that 
$n\in\textrm{Dom}(r)$ and $r(n)=\alpha$. Similarly, 
$n\in\textrm{Dom}(s)$ and $s(m)=\alpha$. But $s$ is an extension of $r$, and because 
both $r$ and $s$ are 1-1 (all forcing conditions under consideration here are 1-1 functions), 
it follows that $n=m$. Hence $r\vDash\lbc\hat{n}=\hat{m}\rbc$, implying $r\vDash\lbc\hat{n}\approx\hat{m}\rbc$. Because 
$r\vDash\lbc a\approx\hat{n}\rbc$ and $r\vDash\lbc b\approx\hat{m}\rbc$, it then follows that 
$r\vDash\lbc a\approx b\rbc$, that is, $r\vDash\lbc a=b\rbc$. But 
$q\vDash\lbc\oldneg(a=b)\rbc$, meaning $r\vDash\lbc\oldneg(a=b)\rbc$, which is a contradiction.

(3) Next, we show that (3) holds. It suffices to consider any $a$, and show that 
$p\vDash\lbc(a\in\hat{\omega}\supset(\exists y)(y\in\widehat{\omega_2}\wedge\langle x,y\rangle\in f))\rbc$. Suppose, on the 
contrary, that $p\nvDash\lbc(a\in\hat{\omega}\supset(\exists y)(y\in\widehat{\omega_2}\wedge\langle a,y\rangle\in f))\rbc$. Then it 
follows that, for some $q$ with $p\mathcal{R}q$, $q\vDash\lbc(a\in\hat{\omega})\rbc$ and 
$q\vDash\lbc\oldneg(\exists y)(y\in\widehat{\omega_2}\wedge\langle a,y\rangle\in f)\rbc$. It follows by the usual reasoning that, for 
some $q'$ with $q\mathcal{R}q'$, $q'\vDash\lbc a\approx\hat{n}\rbc$ for some $n\in\omega$.
Also, $q'\vDash\lbc\oldneg(\exists y)(y\in\widehat{\omega_2}\wedge\langle a,y\rangle\in f)\rbc$. There are two 
cases: either $n\in\textrm{Dom}(q')$, or $n\notin\textrm{Dom}(q')$.

Case 1) $n\in\textrm{Dom}(q')$. Let $q'(n)=\alpha$. Because $q'$ thinks $\textrm{Op}(\hat{n},\hat{\alpha})$ is an ordered pair, 
$q'\vDash\lbc\langle\hat{n},\hat{\alpha}\rangle\approx\textrm{Op}(\hat{n},\hat{\alpha})\rbc$. Also, by definition of $q'$, 
$\alpha\in\omega_2$, meaning $q'\vDash\lbc\hat{\alpha}\in\hat{\omega_2}\rbc$. By the definition of $f$, it can also easily be 
seen to follow that $q'\vDash\lbc\textrm{Op}(\hat{n},\hat{\alpha})\in f\rbc$, meaning we would have 
$q'\vDash\lbc (\hat{\alpha}\in\hat{\omega_2}\wedge\textrm{Op}(\hat{n},\hat{\alpha})\in f)\rbc$, thus 
$q'\vDash\lbc (\hat{\alpha}\in\hat{\omega_2}\wedge\langle\hat{n},\hat{\alpha}\rangle\in f)\rbc$, thus

We prove that $\overline{\overline{\mathcal{G}}}=\aleph_2$. In order to do this, we show that 
$\overline{\overline{\mathcal{G}}}\le\aleph_2$ and $\aleph_2\le\overline{\overline{\mathcal{G}}}$. 

First, we show that $\overline{\overline{\mathcal{G}}}\le\aleph_2$. To do this, for each $n\in\omega$,

$p$ such that $p(\alpha)=\langle\emptyset,\emptyset\rangle$ for all but $n$ ordinals $\alpha\in\omega_2$. Then

$\overline{\overline{f_i}}\le\aleph_2$ for each $i$. So consider any $f_i$. Because, for each $p\in f_i$, the domain of 
$p$ is $\omega_2$, and there are all but $n$ ordinals $\alpha$ such that $p(\alpha)\ne\langle\emptyset,\emptyset\rangle$, it can easily be seen 
by induction on $n$ to follow that there are $\aleph_2$ possibilites for which $p(\alpha)$ are not $\langle\emptyset,\emptyset\rangle$. 
For any given configuration of which $\alpha$ are such that $p(\alpha)\ne\langle\emptyset,\emptyset\rangle$, there are 
in turn $\omega$ possibilities for the choice of $P_\alpha$ and $N_\alpha$ (because $P_\alpha$ and $N_\alpha$ are both 
finite, disjoint sets of integers). This means $f_i$ has cardinality $\aleph_2$, from which it follows that 
$\mathcal{G}$ has cardinality $\aleph_2$.

On the other hand, it easily follows by the definition of $\mathcal{G}$ that $\aleph_2\le\overline{\overline{\mathcal{G}}}$.

This is the proof I attempted of Proposition 5.6. You will see that I was unable to complete step (3) of the proof.

We prove that $\lbc (f:\mathcal{P}(\hat{\omega})\rightarrow\widehat{\omega_2})\wedge\textrm{1-1}(f)\rbc$. First note, however, that 
there is an error in the definition of $f$. Currently, the definition is such that $f$ is not even in 
$\mathcal{D}^\mathcal{G}$. The definition really should be 
\[ f=\{\langle p,\textrm{Op}(a,\hat{\alpha}\rangle)|p\in\mathcal{G}\textrm{ and }a\in C_0\textrm{ and }f_0(a)=\alpha\} \]

In addition, the formula we are trying to prove seems incorrect, as $\mathcal{P}(\hat{\omega})$ is not 
in $\mathcal{D}^\mathcal{G}$. It seems to me that we really should prove that, for every possible world $p$, 
the following for things hold:
\[ \textrm{(1) }p\vDash\lbc(\forall x)(x\subseteq\hat{\omega}\supset(\exists y)(\langle x,y\rangle\in f))\rbc \]
\[ \textrm{(2) }p\vDash\lbc(\forall x)(\forall y)(\langle x,y\rangle\in f\supset (x\subseteq\hat{\omega}\wedge y\in\widehat{\omega_2}))\rbc \]
\[ \textrm{(3) }p\vDash\lbc(\forall x)(\forall y)(\forall z)((\langle x,y\rangle\in f\wedge\langle x,z\rangle\in f)\supset y=z)\rbc \]
\[ \textrm{(4) }p\vDash\lbc(\forall x)(\forall y)(\forall z)((\langle x,z\rangle\in f\wedge\langle y,z\rangle\in f)\supset x=y)\rbc \]

\begin{proof}
Consider any possible world $p$. We show that the four things above all hold. 

(1) We show that (1) holds. Suppose, on the contrary, that 
$p\nvDash\lbc(\forall x)(x\subseteq\hat{\omega}\supset(\exists y)\langle x,y\rangle\in f)\rbc$. Then, for some 
$d$ and for some $q$ with $p\mathcal{R}q$,
$q\vDash\lbc d\subseteq\hat{\omega}\rbc$ and $q\vDash\lbc\oldneg(\exists y)\langle d,y\rangle\in f\rbc$.
Because $p\vDash\lbc d\subseteq\hat{\omega}\rbc$, we know by Exercise 5.1 that 
$q\vDash\lbc d\approx b\rbc$ for some $b\subseteq\hat{\omega}$. Either $b\in C_0$, or it is a member of 
some equivalence class including some $c\in C_0$. In either case, there is some $c\in C_0$ 
such that $\lbc b\approx c\rbc$ is valid in $\mathcal{M}$. Then there is some $\alpha$ such that 
$f_0(c)=\alpha$. Then, by the definition of $f$, it easily follows that 
$q\vDash\lbc\textrm{Op}(c,\hat{\alpha})\in f\rbc$. But 
$q$ thinks $\textrm{Op}(c,\hat{\alpha})$ is $\langle c,\hat{\alpha}\rangle$, meaning 
$q\vDash\lbc\langle c,\hat{\alpha}\rangle\in f\rbc$, meaning (because $q\vDash\lbc d\approx b\rbc$ and 
$q\vDash\lbc b\approx c\rbc$)
$q\vDash\lbc\langle d,\hat{\alpha}\rangle\in f\rbc$. This implies 
$q\vDash\lbc(\exists y)\langle d,y\rangle\in f\rbc$. But this contradicts 
$p\vDash\lbc\oldneg(\exists y)\langle d,y\rangle\in f\rbc$ (which implies
$q\vDash\lbc\oldneg(\exists y)\langle d,y\rangle\in f\rbc$).

(2) We show that (2) holds. Suppose, on the contrary, that
$p\nvDash\lbc(\forall x)(\forall y)(\langle x,y\rangle\in f\supset (x\subseteq\hat{\omega}\wedge y\in\widehat{\omega_2}))\rbc$.
Then, for some $a$ and $b$ and some $q$ with $p\mathcal{R}q$,
$q\vDash\lbc\langle a,b\rangle\in f\rbc$, and either $q\vDash\lbc\oldneg (a\subseteq\hat{\omega})\rbc$ or 
$q\vDash\lbc\oldneg (b\in\widehat{\omega_2})\rbc$. Suppose, without loss of generality, that the former holds, that 
is, $q\vDash\lbc\oldneg (a\subseteq\hat{\omega})\rbc$. Now, because 
$q\vDash\lbc\langle a,b\rangle\in f\rbc$, it follows that for some
$r$ with $q\mathcal{R}r$, and some $\textrm{Op}(c,\hat{\alpha})$ with $c\in C_0$ and 
$f_0(c)=\alpha$, $r\vDash\lbc\langle a,b\rangle\approx\textrm{Op}(c,\hat{\alpha})\rbc$. 
From this it follows that $r\vDash\lbc a\approx c\rbc$ and 
$r\vDash\lbc b\approx\hat{\alpha}\rbc$. Because $c\in C_0$, it follows that 
$c\subseteq\hat{\omega}$. This can easily be seen to imply that 
$r\vDash\lbc c\subseteq\hat{\omega}\rbc$. Hence
$r\vDash\lbc a\subseteq\hat{\omega}\rbc$ (because $r\vDash\lbc a\approx c\rbc$). But 
this contradicts $q\vDash\lbc\oldneg (a\subseteq\hat{\omega})\rbc$ (which implies 
$r\vDash\lbc\oldneg (a\subseteq\hat{\omega})\rbc$). 

(3) We show that (3) holds. Suppose, on the contrary, that 
$p\nvDash\lbc(\forall x)(\forall y)(\forall z)((\langle x,y\rangle\in f\wedge\langle x,z\rangle\in f)\supset y=z)\rbc$. 
Then, for some $a,b,c,$ and some $q$ with $p\mathcal{R}q$,
$q\vDash\lbc\langle a,b\rangle\in f\rbc$, $q\vDash\lbc\langle a,c\rangle\in f\rbc$, 
and $q\vDash\lbc\oldneg (b=c)\rbc$. Using the usual reasoning, it follows that, for some $r$ with $q\mathcal{R}r$,
$r\vDash\lbc\langle a,b\rangle\approx\textrm{Op}(c,\hat{\alpha})\rbc$ and 
$r\vDash\lbc\langle a,c\rangle\approx\textrm{Op}(d,\hat{\beta})\rbc$, for some 
$c,d\in C_0$ where $f_0(c)=\alpha$ and $f_0(d)=\beta$. These things imply 
$r\vDash\lbc a\approx c\rbc$, $r\vDash\lbc a\approx d\rbc$, $r\vDash\lbc b\approx\hat{\alpha}\rbc$
and $r\vDash\lbc c\approx\hat{\beta}\rbc$. This means 
$r\vDash\lbc c\approx d\rbc$. In order to derive a contradiction, we would need to know that 
$c=d$, which would imply $\alpha=\beta$, and then $r\vDash\lbc b=c\rbc$. However, it does not seem 
to me that we know $c=d$ for sure. If $c\ne d$, then it would follow by the 
definition of $C_0$ that $\lbc c\approx d\rbc$ was not valid; but that would not necessarily mean 
$r\nvDash\lbc c\approx d\rbc$, which is what would be a contradiction in this case. 
Thus it does not seem to me that we can prove this case.

(4) We show that (4) holds. Suppose, on the contrary, that 
$p\nvDash\lbc(\forall x)(\forall y)(\forall z)((\langle x,z\rangle\in f\wedge\langle y,z\rangle\in f)\supset x=y)\rbc$. Then, 
for some $a,b,c,$ and some $q$ with $p\mathcal{R}q$,
$q\vDash\lbc\langle a,c\rangle\in f\rbc$, $q\vDash\lbc\langle b,c\rangle\in f\rbc$, 
and $q\vDash\lbc\oldneg(a=b)\rbc$. Using the usual reasoning, it follows that, for some $r$ with 
$q\mathcal{R}r$, $r\vDash\lbc\langle a,c\rangle\approx\textrm{Op}(w,\hat{\alpha})\rbc$ and 
$r\vDash\lbc\langle b,c\rangle\approx\textrm{Op}(v,\hat{\alpha})\rbc$, for some $w,v\in C_0$ where
$f_0(w)=\alpha$ and $f_0(v)=\beta$. These things imply that $r\vDash\lbc a\approx w\rbc$,
$r\vDash\lbc c\approx\hat{\alpha}\rbc$, $r\vDash\lbc b\approx v\rbc$ and 
$r\vDash\lbc c\approx\hat{\beta}\rbc$. Then 
$r\vDash\lbc\hat{\alpha}\approx\hat{\beta}\rbc$, meaning $\alpha=\beta$. Because $f$ is 1-1, 
this implies $w=v$, thus 
$r\vDash\lbc a\approx b\rbc$. But 
this contradicts $q\vDash\lbc\oldneg(a=b)\rbc$ (which implies 
$r\vDash\lbc\oldneg(a=b)\rbc$).

\end{proof}
