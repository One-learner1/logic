\section*{Section 1}

\subsection*{Notes}
Here is why, for any class of ordinals $B$, the smallest ordinal $\alpha\in B$ is an initial element of $B$ 
If $\alpha=\emptyset$, then $\alpha\cap B=\emptyset$. 
If $\alpha\ne\emptyset$, then all members of $\alpha$ are ordinals less than $\alpha$. But, by assumption, there are no ordinals in $B$ less than 
$\alpha$, meaning $\alpha\cap B=\emptyset$.

\subsection*{Exercise 1.1}
(1) We first show that $R_\Omega$ is well-founded. Consider any non-empty subclass $A$ of $R_\Omega$. Then let $\alpha$ be the 
lowest rank that any of the elements in $A$ have. Now consider any element $x\in A$ which has rank $\alpha$. 
Suppose that there was some element $y$ of $A$ in $x$. Then $y$ would have rank $\ge\alpha$. But this is not possible, as, by 
$P_6$ of Chapter 7 (and the fact that $x$ is a set), $y$ would have a rank $<\alpha$, a contradiction. Thus 
all elements of $x$ are not in $y$, meaning $x\cap A=\emptyset$. Thus every element $x\in A$ with rank $\alpha$ is an 
initial element of $A$.

(2) The fact that every $R_\alpha$ (where $\alpha>0$) is well-founded follows because every $R_\alpha$ is a non-empty subclass of 
$R_\Omega$. Obviously $R_0$ is also well-founded (because $\emptyset$ is well-founded). 

If now it was the case that $R_\Omega$ was in fact equal to $V$, this exercise would prove that 
$V$ was well-founded.

\subsection*{Theorem 2.3}
Here is a more formal proof of Theorem 2.3 (a more formal form of the second paragraph of the proof).

Since $B$ is non-empty, it contains an element $e$. We now form the denumerable sequence 
$b_1,b_2,...,b_n,...$ as follows: $b_1=e$; if $b_n$ is an initial element of $B$, then 
$b_{n+1}=b_n$; if $b_n$ is not an initial element of $B$, then we take $b_{n+1}$ to be the least element (under the well-ordering of $A$) of 
$b_n$ that is in $B$.

As remarked before the proof of Theorem 2.3, $A$ satisfying the descending $\in$-chain condition means that 
$A$ contains no $\in$-cycles. If all elements of the above 
denumerable sequence are distinct, then clearly that sequence is an infinite descending $\in$-chain, contradicting the assumption that 
$A$ satisfies the descending $\in$-chain condition. 

Suppose, on the other hand, that two elements of the sequence were the same 
(say the elements $b_m$ and $b_n$, where $m<n$), and that $b_m$ was not an initial element of $B$. Then, for all $i$ where $m\le i<n$, 
it must be that $b_i\in b_{i+1}$. But that means we would have an $\in$-cycle $b_m,b_{m+1},...,b_n$, which cannot happen. 

Thus it cannot be that all elements of the sequence are distinct, or that two elements of the sequence were the same where one of them 
was not an initial element of $B$. Hence it must be that a pair of elements of the sequence are the same, where one of the elements of the 
pair is an initial element.

\subsection*{Notes}
It is remarked that an infinite descending chain of ordinals cannot exist. This is because an infinite descending chain of ordinals 
would not have a least element, contrary to the fact that every class of ordinals has a least element.

\subsection*{Theorem 3.6}
The proof of this theorem does not seem correct to me. It says: \textquote{Either $V_0$ contains all ordinals of $V$ or it does not. 
Suppose it does. Then $R_\Omega\subseteq V_0$.} This is not correct, as it was not assumed that $V$ contains all ordinals. Thus 
$V_0$ containing all ordinals of $V$ does not necessarily imply that $R_\Omega\subseteq V_0$ (because $R_\Omega$ contains all 
ordinals). This shouldn't be an issue, as the case where $On$ is not a subclass of $V$ can then be proven in the way starting with 
\textquote{If, on the other hand, $V_0$ does not contain all ordinals of $V$...} in the proof.

However, the part of the proof starting with that sentence seems to be more complicated than the proof lets on. It claims that the 
rank of every element of $V_0$ must be in $V_0$, which does require proof.
\begin{proof}
By the induction method of Theorem 3.2. Suppose the hypothesis holds for the ranks of all elements of some element $x$ in $V_0$. 
Then the rank $\alpha$ of $x$ is the least ordinal that is greater than all the ranks of the elements of $x$. Either $\alpha$ is a 
successor ordinal or $\alpha$ is a limit ordinal. Let $O$ be the set of all ranks of elements of $x$. Then $\cup O$ is an ordinal and 
is in $V_0$ (because $V_0$ is a Zermelo-Fraenkel universe) 
If $\alpha$ is a successor ordinal, then $\alpha=\cup O\cup\{\cup O\}$, which is also in $V_0$. If $\alpha$ is a limit ordinal, then 
$\cup O=\alpha$. In any case, $\alpha\in V_0$, therefore completing the proof.
\end{proof} 
Thus the rank of every element of $V_0$ is less than $\alpha$ (the $\alpha$ defined in the proof). It is then concluded that this means 
that $V_0\subseteq R_\alpha$. This is because all elements of $V_0$ have rank less than $\alpha$, meaning they are all members of $R_\alpha$.

\subsection*{Exercise 3.1}
\begin{lemma}
If $x\subset R_\lambda$ for a limit ordinal $\lambda$ and $x$ is a set, then $x\in R_\lambda$.
\end{lemma}
\begin{proof}
Suppose the hypothesis. Then all elements of $x$ have a rank less than $\lambda$. Then it can easily be seen that 
$x\subseteq R_\alpha$ for the smallest ordinal $\alpha$ that is greater than all the ranks of the elemetns of $x$. Clearly 
$\alpha$ is not greater than $\lambda$. For if it were, then an ordinal $\beta$ such that $\beta\ge\lambda$ would need to be 
the rank of some element of $x$, contradicting the fact that all elements of $x$ are in $R_\lambda$. Hence $\alpha\le\lambda$.
Also $\alpha<\lambda$, as $x\subset R_\lambda$ (that is, $x\ne R_\lambda$). Thus $\alpha<\lambda$. Hence 
$\alpha+1<\lambda$, and $x\in R_{\alpha+1}$, meaning $x\in R_\lambda$.
\end{proof}

\begin{lemma}
$R_\lambda$ for every limit ordinal $\lambda$ is a Zermelo-Fraenkel universe.
\end{lemma}
\begin{proof}
Consider $R_\lambda$ for any limit ordinal $\lambda$. We already know that it is a Zermelo universe. It remains to be seen 
that $R_\lambda$ satisfies the axiom of substitution. So let $F$ be any functions from $R_\lambda$ to $R_\lambda$. Take any 
$x\in R_\lambda$. Since $x\in R_\lambda$, then $x$ is a set, and so by the axiom of substition (applied in $V$) $F''(x)$ is a set. 
Thus $F''(x)$ is a set of all whose members are in $R_\lambda$. Also $F''(x)\ne R_\lambda$, as, for example, 
$F(x)\notin F''(x)$ (because $x\notin x$, as if $x\in x$, then $x$ would have a smaller rank than $x$, which is impossible). Thus 
$F''(x)\subset R_\lambda$, and thus, by Lemma 0.1, $F''(x)\in R_\lambda$. Hence $R_\lambda$ satisfies the axiom of substition, meaning it 
is a Zermelo-Fraenkel univese.
\end{proof} 

Now we prove that, for any Zermelo-Fraenkel universe $V$, the intersection of all Zermelo sub-universes of $V$, each containing 
all the ordinals of $V$, is well founded.
\begin{proof}
If $V$ contains all ordinals, then the above intersection is $R_\Omega$ (by Exercise 4.1 of Chapter 7), which is well founded 
(by Exercise 1.1). On the other hand, suppose that $V$ does not contain all ordinals. Then it can easily be seen that 
the least ordinal that $V$ does not contain must be some limit ordinal $\lambda$. We aim to show that $R_\lambda\subseteq V$. First, we 
show that for every $\alpha<\lambda$, $R_\alpha\in V$. Obviously $R_0\in V$. Suppose some $R_\alpha\in V$. Then 
$\mathcal{P}(R_\alpha)\in V$ (because $V$ is a Zermelo-Fraenkel universe), that is, $R_{\alpha+1}\in V$. On the other hand, suppose 
that for all ordinals $\alpha$ less than some limit ordinal $\lambda_1$ such that $\lambda_1<\lambda$, $R_\alpha\in V$. Then 
$R_{\lambda_1}=\cup_{\alpha<\lambda_1}R_\alpha$. Because $\lambda_1<\lambda$, and $V$ contains all ordinals less than $\lambda$, 
$\lambda_1\in V$. Thus the set of all $R_\alpha$ for all $\alpha<\lambda_1$ is in $V$ (by the axiom of substitution), meaning 
so is $\cup_{\alpha<\lambda}R_\alpha$, that is, $R_\lambda_1$. Hence, for all $\alpha<\lambda$, $R_\alpha V$. By the transitivity of 
$V$, it then obviously follows that $R_\lambda\subseteq V$.

Now, $R_\lambda$ is a Zermelo-Fraenkely universe by Lemma 0.2, and contains all ordinals of $V$. Also $R_\lambda$ is well founded. 
Thus the intersection of all Zermelo sub-universes of $V$, each containing all the ordinals of $V$, is a subclass of $R_\lambda$, meaning 
it is well founded (because all subclasses of a well founded class are well founded). 
\end{proof}

\subsection*{Exercise 3.2}
This exercise does not seem correct to me. For example, consider the set $R_3=\{0,\{0\},\{1\},\{0,1\}\}$. It is well-founded
(by Exercise 1.1) and transitive, so it satisfies the assumptions of this exercise. Then we could let $G$ be the set of all ordered 
pairs $\langle x,\{0,1\}\rangle$ where $x\in R_3$. Now, suppose we had a function $F$ satisfying the conditions of the exercise. Then
$F(0)=G(F''(0))=G(0)=\{0,1\}$ and thus (because $x\cap R_3=x$ for any $x\in R_3$, as $R_3$ is transitive)
$F(1)=G(F''(1))=G(\{\{0,1\})$. But $G$ is not defined for $\{\{0,1\}\}$, which means this is an apparent contradiction.
