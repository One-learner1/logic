Prove the Generalized Induction Threorem:

Generalized Induction Theorem: A sufficient condition for a component relation C(x,y) on a set A to obey the generalized induction principle is that all descending chains be finite.

1: If an inductive property P fails for some element x of set A, then P must also fail for some component x1 of x (because by definition of P being inductive, if P held for all components of x, then P must also hold for x). Then, because P does not hold for x1, P must also not hold for some component x2 of x1. But, because this process must necessarily go on infinitely, an infinite chain has been created, going from x to its component x1 for which P fails for, and then the component for x1 which P fails fors, thus creating an infinitely descending chain. But, because it was assumed that all descending chains be finite, this leads to a contradiction. Thus, if all descending chains be finite in a set A, an inductive property P cannot fail for any element, and thus must hold for every element of A, thus proving the generalized induction theorem.
