Problem 2(a): Prove that if A is nameable, so is A#:

	Assume that A is nameable. The set A# is the set of all n such that n* is a member of A. By definition of a diagonalization, K(n) is true iff H(n*) is true. Thus, K(n) names all of those and only those n which have n* being members of A, meaning K names A#.

Problem 2(b): Prove there is a Godel sentence for any nameable set A.
	
	Assume that the set A is nameable. By problem 2(a), there is some designator which designates A#; let k be its Godel number. Now consider the sentence Hk(k). This is true iff k is a member of A#, meaning by definition k* would be a member of A. But, because k* is the Godel number of Hk(k), this means Hk(k) is true iff its Godel number is a member of A, meaning that Hk(k) is a Godel sentence for A.

Then, the formula Vy(F1(x1,...,xn, y) then Ez(z <= n and F2(x1,...,xn, y))) is logically implied by the formula obtained immediately from L2', and thus is provable as well. 

	Now we prove that ~Vy(F1(x1,...,xn, y) then Ez(z <= n and F2(x1,...,xn, y))) represents A. First, assume that R1(x1,...,xn) holds.
