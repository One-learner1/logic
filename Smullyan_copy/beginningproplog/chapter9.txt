Problem 1(a): Vx(Px or Qx) says that every x either has property P or property Q. VxPx or VxQx says that either every x has property P, or every x has property Q. This is obviously not equivalent to the first formula, as every x having either property P or property Q says nothing about whether or not every x has property P or if every x has property Q. For example, in a domain U, Px could be true for half of the elements, while Qx could be true for the other half (as in the property of being even and being odd for natural numbers), meaning Vx(Px or Qx) is true, but the second formula would not be true, as VxPx or VxQx does not hold.

Problem 1(b): Ex(Px and Qx) means that there is some x such that Px and Qx both hold. ExPx and ExQx says that there is some x such that Px, and there is some x (not necessarily the same one) such that Qx. We could have the case where Px holds for some x, and Qx holds for some y distinct from x. This does not guarantee there is some x such that both P and Q hold, meaning Ex(Px and Qx) is not implied. Again, we could take the example of being even and odd. Obviously no number can be both even and odd, but there is an odd and an even number.

Problem 2: We assume the interpretation I satsifies S. Consider some formula s of type delta in S and some parameter a that is new to S. Now consider some interpretation I` which is an extension of I. Well, because I` preserves all the values of the formulas in S, s would still be true under I`. Being true, s(e) must be true for some e in U. Now, because I` is an interpretation of S`, which has S as a subset, it necessarily contains some parameter a which is new to S. Then, when assigning a value to a under I`, we simply give it the value of e, meaning s(a) is true (we could not do this same procedure for the parameters being members of S, as they have already been assigned their original values in I by definition of I`, of which we can not be certain any of them were true for s).

Problem 3: Prove that every Hintikka Set for First Order Logic is Satisfiable:

We prove that for all formulas of degree n in set S, each formula is satisfiable under some interpreation I. This will be proven by complete mathematical induction.
Base Case: For the base case of formulas of degree 0, these are just n-ary predicates. Then it is obvious that we can assign each predicate P the n-ary relation x1,...,xn such that T Px1,...,xn is a member of S (we can assign any n-ary relation whatsoever to each predicate, meaning we of course can assign it a relation such that it is true under I). Because F Px1,...,...xn is not a member of S by H0, the base case has been proven. 
Now assume that for all formulas of degrees less than n, these formulas are all true under I. In the case of formulas of type b or a, these are true by either the fact that either b1 or b2 is a member of S, or both a1 and a2 are members of S (by H1 and H2). In the case of the formula of degree n+1 being of type y, y(a) is a member of S for every parameter a, by H3. Now, because y(a) is the result of replacing the occurences of x by a, the bounding quantifier for x (either Vx or ~Ex) is taken out of the formula. Thus the formula y(a) must be less than degree n for every parameter a. Thus every formula y(a) is true under I, meaning y itself is true under I. 
In the case of a formula of type s, there is at least one parameter a such that the formula s(a) is in S (by H4). Again, s(a) must be of a degree less than n, so that s(a) is true. Than, s itself is also true by definition. 
Thus, in all cases of formulas, the formula is true under I, meaning that the set S is satisfiable, completing the proof.

Eventually, because S was assumed to be a finite set of formulas, the sequence must terminate, ending with either A1 or A2 proving X.
