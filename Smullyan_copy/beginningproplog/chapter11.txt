***Prove that, for any prime number p, a number x is a power of p iff every divisor of x other than 1 or itself divisible by p.

We then have k * y = p1 * p2 * ... * pn. By Euclids Lemma, either k or y must be divisible by p. If it is not k, then we have y = j1 * p. Thus, rewriting the above yields k * j1 * p = p1 * p2 * ... * pn. Dividing by p yeilds k * j1 = p1 * p2 * ... * pn-1. Again, either k or j1 is divisible by p. If it is not k, we have j1 = j2 * p. Thus every divisor of x other than 1 or itself must be divisible by p.

Because n is not a prime, there must be at least one pair of k and j such that k and j are proper factors of n. Thus, both k and j are less than n, meaning by the assumption both k and j have prime factorizations. Thus k = p1 * p2 * ... * pn and j = q1 * q2 * ... * qm. Thus, n = p1 * p2 * ... * pn * q1 * q2 * ... * qm, meaning n also has a prime factorization.

Prove that the nth sum of successive odd numbers is n^2:

	We must first prove two key Lemmas: 

	Lemma 1: Prove that n^2+n+n+1 = (n+1)^2 for all integers:

		Base Case: 1^2 + 1 + 2 = 4, which equals 2^2, completing the base case. 

		Induction: Assume that the statement holds for all numbers less than n + 1. No we consider the expression:

			(1) n^2 + n + n + 1      We can rewrite this (by the assumption), as:
			(2) n-1^2 + n - 1 + n + n + n + 1 We can then rewrite this as:
			(3) n-2^2 + n-2 + n-1 + n-1 + n + n + n + 1 We can repeat this process until we have n^2 = 1, ending at:
			(4) 1 + 1 + 2 + 2 + ... + n + n + n+1 We now can systematically pair off each k (starting at 1) with each j (starting at n). We start by pairing off 1 with n, and 2 with n-1, and in general, if we have some k, we pair this number off with n+1-k, ensuring that each pair sums to n+1. Because there are two sets of each number less than n+1, and there are n of these numbers, we have 2n total numbers, of which each two numbers pair off to sum to n+1, meaning we have n total pairs of an n+1 sum. Thus, we have n pairs of n+1, in addition to the n+1 we started off with in step (1), meaning we have n+1 pairs of n+1, which is just (n+1)^2, thus completing the proof. 

	Lemma 2: Prove that the nth odd number is n-1 + n:

		Base Case: The first odd number is 1, which is 0 + 1, proving the base case.

		Induction: Assume that the statement holds for some n. Now consider the n+1th odd number. This number
		is equal to the nth odd number plus two by definition. By the assumption, the nth odd number = n-1 + n. Thus, the n+1th odd number = n-1 + n + 2, or, rewriting, n + n + 1, proving the induction case, and thus the whole statement. 
	Now for the real proof:

	Base Case: The first 1 odd number is 1, which equals 1^2, proving the base case.

	Induction: Assume that the statement holds for some n. Thus, we have the sum of the first n+1 odd numbers equaling n^2 + n + n + 1 (by Lemma 2), and thus by Lemma 1 this equals (n+1)^2, completing the proof.
