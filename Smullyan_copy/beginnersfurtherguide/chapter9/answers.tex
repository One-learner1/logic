\section*{Problem 1}
Suppose that $\mathcal{C}$ contains a bluebird $B$ and a mocker $M$. Thus, for all $x,y$ and $z$, $Bxyz=x(yz)$ and $Mx=xx$. Now consider any elements $x$ and $y$. Take $C$ to be the 
combinator $(Bx)y$. Thus $(Bxy)z=((Bx)y)z=Bxyz=x(yz)$ for every $z$, meaning $C$ combines $x$ with $y$, and thus the composition condition holds. By Theorem 1 of the last chapter, 
a fixed point of every element $x$ is $CC$, where $C$ combines $x$ with $M$. Thus a fixed point of every element $x$ in $\mathcal{C}$ is $(BxM)(BxM)$, which is the same as $M(BxM)$.

\section*{Problem 2}
Suppose that $\mathcal{C}$ has some bluebird $B$ and mocker $M$. Then, by Problem 2 of Chapter 8, there is an egocentric element, namely $y$ for $y$ the fixed point of $M$. In particular, 
this is the element $M(BMM)$. In particular: $(M(BMM))(M(BMM))=M(M(BMM))=(BMM)(BMM)=M(BMM)$.

\section*{Problem 3}
Now suppose that $\mathcal{C}$ contains some $B,M$ and a kestrel $K$. Thus by Problem 1, $K$ has a fixed point, and hence, by Problem 20(b) of Chapter 8, the fixed point of $K$ is narcissistic. 
In particular, $M(BKM)$ is narcissistic.

\section*{Problem 4}
(1):


(a): Take $D$ to be $BB$. Thus $Dxyzw=BBxyzw=(BBxy)zw=(B(xy))zw=B(xy)zw=(xy)(zw)=xy(zw)$.


(b): Take $B_1$ to be $DB$. Thus $B_1xyzw=DBxyzw=(DBxyz)w=(Bx(yz))w=Bx(yz)w=x((yz)w)=x(yzw)$.


(c): Take $E$ to be $BB_1$. Thus $Exyzwv=BB_1xyzwv=(BB_1xy)zwv=B_1(xy)zwv=(xy)(zwv)=xy(zwv)$.


(d): Take $B_2$ to be $EB$. Thus $B_2xyzwv=EBxyzwv=(EBxyzw)v=(Bx(yzw))v=Bx(yzw)v=x((yzw)v)=x(yzwv)$.


(e): Take $D_1$ to be $B_1B$. Thus $D_1xyzwv=B_1Bxyzwv=(B_1Bxyz)wv=B(xyz)wv=(xyz)(wv)=xyz(wv)$. Alternatively, we could take $D_1$ to be $BD$. Actually, 
$BD=B_1B$, as $BD=B(BB)=BBBB=DBB=B_1B$. Thus $D_1xyzw=BDxyzwv=(BDxy)zwv=D(xy)zwv=(xy)z(wv)=xyz(wv)$.


(f): Take $B^+$ to be $D_1B$. Thus $B^+xyzw=D_1Bxyzw=Bxy(zw)=x(y(zw))$.


(g): Take $D_2$ to be $DD$. Thus $D_2xyzwv=DDxyzwv=(DDxyz)wv=Dx(yz)wv=x(yz)(wv)$.


(h): Take $\overset{\mathrm{\wedge}}{E}$ to be $EE$. Thus 
\[ \overset{\mathrm{\wedge}}{E}xy_1y_2y_3z_1z_2z_3=EExy_1y_2y_3z_1z_2z_3=(EExy_1y_2y_3)z_1z_2z_3=Ex(y_1y_2y_3)z_1z_2z_3=x(y_1y_2y_3)(z_1z_2z_3) \] 

(2): The base case, when $B=0$, is $B$ itself. Now suppose that the hypothesis holds for some $n$, that is, \[ B_nxy_1...y_{n+2}=x(y_1...y_{n+2}) \] 
Let $B_{n+1}$ be the combinator $BB_nB$. Thus \[ BB_nBxy_1...y_{n+3}=(BB_nBx)y_1...y_{n+3}=B_n(Bx)y_1...y_{n+3}=(B_n(Bx)y_1...y_{n+2})y_{n+3}=(Bx)(y_1...y_{n+2})y_{n+3} \]
\[ =Bx(y_1...y_{n+2})y_{n+3}=x((y_1...y_{n+2})y_{n+3})=x(y_1...y_{n+2}y_{n+3}) \] thus showing that $B_{n+1}$ is the desired combinator, and therefore the proof is complete. Alternatively, as 
Smullyan gives in his answer, it can be seen that taking $B_{n+1}$ to be $BBB_n$ also works.

\section*{Problem 5}
Suppose that we have a truth $T$ and a lark $L$. Thus $Txy=yx$ and $Lxy=x(yy)$ for all $x$ and $y$. Now, by Problem 23 of Chapter 7, $T$ has a fixed point. Let $A$ be some fixed point of $T$. 
Thus $Ax=TAx=xA$, meaning $A$ commutes with every element $x$.

\section*{Problem 6}
Suppose we have a bluebird $B$ and a trush $T$. Let $R$ be the combinator $DT$ (that is, $BBT$), meaning $Rxyz=DTxyz=Tx(yz)=(yz)x=yzx$.

\section*{Problem 7}
Take $C$ to be $RRR$. Thus $Cxyz=RRRxyz=RxRyz=Ryxz=xzy$.

\section*{Problem 8}
Here is a reduction of $C$ from Problem 7 to $B$ and $T$, using only 8 letters: $C=RRR=DT(DT)(DT)=BBT(BBT)(BBT)=B(T(BBT))(BBT)$.

\section*{Problem 9}
Suppose we have a cardinal $C$ and an indentity combinator $I$. Take $T$ to be $CI$. Thus $Txy=CIxy=Iyx=yx$, meaning $T$ is a thrush.

\section*{Problem 10}
Suppose we have some cardinal $C$. Take $R$ to be $CC$. Thus $Rxyz=CCxyz=Cyxz=yzx$, meaning $R$ is a robin.

\section*{Problem 11}
(a): Take $F$ to be $BCR$, meaning $Fxyz=BCRxyz=C(Rx)yz=Rxzy=zyx$, meaning $F$ is a finch.


(b): Take $F$ to be $ETTET$, meaning $Fxyz=ETTETxyz=TT(ETx)yz=(ETx)Tyz=ETxTyz=Tx(Tyz)=(Tyz)x=Tyzx=zyx$. 

\section*{Problem 12}
Take $V$ to be $CF$, meaning $Vxyz=CFxyz=Fyxz=zxy$, meaning $V$ is a vireo. 

\section*{Problem 13}
Take $F$ to be $CV$, meaning $Fxyz=CVxyz=Vyxz=zyx$.

\section*{Problem 14}
Suppose that we have a robin $R$ and a kestrel $K$. Take $I$ to be $RKK$. Thus $Ix=RKKx=KxK=x$, meaning $I$ is an identity combinator. In fact, we can take 
$I$ to be $RAK$ for any element $A$, as $RAKx=KxA=x$.

\section*{Problem 15}
(a): Take $C^*$ to be $BC$, meaning $C^*wxyz=BCwxyz=C(wx)yz=(wx)zy=wxzy$.


(b): Take $R^*$ to be $BCC^*$ (that is, $C^*C^*$), meaning $R^*wxyz=BCC^*wxyz=C(C^*w)xyz=C^*wyxz=wyzx$.


(c): Take $F^*$ to be $BC^*R^*$, meaning $F^*wxyz=BC^*R^*wxyz=C^*(R^*w)xyz=R^*wxzy=wzyx$.


(d): Take $V^*$ to be $C^*F^*$, meaning $V^*wxyz=C^*F^*wxyz=F^*wyxz=wzxy$. 

\section*{Problem 16}
For all parts of this problem, take the new combinator $A^{**}$ to be the combinator $BA^*$. For example, in the case of $C^{**}$, we have 
$C^{**}vwxyz=BC^*vwxyz=C^*(vw)xyz=vwxzy$. More generally, if $Axyz=abc$, where $abc$ is a permutation of $xyz$, then $BA^*wvxyz=A^*(wv)xyz=wvabc$.


Note that this problem can be generalized in the following way: If $Axyz=abc$ for some permutation $abc$ of $xyz$, let $A_n$ for $n>1$ be defined in the following way:
$A_nx_1...x_nxyz=x_1...x_nxyz$. If $n=2$, let $A_n=BA^{*}$, which means $A_nvwxyz=vwxyz$ by Problem 16. If $n>2$, let $A_n=BA_{n-1}$, and because 
$BA_{n-1}x_1...x_nxyz=A_{n-1}(x_1x_2)...x_nxyz=(x_1x_2)x_3...x_nabc=x_1x_2...x_nabc$, $A_n$ satisfies the desired condition.

\section*{$n$th Identity Combinator}
Assuming a bluebird $B$ and an identity combinator $I$, we can define, for every $n$, a combinator $I_n$ such that $I_nx_1...x_{n+1}=x_1...x_{n+1}$. 
The base case when $n=0$ is simple: we take $I_0$ to be $I$. Now suppose $n>0$. Then take $I_n$ to be $B_{n-1}I$. Thus
\[ I_nx_1...x_{n+1}=B_{n-1}Ix_1...x_{n+1}=I(x_1...x_{n+1})=x_1...x_{n+1} \]
By Problem 14, the $n$th Identity Combinator is also present if some robin $R$ (or equivalently, some cardinal $C$) and some kestrel $K$ are present (and of course, 
also a bluebird $B$).

\section*{Problem 17}
Let $V$ be $C^*T$. Thus $Vxyz=C^*Txyz=Txzy=zxy$, meaning $V$ is a vireo. Expanded to $B$ and $T$, this is: 
$V=C^*T=(BC)T=(B(RRR))T=(B(B(T(BBT))(BBT)))T$ (the last step uses Problem 8).

\section*{Problem 18}
Just take $A$ to be $T$: $Axyz=Txyz=(Txy)z=(yx)z=yxz$.

\section*{Problem 19}
Consider the $A$ from Problem 18. Let $A^*$ be the combinator $BR^*C^*$. Thus $A^*wxyz=BR^*C^*wxyz=R^*(C^*w)xyz=C^*wyzx=wyzx$. Then take $Q$ to be 
$A^*Bxyz$, meaning $Qxyz=A^*Bxyz=Byxz=y(xz)$. Note that by Problem 16, $A^{**}=BA^*$.


A far simpler solution is taking $Q$ to be $CB$, as $CBxyz=Byxz=y(xz)$.

\section*{Problem 20}
Take $Q_1$ to be $C^*B$, meaning $Q_1xyz=C^*Bxyz=Bxzy=x(zy)$. Take $Q_2$ to be $R^*B$, meaning $Q_2xyz=R^*Bxyz=Byzx=y(zx)$.


Note that, in general, if $Q_i$ is defined to be $Q_ixyz=a(bc)$ for some permutation $abc$ of $xyz$, we can take $Q_i$ to be $A^*B$ where $A^*xyz=abc$, as 
$A^*Bxyz=Babc=a(bc)$. Given a combinator $Q_i$ such that $Q_ixyz=a(bc)$ for some permutation $abc$ of $xyz$, define $Q_i^*$ to be the combinator satisfying the condition 
$Q_i^*wxyz=wa(bc)$. Take $Q_1^*$ to be $BQ_1$, as $BQ_1wxyz=Q_1(wx)yz=(wx)(zy)=wx(zy)$. Take $Q_2^*$ to be $A^{**}Q_1^*$ with the $A$ that was defined in Problem 18, as 
$A^{**}Q_1^*wxyz=Q_1^*wyxz=wy(zx)$. Let $Q_0$ be an abbreviation for $Q$, the queer bird. Take $Q_0^*$ to be $R^{**}Q_1^*$, as 
$R^{**}Q_1^*wxyz=Q_1^*wyzx=wy(xz)$. In a similar fashion, take $Q_3^*$ to be $F^{**}Q_1^*$, and $Q_4^*$ to be $V^{**}Q_1^*$.


We can generalize the concept of $Q_i^*$ in a near identical fashion to that expressed in Problem 16. First, let $Q_i^*$ be $Q_i^1$. Now, we want a combinator $Q_i^n$ 
such that $Q_i^nx_1...x_nxyz=x_1...x_na(bc)$ where $abc$ is a permutation of $xyz$ and $Q_ixyz=a(bc)$. The base cases were proven in the last paragraph (as $Q_i^1$ 
is $Q_i^*$). Now if $n>1$, we, just as in Problem 16, take $Q_i^n$ to be $BQ_i^{n-1}$, as 
$BQ_i^{n-1}x_1...x_nxyz=Q_i^{n-1}(x_1x_2)...x_nxyz=(x_1x_2)...x_na(bc)=x_1x_2...x_na(bc)$.

\section*{Problem 21}
Suppose that a cardinal $C$ is present. On the one hand, if a quixotic bird $Q_1$ is present, take $Q_2$ to be $CQ_1$, as $CQ_1xyz=Q_1yxz=y(zx)$. 
Alternatively, take $Q_2$ to be $CRQ_1$ (recalling that $R$ is just $CC$), as 
$CRQ_1xyz=RxQ_1yz=Q_1yxz=y(zx)$, meaning $Q_2$ is quizzied. On the other hand, if a quizzied bird $Q_2$ is present, take $Q_1$ to be $CQ_2$, as 
$CQ_2xyz=Q_2yxz=x(zy)$, meaning $Q_1$ is quixotic.   

\section*{Problem 22}
By the note in Problem 20, we can take $Q_3$ to be $V^*B$, and $Q_4$ to be $F^*B$. Take $Q_5$ to be $V^*B_1$, as 
$V^*B_1xyzw=B_1zxyw=z(xyw)$. Take $Q_6$ to be $C_3Q_5$, with the $C_3$ defined in the note of Problem 16 (that is, $BC^{**}$), as
$C_3Q_5xyzw=Q_5xywz=w(xyz)$. 

\section*{Problem 23}
Suppose that a cardinal $C$ is present. On the one hand, if a quirky bird $Q_3$ is present, take $Q_4$ to be $CQ_3$, as 
$CQ_3xyz=Q_3yxz=z(yx)$. On the other hand, if a quacky bird $Q_4$ is present, take $Q_3$ to be $CQ_4$, as $CQ_4xyz=Q_4yxz=z(xy)$.
