\section*{Problem 1}
(a): Consider $\omega_n$, that is, the set of all $x$ such that $r\left(n,x\right)\in T_0$. In the last chapter, we showed that $T_0$ and the relation 
$g\left(x\right)=y$ are both recursively enumerable. Hence $r\left(n,x\right)\in T_0$ iff $g\left(x\right)=x_0\wedge nx_0\in T_0$. Now, the relation 
$r\left(x,y\right)=z$ is recursively enumerable, as it is expressed by: \[ \exists x_0\left(g\left(x\right)=x_0\wedge yx_0=z\right) \]
and thus the relation $r\left(n,x\right)\in T_0$ is expressed by the formula: \[ \exists z\left(r\left(n,x\right)=z\wedge z\in T_0\right) \]


(b): Suppose that $A$ is a recursively enumerable set. Hence there is some predicate $P$ of $\left(U\right)$ such that $Hx\in T$ iff $x\in A$. If $p$ is the Gödel number of 
$P$, $Px\in T$ iff $px_0\in T_0$ iff $r\left(p,x\right)\in T_0$ iff $x\in\omega_p$, thus proving that $A=\omega_p$.

\section*{Problem 2}
Consider a recursively enumerable relation $R\left(x,y\right)$. Hence, in $\left(U\right)$, it is represented by some predicate $H$, with a Gödel number of $h$. 
Hence $R(x,y)$ holds iff $hxcy\in T_0$ for $c$ the Gödel number of the comma. Take $t(y)$ to be $hy_0c$, which is recursive as $g(x)=x_0$ is recursively enumerable. 
Hence $x\in\omega_{t(i)}$ iff $r\left(hi_0c,x\right)\in T_0$ iff $hi_0cx\in T_0$ iff $R\left(i,x\right)$.


$Note$: The above is essentially the answer that Smullyan gave, but it is incorrect. It proves that $x\in\omega_{t(i)}$ iff $R(i,x)$, but that was not the theorem! It was 
to prove that $x\in\omega_{t(i)}$ iff $R(x,i)$. Below is a correct proof:


We suppose that $R(x,y)$ is recursively enumerable. Let $R_1(x,y)$ be the relation $R(y,x)$. Hence $R_1(x,y)$ is recursively enumerable. Thus 
$R(x,y)$ is represented in $(U)$ by some predicate $H$ with Gödel number $h$, and $R_1(x,y)$ is represented in $(U)$ by some predicate $P$ with Gödel number $p$. Hence 
\[ px_0cy_0\in T_0\textrm{ iff } hy_0cx_0\in T_0 \] for $x_0,y_0,c$ the Gödel numbers for $x,y,$ and the comma, respectively. Let $t(y)$ be the relation 
$py_0c$. Thus $x\in\omega_{t(i)}$ iff $r(pi_0c,x)\in T_0$ iff $pi_0cx_0\in T_0$ iff $hx_0ci_0\in T_0$ iff $R(x,i)$, meaning 
$x\in\omega_{t(i)}$ iff $R(x,i)$, thus completing the proof.

\section*{Problem 3}
Consider some recursively enumerable relation $R\left(x_1,...,x_m,y_1,...,y_n\right)$. Hence there is a recursively enumerable relation $M(x,y)$ such that 
$R(x_1,...,x_m,y_1,...,y_n)$ iff $M\left(\delta_m\left(x_1,...,x_m\right),\delta_n\left(y_1,...,y_n\right)\right)$. By the Simple Iteration Theorem, there is a function 
$t(i)$ such that $x\in\omega_{t(i)}$ iff $M(x,i)$. Hence, take 
$\phi(i_1,...,i_n)$ to be $t(\delta_n(i_1,...,i_n)$. Hence $M(\delta_m(x_1,...,x_m),\delta_n(i_1,...,i_n)$ iff $\delta_m(x_1,...,x_m)\in \omega_{\phi(i_1,...,i_n)}$ iff
$R_{\phi(i_1,...,i_n)}(x_1,...,x_m)$. This is true as we recall that $R^n_i(x_1,...,x_n)$ was defined to be $\delta_n(x_1,...,x_n)\in\omega_i$.

\section*{Problem 11}
Suppose that $f(x)$ reduces $A$ to $B$ and $\phi(x)$ is a generative function for $A$, and $t(y)$ is an iterative function for the relation $f(x)\in\omega_y$. Hence 
$x\in A$ iff $f(x)\in B$, $x\in\omega_{t(y)}$ iff $f(x)\in\omega_{y}$, and $\phi(i)\in A$ iff $\phi(i)\in\omega_i$. Thus $f(\phi(t(x)))\in B$ iff $\phi(t(x))\in A$ iff $\phi(t(x))\in\omega_{t(x)}$
iff $f(\phi(t(x)))\in\omega_x$. That is, $f(\phi(t(x)))\in B$ iff $f(\phi(t(x)))\in\omega_x$. If we let $\phi(i)$ be the function $f(\phi(t(x)))$, this proves that 
$\phi(i)\in B$ iff $\phi(i)\in\omega_i$.

\section*{Problem 14}

\section*{Problem 16}
Suppose that $A$ is a recursively enumerable set. Define $M(x,y)$ iff $y\in A$. Because $M(x,y)$ is recursively enumerable, by the iteration theorem, there is some recursive function 
$t(y)$ such that for all $i$, $\omega_{t(i)}=\{x:M(x,i)\}$. 


(1): Suppose $i\in A$. Hence $x\in\omega_{t(i)}$ iff $M(x,i)$ iff $i\in A$, which shows that, because $i\in A$, $x\in\omega_{t(i)}$ for every $x$.


(2): Suppose $i\notin A$. By part (1) of this problem, we know that $x\in\omega_{t(i)}$ iff $i\in A$. Hence, because $i\notin A$, $x\notin\omega_{t(i)}$ for every $x$, thus meaning 
$\omega_{t(i)}=\emptyset$.

\section*{Problem 17}
Consider some generative set $B$. By Problem 15, we know that, if $B$ is generative under the recursive function $\phi(x)$, then, for every $i$:\newline
(1) If $\omega_i=\N$ then $\phi(i)\in B$.\newline
(2) If $\omega_i=\emptyset$ then $\phi(i)\notin B$.\newline
Now consider any recursively enumerable set $A$. Hence, by Problem 16, there is a recursive function $t(y)$ such that for every number $i$:\newline
(1) If $i\in A$, then $\omega_{t(i)}=\N$;\newline
(2) If $i\notin A$, then $\omega_{t(i)}=\emptyset$.\newline
Now, consider the function $\phi(t(i))$. If $i\in A$, then $\omega_{t(i)}=\N$ and thus $\phi(t(i))\in B$. On the other hand, if $\phi(t(i))\in B$, then 
$\phi(t(i))\in\omega_{t(i)}$. If $i\notin A$, then $\omega_{t(i)}=\emptyset$, which would be contrary to the fact that $\phi(t(i))\in B$ (by (2) of Problem 15). Thus $i\in A$. We have therefore 
shown that $i\in A$ iff $\phi(t(i))\in B$, which shows that $A$ is reducible to $B$ under the function $\phi(t(i))$, and therefore $B$ is universal.

\section*{Problem 18}
Assume $C_1$, that is: There is a recursive function $\phi(x)$ such that for every $i$ such that $\omega_i$ is 
disjoint from $A$ and such that $\omega_i$ contains at most one member, the number $\phi(i)$ lies outside 
both $A$ and $\omega_i$.


(1): Suppose $\omega_i=\emptyset$. Suppose $\phi(i)\in A$. Hence $\omega_i$ is disjoint from $A$, and $\omega_i$ contains at most one member. Thus $\phi(i)$ lies outside both $A$ and 
$\omega_i$, contrary to the assumption $\phi(i)\in A$. Hence $\phi(i)\notin A$.


(2): Suppose $\omega_i=\{\phi(i)\}$. Suppose that $\phi(i)\notin A$. Then $A$ and $\omega_i$ are disjoint. But because $\omega_i$ has only one member, $\phi(i)$ lies outside both 
$A$ and $\omega_i$, contrary to the assumption that $\phi(i)\in\omega_i$. Thus $\phi(i)\in A$.

\section*{Problem 19}
Consider some recursive function $\phi(x)$. Let $M(x,y,z)$ be the recursively enumerable relation $x\in\omega_y\wedge x=\phi(z)$. By the strong recursion theorem, there is some recursive function 
$t(i)$ such that $x\in\omega_{t(i)}$ iff $M(x,i,\phi(i))$ iff $x\in\omega_i\wedge x=\phi(t(i))$ iff $x\in\omega_i\cap\{\phi(t(i))\}$, which is the same as saying 
$\omega_{t(i)}=\omega_i\cap\{\phi(t(i))\}$. Thus $t(i)$ is the desired recursive function. 

\section*{Problem 20}
Suppose that $\phi(x)$ is a weakly co-productive function for $A$. Let $t(y)$ be the recursive function related to $\phi(x)$ as defined in Problem 19. 
Thus if $\phi(t(i))\in\omega_{t(i)}$, then $\phi(t(i))\in\omega_i\cap\{\phi(t(i))\}$, which is the same as saying $\omega_{t(i)}=\{\phi(t(i))\}$, and thus $\phi(t(i))\in A$ by $C_2$ (2).
Now suppose that $\phi(t(i))\in A$. If $\phi(t(i))\notin\omega_{t(i)}$, then we know that $\phi(t(i))\notin\omega_i\cap\{\phi(t(i))\}$ and 
$\omega_{t(i)}=\omega_i\cap\{\phi(t(i))\}$, thus meaning $\omega_{t(i)}=\emptyset$, and thus $\phi(t(i))\notin A$ by $C_2$ (1). Thus $\phi(t(i))\in\omega_{t(i)}$. Hence we have shown that 
$\phi(t(i))\in A$ iff $\phi(t(i))\in\omega_{t(i)}$, thus proving that $\phi(t(i))$ is a generative function for $A$.

\section*{Direct Proof that Weak Co-productivity Implies Universality}
Suppose that $B$ is weakly co-productive under $\phi(x)$ and that $A$ is a set that we wish to reduce to $B$ (that is, a recursively enumerable set). Let $M(x,y,z)$ be the recursively enumerable 
relation \[ y\in A\wedge x=\phi(z) \] By the strong recursion theorem, there is some recursive function $t(i)$ such that 
\[ \textrm{(1) }x\in\omega_{t(i)}\textrm{ iff }M(x,i,t(i))\textrm{ iff }i\in A\wedge x=\phi(t(i)) \] 


Now suppose that $i\in A$. There are then two cases. In the first case, $x=\phi(t(i))$. Thus by (1), $x\in\omega_{t(i)}$. In the second case, $x\ne\phi(t(i))$. Again by 
(1), this would mean that $x\notin\omega_{t(i)}$. Thus $x\in\omega_{t(i)}$ iff $x=\phi(t(i))$, and therefore $\omega_{t(i)}=\{\phi(t(i))\}$. On the other hand, suppose that 
$i\notin A$. Thus, by (1), $x\notin\omega_{t(i)}$, and because this holds for all $x$, $\omega_{t(i)}=\emptyset$ in this case.


We now have the following. If $i\in A$, then by the above result, $\omega_{t(i)}=\{\phi(t(i))\}$. Thus $\phi(t(i))\in B$ by $C_2$ (2). If $\phi(t(i))\in B$, then 
$\omega_{t(i)}\ne\emptyset$ by $C_2$ (1). If $i\notin A$, then $\omega_{t(i)}=\emptyset$ by the above result, which is a contradiction. Hence $i\in A$. Thus, we have shown that 
$i\in A$ iff $\phi(t(i))\in B$, which proves that $\phi(t(i))$ reduces $A$ to $B$, thus showing that $B$ is universal. 


\textit{Note}: When Smullyan said $\omega_{t(y)}=\{\phi(y)\}$ in the explanation of this problem, he actually meant $\omega_{t(y)}=\{\phi(t(y))\}$. 

\section*{Exercise 5}
To me it appears that for every sets $A$ and $B$ such that $A$ is recursively isomorphic to $B$, then both $A$ and $B$ are recursive. For let $\phi(x)$ be the recursive 
isomorphism from $A$ to $B$. Thus for every $x\in A$, $f(x)=y$ for some $y\in B$, and for every $y\in B$, there is one and only one number $x$ such that $f(x)=y$. So the relation
\[ \exists y(\phi(x)=y) \] is a recursive relation for $A$. Because $B$ is recursively isomoprhic to $A$ under $\phi^{-1}(x)$, it also follows that
\[ \exists y(\phi^{-1}(x)=y) \] is a recursive relation for $B$. Thus neither $A$ nor $B$ can be generative, co-productive (which implies universality) or universal, as the Bonus Question 
shows that no generative or universal sets can be recursive.


Now suppose that $A$ is productive. Hence there is some recursive function $\phi(i)$ such that, if $\omega_i$ is a subset of $A$, then $\phi(i)\in A-\omega_i$. Now let $f(x)$ be the 
recursive isomorphism from $A$ to $B$. Hence $\phi(i)\in A$ iff $f(\phi(i))\in B$. Thus if $\omega_i$ is a subset of $B$, then $f(\phi(i))\in B$ iff $\phi(i)\in A$ and thus 
$\phi(i)\in A-\omega_i$ meaning $\phi(i)\notin\omega_i$ and therefore $\phi(i)\in B-\omega_i$, thus meaning $f(\phi(i))$ is a productive function for $B$.

\section*{Bonus Question}
Consider some universal set $A$, and suppose that it was recursive. Hence $\bar{A}$ would be recursively enumerable. We have shown that every universal set is generative. 
Thus there is some recursive function $\phi(i)$ such that $\phi(i)\in A$ iff $\phi(i)\in\omega_i$. Because $\bar{A}$ is recursively enumerable, it has an index $n$. Thus 
$\phi(n)\in A$ iff $\phi(n)\in\omega_n$ iff $\phi(n)\in\bar{A}$, which is impossible. Hence there can be no recursive universal set (and no recursive generative set).
