\section*{Lemma}
We must show that, from $F_1$ and $F_2$, the following two conditions hold:\newline
(1): We need to show that $\oldneg\exists x\phi(x)$ is true iff $\oldneg\phi(a)$ is true for every parameter $a$. Suppose that $\oldneg\exists x\phi(x)$ 
is true (under some valuation $v$). Thus, by $F_2$, the sentence $\phi(a)$ is not true under $v$ for any parameter $a$. Because $\phi(a)$ is not 
true under $v$ for any parameter $a$, it follows that $\oldneg\phi(a)$ is true under $v$ for every parameter $a$ (by $B_1$). On the other hand, 
suppose that $\oldneg\phi(a)$ is true under $v$ for every parameter $a$. Thus, by $B_1$, $\phi(a)$ is false under $v$ for every parameter $a$ (by $B_1$). Thus, by $F_2$, $\exists x\phi(x)$ is not true under $v$, meaning, by $B_1$, $\oldneg\exists x\phi(x)$ is true under $v$.\newline
(2): We need to show that $\oldneg\forall x\phi(x)$ is true iff $\oldneg\phi(a)$ is true for at least one parameter $a$. On the one hand, suppose 
that $\oldneg\forall x\phi(x)$ is true under some valuation $v$. Thus $\forall x\phi(x)$ is not true under $v$ (by $B_1$), meaning, by $F_1$, 
$\phi(a)$ is not true for every parameter $a$. Thus, for the parameter $e$ for which $\phi(e)$ is not true, $\oldneg\phi(e)$ is true by $B_1$. On the 
other hand, suppose that $\oldneg\phi(a)$ is true for at least one parameter $a$, call it $e$. Thus, by $B_1$, $\phi(e)$ is false, meaning, by $F_1$, 
$\forall x\phi(x)$ is not true, and therefore, by $B_1$, $\oldneg\forall x\phi(x)$ is true.  

\section*{1}
We suppose that $v$ is a Boolean valuation such that the following two conditions hold (for all sentences $\gamma$ and $\delta$):\newline
(1) if $\gamma$ is true under $v$, then for every parameter $a$, the sentence $\gamma(a)$ is true under $v$, and\newline
(2) if $\delta$ is true under $v$, then $\delta(a)$ is true under $v$ for at least one parameter $a$.\newline
We must prove that $v$ is a first-order valuation. Thus, we must derive $F_1'$ and $F_2'$. Because we have already have (1) and (2), we only need 
to prove the converses of (1) and (2).\newline
(1): In this case, we need to prove that, if for every parameter $a$, the sentence $\gamma(a)$ is true under $v$, then $\gamma$ is true under $v$.


Case 1: In this case, $\gamma$ is of the form $\forall x\phi(x)$. So suppose that $\phi(a)$ is true under $v$ for every paramter $a$. By $B_1$, 
it follows that $\oldneg\phi(a)$ is false under $v$ for every parameter $a$, meaning, by (2), that $\oldneg\forall x\phi(x)$ is not true, and is 
therefore false (because every sentence $X$ is either assigned the value $t$ or $f$), meaning, by $B_1$, $\forall x\phi(x)$ is true.\newline


Case 2: In this case, $\gamma$ is of the form $\oldneg\exists x\phi(x)$. So suppose that $\oldneg\phi(a)$ is true for every parameter $a$, meaning, 
by $B_1$, that $\phi(a)$ is false for every parameter $a$. Thus, by (2), $\exists x\phi(x)$ is not true, and is therefore false (for the same reason 
as in Case 1), meaning, by $B_1$, that $\oldneg\exists x\phi(x)$ is true.\newline\newline
(2): In this case, we need to prove that, if $\delta(a)$ is true for at least one parameter $a$ under $v$, then $\delta$ is true under $v$.


Case 1: In this case, $\delta$ is of the form $\exists x\phi(x)$. So suppose that $\phi(a)$ is true for at least one parameter $a$, call it $e$. 
By $B_1$, $\oldneg\phi(e)$ is false, meaning, by (1), $\oldneg\exists x\phi(x)$ is not true, and is therefore false, and thus, by $B_1$, 
$\exists x\phi(x)$ is true.\newline 


Case 2: In this case, $\delta$ is of the form $\oldneg\forall x\phi(x)$. So suppose that $\oldneg\phi(a)$ is true for at least one parameter $a$, call 
it $e$. By $B_1$, $\phi(e)$ is false, meaning, by (1), $\forall x\phi(x)$ is not true, and therefore false, meaning, by $B_1$, $\oldneg\forall x\phi(x)$
is true.  

\section*{2}
We are to show that every Magic set is a truth-functional basis for propositional logic.


On the one hand, suppose that some pure sentence $X$ is valid. Thus, it is true under all first-order valuations. We must show that $X$ is a tautological consequence of some finite subset $M_0$ of $M$. That is, we must show that under every $Boolean$ valuation 
that satisfies $M_0$, $X$ is true. Well, by $M_1$, every Boolean valuation that satisfies $S$ is also a first-order valuation. 
Thus, $X$ is true under all Boolean valuations that satisfy $M$, because $X$ was assumed to be true under all first-order 
valuations, and every Boolean valuation that satisfies $M$ is also a first-order valuation. Thus, $X$ is a tautological 
consequence of $M$. By the Corollary to the Denumerable Compactness Theorem for Propositional Logic, it is also a logical 
consequence of some finite subset $M_0$ of $M$.


On the other hand, suppose that some pure sentence $X$ is a truth-functional consequence of some finite subset $M_0$ of $M$. 
Thus, $M_0\bigcup {\oldneg X}$ is not first-order satisfiable (every first-order valuation is also a Boolean valuation). 
This means 
that $\oldneg X$ is not first-order satisfiable. For, if it were, by $M_2$, $M_0\bigcup {\oldneg X}$ would also be first-order 
satisfiable. 
Thus, $X$ is valid (true under every first-order valuation). 

\section*{3}


We must show that every complete regular set is also a magic set. Recall that a complete regular set $M$ is a set such that 
for every $\gamma$, $\gamma\supset \gamma(a)\in M$ for every parameter $a$, and for every $\delta$, $\delta\supset \delta(a)\in M$ 
for at least one parameter $a$, and that every finite subset of $M$ is a regular set. Because we are showing that every complete 
regular set is a magic set, it suffices to show that $M$ satisfies the conditions $M_1,M_2$.


$M_1$: We must show that every Boolean valuation that satisfies $M$ is also a first-order valuation. To that end, it suffices to 
show that:\newline
If $\gamma$ is true, then $\gamma(a)$ is true for every parameter $a$,\newline
If $\delta$ is true, then $\delta(a)$ is true for at least one parameter $a$.\newline
(which implies a first-order valuation by Problem 1). So, suppose $\gamma$ is true. Thus, $\gamma\supset\gamma(a)\in M$ for 
every parameter $a$. Because this is a Boolean valuation, and $\gamma$ is true, $\gamma(a)$ is likewise true for $\gamma(a)$ 
for every parameter $a$ (by $B_4$). On the other hand, suppose that $\delta$ is true. 
Thus, $\delta\supset\delta(a)\in M$ for at least one
parameter $a$. Again, because this is a Boolean valuation, and $\delta$ is true, $\delta(a)$ is likewise true for at least one 
parameter $a$ (again by $B_4$). 


$M_2$: We must show that, for every finite set $S_0$ of pure sentences, and every finite subset $M_0$ of $M$, if 
$S_0$ is first-order satisfiable, so is $M_0\bigcup S_0$. So, suppose that $S_0$ is a finite set of pure sentences, and 
that it is first-order satisfiable. Now consider any finite subset $M_0$ of $M$. By the definition of a complete regular set, it 
is a regular set. Thus, it can be split into a sequence
\[ Q_1\supset Q_1(a_1),...,Q_n\supset Q_n(a_n) \] where, if $Q_i$ is a $\gamma$, $a_i$ is any parameter $a$, and if $Q_i$ 
is a $\delta$, then $a_i$ is a parameter $a$ such that $a$ does not occur in $\delta$ or in any previous $Q$'s. So, what 
we really need to show is that, if a set $S$ is first-order satisfiable, 
$S\bigcup \gamma\supset\gamma(a)$ is first-order satisfiable for every 
parameter $a$, and $S\bigcup\delta\supset\delta(a)$ is first-order satisfiable, provided $a$ does not occur in $\delta$ or 
$S$. This would let us show that \[ S_0\bigcup Q_1\supset Q_1(a_1)\bigcup ...\bigcup Q_n\supset Q_n(a_n) \] is first-order 
satisfiable, which is the same as saying $S_0\bigcup M_0$ is first-order satisfiable. There are then two cases: $Q_i$ is a 
$\gamma$, or is a $\delta$.


$\gamma$: in this case, $Q_i$ is a $\gamma$, meaning $Q_i\supset Q_i(a_i)$ is of the form $\gamma\supset \gamma(a_i)$. 
Suppose $S$ is first-order satisfiable under some interpretation $I$. Well, $\gamma\supset\gamma(a_i)$ is satsified by $every$ 
first-order valuation (which can easily be shown, if one desires), meaning $S\bigcup\gamma\supset\gamma(a_i)$ is obviously 
also first-order satisfiable.


$\delta$: in this case, $Q_i$ is a $\delta$, meaning $Q_i\supset Q_i(a_i)$ is of the form $\delta\supset\delta(a_i)$. 
Suppose $S$ is first-order satisfiable under some interpreation $I$. If $\delta$ is false under $I$, then 
$\delta\supset\delta(a_i)$ is true under $I$. If $\delta$ is true under $I$, then $S\bigcup\delta$ is satisfiable, meaning 
$S\bigcup\delta\supset\delta(a_i)$ is satisfiable by Problem 2 of Chapter 9 of the Beginners Guide[Smullyan, 2014] (because we 
assumed that $a$ does not occur in $\delta$ or any of the previous $Q_i's$, and that $S_0$ was a set of pure sentences, 
meaning $a$ of course does not occur in them). In either 
case, $S\bigcup\delta\supset\delta(a_i)$ is satsifiable.

\section*{4}
We are to find a quicker proof of the Regularity theorem, using Magic sets. It has been shown that a complete regular set exists, 
and by Problem 3, it is a Magic set. By Problem 2, it is therefore a truth-functional basis for first-order logic. So, suppose 
that $X$ is a valid pure sentence. Thus, $X$ is truth-functionally implied by some finite subset $M_0$ of $M$. By the definition 
of a complete regular set, $M_0$ is a regular set. Thus, $X$ is tautologically implied by some regular set, which is what we 
were required to prove.  

\section*{System $G_0$}

\subsection*{Correctness of $G_0$}


The Axiom of the system is obviouslly correct. For, whenever the set of formulas $U,X$ is true, $X$ is true, meaning it is obviouslly true that $at least one$ of the 
formulas $V,X$ are true for any set of formulas $V$.


$C_1$: This is obvious, as $X,Y$ are defined to both be true whenever $X\wedge Y$ is true. 


$C_2$: If whenever all elements of $U$ are true, at least one element of $V,X$ and $V,Y$ is true, on the one hand, if $V$ is the element which is true, it 
follows that at least one element ($V$) of $V,X\wedge Y$ is true. On the other hand, if $V$ is false, it would then follow that both $X,Y$ are true, therefore meaning 
$X\wedge Y$ is the element which is true. 


$C_3$: If whenever all elements of $U$ are true then at least one element of $V,X,Y$ is true, if $V$ is the element which is true, it follows that at least one element 
of ($V$) of $V,X\vee Y$ is true. On the other hand, if $V$ is false, it would then follow that either $X$ or $Y$ is true, therefore meaning at least one element of 
$V,X\vee Y$ is true.


$C_4$: We are given that at least one element of $V$ is true whenever both $U,X$ are true, or when both $U,Y$ are true. By definition of $X\vee Y$, it follows that all 
elements of $U,X\vee Y$ are true iff either $X$ or $Y$ is true, which would imply that at least one element of $V$ is true.


$C_5$: We are given that at least one element of $V,Y$ is true whenever all elements of $U,X$ are true. Thus, if all elements of $U$ are true, either $X$ is true or false. 
If it is false, at least one element $(X\supset Y)$ of $V,X\supset Y$ is true, while if it is true, it would follow by the assumptions that either $V$ or $Y$ is true. If it 
is $V$ that is true, this is the element that is true. If it is $Y$ that is true, then $X\supset Y$ is also true.


$C_6$: We are given that at least one element of $V,X$ is true whenever $U$ is true, and that at least one element of $V$ is true whenever all elements of $U,Y$ are true. 
Thus, if all elements of $U,X\supset Y$ are true, it follows that either $V,X$ are true. If it is $V$ that is true, we are done. If it is $X$ that is true, we know that $Y$ is 
also true, meaning $V$ would also be true by the assumptions.


$C_7$: We are given that at least one element of $V$ is true whenever all elements of $U,X$ are true. If $U$ is true, either $X$ is true or false: if it is true, the assumptions
prove that $V$ is also true. If it is false, then $\oldneg X$ would be true by definition.


$C_8$: We are given that when all elements of $U$ are true, at least one element of $V,X$ is true. Thus, if all elements of $U,\oldneg X$ are true, $V$ would be the true element
implied by $U$, as $X$ is false.

\subsection*{A set $S$ is unsatisfiable iff its corresponding sequent $|S|$ is a tautology}


On the one hand, suppose that a non-empty set $S$ of formulas is unsatisfiable. There are then multiple cases. In the first case, suppose that there are no formulas of the form 
$TX$. Thus, $|S|$ is of the form $\rightarrow Y_1,...,Y_k$ where every $Y_i$ is the formula part of the formula $FY_i$. We must show that at least one of $Y_1,...,Y_k$ is true. 
We are given that $FY_1,...,FY_k$ is unsatisfiable, meaning, under every interpretation $I$, there is some formula $FY_j$ that is false. Under this same interpretation $I$, 
it is obvious that $Y_j$ (removing the sign) is true, thus meaning at least one of $FY_1,...,FY_k$ is true. In the second case, suppose that the set $S$ contains no formulas 
of the form $FY$. Thus $|S|$ is of the form $X_1,...X_n\rightarrow$. We need to show that at least one of $TX_1,...,TX_n$ is false. But this is immediate, as it was 
assumed that one of $TX_1,...,TX_n$ was false. In the last case, the set $S$ contains at least one formula of the form $TX$ and at least one of the form $FY$. Thus $|S|$ is of 
the form $X_1,...,X_n\rightarrow Y_1,...,Y_k$. If every element of $X_1,...,X_n$ is true, this would mean, by the assumption that $S$ is not simultaneously 
satisfiable, that at least one of $FY_1,...,FY_k$ is false (call this element $FY_K$). As before, it can be easily seen that $Y_k$ would then be true under this same 
interpretation, therefore meaning at least one of $Y_1,...,Y_k$ is true.


On the other hand, suppose that $|S|$ is a tautology for some non-empty set of formulas $S$. There are then 3 cases:


Case 1: In this case, $S$ does not contain any formulas of the form $TX$. We know that $\rightarrow Y_1,...,Y_k$ is a tautology, meaning under every interpretation, at least 
one of $Y_1,...,Y_k$, which is the same as saying, under every interpreation, at least one of $FY_1,...,FY_k$ is false, thus meaning $S$ is unsatisfiable.


Case 2: In this case, $S$ does not contain any formulas of the form $FY$. We know that $X_1,...,X_n\rightarrow $ is a tautology, meaning, under every interpretation, 
at least one of $X_1,...,X_n$ are false, which is the same as saying at least one of $TX_1,...,TX_n$ are false, which means that $S$ is unsatisfiable.


Case 3: In this case, $S$ contains at least one formula of the form $FY$, and at least one formula of the form $TX$. Thus we know that 
$X_1,...,X_n\rightarrow Y_1,...,Y_K$ is a tautology. There are then two cases. In the first case, at least one of $X_1,...,X_n$ are false under an interpretation $I$, 
which is the same as saying at least one of $TX_1,...,TX_n$ is false under $I$, which would mean $S$ is not simultaneously true under $I$. In the other case, 
all of $X_1,...,X_n$ are true, which would mean that at least one of $Y_1,...,Y_k$ are true, which is the same as saying that at least one of 
$FY_1,...,FY_k$ is false, therefore meaning that $S$ is also not simultaneously true under this interpretation.
