\section*{Problem 1}
(a): Take $N$ to be $Vft$, as $Vftt=tft=f$, and $Vftf=fft=t$.


(b): Take $\wedge$ to be $Ff$, as $Fftt=ttf=t$, $Fftf=ftf=f$, $Ffft=tff=f$, and $Ffff=fff=f$. Smullyan gives an alternative solution, taking $\wedge$ to be $Rf$, as 
$Rfpq=pqf$ (which can easily be seen to also work).


(c): Take $\vee$ to be $Vt$, as $Vttt=ttt=t$, $Vttf=ftt=t$, $Vtft=ttf=t$, and $Vtff=ftf=f$. Smullyan gives an alternative solution, taking $\vee$ to be $Tt$, which can easily be seen to work.


(d): Take $\supset$ to $Rt$, as $Rttt=ttt=t$, $Rttf=tft=f$, $Rtft=ftt=t$, and $Rtff=fft=t$.


(e): Take $\equiv$ to be the combinator \[ W(W_2(F^{**}(R^*(R^*(B_1E\supset )\wedge )\supset ))) \]
as \[ W(W_2(F^{**}(R^*(R^*(B_1E\supset )\wedge )\supset )))pq \]
\[ =W_2(F^{**}(R^*(R^*(B_1E\supset )\wedge )\supset ))ppq \]
\[ =F^{**}(R^*(R^*(B_1E\supset )\wedge )\supset )ppqq \]
\[ =R^*(R^*(B_1E\supset )\wedge )\supset pqqp \]
\[ =R^*(B_1E\supset )\wedge pq\supset qp \]
\[ =B_1E\supset pq\wedge\supset qp \]
\[ =E(\supset pq)\wedge\supset qp \]
\[ =(\supset pq)\wedge(\supset qp) \]
That is, $\equiv pq=(\supset pq)\wedge(\supset qp)$, which is how we wished to define $\equiv$.


Smullyan provides a far simpler solution for part (e). He notes that we want $\equiv$ to be such that:
\[ \equiv pq=pq(Nq) \] which can be received by taking $\equiv$ to be the combinator $CSN$, as
\[ CSNpq=SpNq=pq(Nq) \]

\section*{Problem 2}
Let $n^+$ be an abbreviation for $n+1$. We first show that, for every $n$, $\overline{0}\ne\overline{n^+}$. Suppose that $\overline{0}=\overline{n^+}$. Then 
$I=Vf\sigma$, meaning $K=IK=V(KI)\sigma K=K(KI)\sigma=KI$, which is in contradiction to Problem 19 of Chapter 8, which proved that $Kx\ne K$ for all $x$. Next, we show that, 
if $\overline{m^+}=\overline{n^+}$, then $\overline{m}=\overline{n}$. If $\overline{m^+}=\overline{n^+}$, then $Vf\overline{m}=Vf\overline{n}$, meaning 
$\overline{m}=ff\overline{m}=Vf\overline{m}f=Vf\overline{n}f=ff\overline{n}=\overline{n}$. Lastly, we show that, for all $n$ and positive $k$, $\overline{n}\ne\overline{n+k}$. But suppose 
$\overline{n}=\overline{n+k}$. Now, by the first result of this problem, we know that $n>0$. Consider the sequence of combinators
\[ \overline{n-1},\overline{n-2},...,\overline{n-(n-1)},\overline{n-n} \] For each $\overline{n-i}$, it is true that $\overline{n-i}=\overline{(n+k)-i}$. For, because $\overline{n}=\overline{n+k}$, then 
$\overline{n-1}=\overline{(n+k)-1}$ by the second result of this problem. Then, if $\overline{n-i}=\overline{(n+k)-i}$ holds for some $i$, and there is an $i+1$th term in the sequence, 
$\overline{n-(i+1)}=\overline{(n+k)-(i+1)}$ again by the second result of the problem. Thus $\overline{0}=\overline{n-n}=\overline{(n+k)-n}$ such that $(n+k)-n$ is positive, which is in contradiction to the first result 
of this problem. Therefore $\overline{n}\ne\overline{n+k}$. Thus, if $n\ne m$, either $m<n$ or $n<m$. If the former, then the preceeding result would show that 
$\overline{m}\ne\overline{n}$, which is the same as saying $\overline{n}\ne\overline{m}$. Similarly, if $n<m$, then the preceeding result proves that $\overline{n}\ne\overline{m}$, which is the same as saying 
$\overline{m}\ne\overline{n}$.

\section*{Problem 6}
Consider any combinator $A$ and number $k$. Consider the realizable term $t(x,x_1)=Zx_1\bar{k}(A(x(Px_1)))$. By the fixed point theorem, there is a combinator $\Gamma$ such that 
$\Gamma x_1=t(\Gamma,x_1)=Zx_1\bar{k}(A(\Gamma(Px_1)))$. Thus 
\[ \Gamma\bar{0}=Z\bar{0}\bar{k}(A(\Gamma(P\bar{0})))=t\bar{k}(A(\Gamma(P\bar{0})))=\bar{k} \]
and \[ \Gamma\overline{n^+}=Z\overline{n^+}\bar{k}(A(\Gamma(P\overline{n^+}))) \]
\[ =f\bar{k}(A(\Gamma\bar{n})) \]
\[ =A(\Gamma\bar{n}) \]
Note that if $\theta$ is the combinator that realizes the term $t(x,x_1)$, then $\Gamma$ is specifically the fixed point of $\theta$.

\section*{Problem 10}
Note the importance of specifying that a relational combinator of degree $n$ must always be such that 
$A\overline{k_1}...\overline{k_n}=t$ or $A\overline{k_1}...\overline{k_n}=f$. If this wasn't specified, it could be that it neither equaled $t$ nor $f$. Now suppose we had such a relational 
combinator computing some relation $R$. Then if $R(k_1,...,k_n)$ holds, $A\overline{k_1}...\overline{k_n}=t$, and if it doesn't hold, then 
$A\overline{k_1}...\overline{k_n}=f$. But the contrapositives of those two statements show that, if $A\overline{k_1}...\overline{k_2}$ does not equal either $t$ or $f$, 
$R(k_1,...,k_n)$ both holds and does not hold at the same time, a contradiction. Thus the requirenment that $A\overline{k_1}...\overline{k_n}$ is always either equal to $t$ or $f$ is a necessary one.


Consider the realizable term: \[ t(x,x_1x_2)=\wedge (N(Z\overline{x_1}))(\vee (Z\overline{x_2})(x(P\overline{x_1})(P\overline{x_2}))) \]
By the fixed point theorem, there is some $\Gamma$ such that:
\[ \Gamma\bar{x}\bar{y}=\wedge (N(Z\bar{x}))(\vee (Z\bar{y})(\Gamma(P\bar{x})(P\bar{y}))) \]
We can prove that this works by induction on $x$. The base case is when $x=0$. Thus, because $N(Z\bar{0})=f$, 
\[ \Gamma\bar{0}\bar{y}=\wedge (N(Z\bar{0}))(\vee (Z\bar{y})(\Gamma(P\bar{0})(P\bar{y})))=f \]
Now suppose the hypothesis holds for some $x$, that is, for all $y$, if $x>y$, then $\Gamma xy=t$, and if $x\le y$, then $\Gamma xy=f$. On the one hand, suppose that 
$x>y$. Then either $y=0$, meaning $Z\bar{y}=t$, or $x-1>y-1$, in which case $\Gamma(P\bar{x})(P\bar{y})=t$ by the assumption. Thus, either of 
$Z\bar{y}=t$ or $\Gamma(P\bar{x})(P\bar{y})=t$, and $N(Z\bar{x})=t$ as well, as $x>0$. Thus
\[ \vee (Z\bar{y})(\Gamma(P\bar{x})(P\bar{y}))=t\textrm{ and }N(Z\bar{x})=t \] meaning
\[ \Gamma\bar{x}\bar{y}=\wedge (N(Z\bar{x}))(\vee (Z\bar{y})(\Gamma(P\bar{x})(P\bar{y})))=t \] On the other hand, suppose that $x\le y$. Thus $y\ne 0$ (and we are supposing that $x>0$, as the 
case where $x=0$ was proven above) and $x-1\le y-1$. Thus, by the assumption, \[ \vee(Z\bar{y})(\Gamma(P\bar{x})(P\bar{y}))=f \] 
meaning
\[ \Gamma\bar{x}\bar{y}=\wedge (N(Z\bar{x}))(\vee (Z\bar{y})(\Gamma(P\bar{x})(P\bar{y})))=f \] 


Smullyan provides an alternative solution which does not involve the logical combinators. By the fixed point theorem, there is some $\Gamma$ such that 
$\Gamma xy=Zxf(Zyt(\Gamma(Px)(Py)))$. $\Gamma$ can be seen to satisfy the conditions of the problem.

\[ B(A_3^*(DA)A_2)A_1\bar{x}\bar{y}=A_3^*(DA)A_2(A_1\bar{x})\bar{y} \]
\[ =DA(A_1\bar{x})A_2\bar{y}=A(A_1\bar{x})(A_2\bar{y}) \]


For part (c), Smullyan provides two swifter proofs. Let $S(x,y)$ be the relation $R(f(x),y)$. By part (a), $BAA_1$ computes it. Hence, by part (b), 
$S(x,g(y))$, that is, $R(f(x),g(y))$, is computed by $BCD(BAA_1)A_2$. Alternatively, let $\delta(x,y)$ be the relation $R(x,g(y))$. By part (b), $BCDAA_2$ computes it.
Hence, by part (a), $\delta(f(x),y)$, that is, $R(f(x),g(y))$, is computed by $B(BCDAA_2)A_1$.

\section*{Problem 24}
Suppose that $A$ is representable by $\Gamma$. Now let $f$ be the function such that $f(x)=x*52$. This is realizable by the combinator $\gamma$ realizing the term 
$t(x)=\Circled{*}\bar{x}\overline{52}$. Then, by Problem 23, $f^{-1}(A)$ is representable. That is, the set of all $n$ such that $(n*52)\in A$ is representable.

\section*{Problem 25}
For this problem, note that if $n$ is the Gödel number of $X$, then $n*52$ is the Gödel number of $X=t$. 
Consider any representable set $A$. By Problem 24, the set of all $n$ such that $(n*52)\in A$ is representable, say by $\Gamma_1$. By Problem 20, there is some term $X$ 
(let $n$ be its Gödel number)
such that $\Gamma_1\bigl \lceil X\bigr \rceil=X$ holds. Consider the sentence $X=t$. We show that this is a Gödel sentence for $A$. On the one hand, suppose that $X=t$ is true. Then
$\Gamma_1\bigl \lceil X\bigr \rceil =t$ also holds, meaning $n*52\in A$, that is, the Gödel number of $X=t$ is in $A$. On the other hand, suppose that $n*52\in A$. Then 
$X=\Gamma_1\bigl \lceil X\bigr \rceil =t$, that is, $X=t$ holds. Hence $X=t$ is a Gödel sentence for $A$.  

\section*{Problem 26}
Suppose that $\mathcal{T}_0$ was computable. By Problem 22 (2), it follows that $\overline{\mathcal{T}_0}$ is representable. By Problem 25, it would follow that there is some Gödel sentence $X$ for 
$\overline{\mathcal{T}_0}$. That is, $X$ is true iff the Gödel number of $X$ is in $\overline{\mathcal{T}_0}$ iff $X$ is not true. 
Thus $X$ is true iff it is not true, which is a contradiction. Hence $\overline{\mathcal{T}_0}$ cannot be 
representable, and, consequently, $\mathcal{T}_0$ cannot be computable.
