\section*{Problem 1}
(a): Take $N$ to be $Vft$, as $Vftt=tft=f$, and $Vftf=fft=t$.


(b): Take $\wedge$ to be $Ff$, as $Fftt=ttf=t$, $Fftf=ftf=f$, $Ffft=tff=f$, and $Ffff=fff=f$. Smullyan gives an alternative solution, taking $\wedge$ to be $Rf$, as 
$Rfpq=pqf$ (which can easily be seen to also work).


(c): Take $\vee$ to be $Vt$, as $Vttt=ttt=t$, $Vttf=ftt=t$, $Vtft=ttf=t$, and $Vtff=ftf=f$. Smullyan gives an alternative solution, taking $\vee$ to be $Tt$, which can easily be seen to work.


(d): Take $\supset$ to $Rt$, as $Rttt=ttt=t$, $Rttf=tft=f$, $Rtft=ftt=t$, and $Rtff=fft=t$.


(e): Take $\equiv$ to be the combinator \[ W(W_2(F^{**}(R^*(R^*(B_1E\supset )\wedge )\supset ))) \]
as \[ W(W_2(F^{**}(R^*(R^*(B_1E\supset )\wedge )\supset )))pq \]
\[ =W_2(F^{**}(R^*(R^*(B_1E\supset )\wedge )\supset ))ppq \]
\[ =F^{**}(R^*(R^*(B_1E\supset )\wedge )\supset )ppqq \]
\[ =R^*(R^*(B_1E\supset )\wedge )\supset pqqp \]
\[ =R^*(B_1E\supset )\wedge pq\supset qp \]
\[ =B_1E\supset pq\wedge\supset qp \]
\[ =E(\supset pq)\wedge\supset qp \]
\[ =(\supset pq)\wedge(\supset qp) \]
That is, $\equiv pq=(\supset pq)\wedge(\supset qp)$, which is how we wished to define $\equiv$.


Smullyan provides a far simpler solution for part (e). He notes that we want $\equiv$ to be such that:
\[ \equiv pq=pq(Nq) \] which can be received by taking $\equiv$ to be the combinator $CSN$, as
\[ CSNpq=SpNq=pq(Nq) \]

\section*{Problem 2}
Let $n^+$ be an abbreviation for $n+1$. We first show that, for every $n$, $\overline{0}\ne\overline{n^+}$. Suppose that $\overline{0}=\overline{n^+}$. Then 
$I=Vf\sigma$, meaning $K=IK=V(KI)\sigma K=K(KI)\sigma=KI$, which is in contradiction to Problem 19 of Chapter 8, which proved that $Kx\ne K$ for all $x$. Next, we show that, 
if $\overline{m^+}=\overline{n^+}$, then $\overline{m}=\overline{n}$. If $\overline{m^+}=\overline{n^+}$, then $Vf\overline{m}=Vf\overline{n}$, meaning 
$\overline{m}=ff\overline{m}=Vf\overline{m}f=Vf\overline{n}f=ff\overline{n}=\overline{n}$. Lastly, we show that, for all $n$ and positive $k$, $\overline{n}\ne\overline{n+k}$. But suppose 
$\overline{n}=\overline{n+k}$. Now, by the first result of this problem, we know that $n>0$. Consider the sequence of combinators
\[ \overline{n-1},\overline{n-2},...,\overline{n-(n-1)},\overline{n-n} \] For each $\overline{n-i}$, it is true that $\overline{n-i}=\overline{(n+k)-i}$. For, because $\overline{n}=\overline{n+k}$, then 
$\overline{n-1}=\overline{(n+k)-1}$ by the second result of this problem. Then, if $\overline{n-i}=\overline{(n+k)-i}$ holds for some $i$, and there is an $i+1$th term in the sequence, 
$\overline{n-(i+1)}=\overline{(n+k)-(i+1)}$ again by the second result of the problem. Thus $\overline{0}=\overline{n-n}=\overline{(n+k)-n}$ such that $(n+k)-n$ is positive, which is in contradiction to the first result 
of this problem. Therefore $\overline{n}\ne\overline{n+k}$. Thus, if $n\ne m$, either $m<n$ or $n<m$. If the former, then the preceeding result would show that 
$\overline{m}\ne\overline{n}$, which is the same as saying $\overline{n}\ne\overline{m}$. Similarly, if $n<m$, then the preceeding result proves that $\overline{n}\ne\overline{m}$, which is the same as saying 
$\overline{m}\ne\overline{n}$.

\section*{Problem 6}
Consider any combinator $A$ and number $k$. Consider the realizable term $t(x,x_1)=Zx_1\bar{k}(A(x(Px_1)))$. By the fixed point theorem, there is a combinator $\Gamma$ such that 
$\Gamma x_1=t(\Gamma,x_1)=Zx_1\bar{k}(A(\Gamma(Px_1)))$. Thus 
\[ \Gamma\bar{0}=Z\bar{0}\bar{k}(A(\Gamma(P\bar{0})))=t\bar{k}(A(\Gamma(P\bar{0})))=\bar{k} \]
and \[ \Gamma\overline{n^+}=Z\overline{n^+}\bar{k}(A(\Gamma(P\overline{n^+}))) \]
\[ =f\bar{k}(A(\Gamma\bar{n})) \]
\[ =A(\Gamma\bar{n}) \]

\section*{Problem 7}
(a): We can use a similar concept as in Problem 6. Now, however, we want a combinator $\Gamma$ such that for any combinator $A$: 
\newline $C_1$: $\Gamma \bar{0}\bar{k}=\bar{k}$.\newline $C_2$: $\Gamma \overline{n^+}\bar{k}=A(\Gamma\bar{n}\bar{k})$.\newline
We can find this combinator by, in Problem 6, instead letting $t(x,x_1,x_2)$ be the term $Zx_1x_2(A(x(Px_1)x_2))$, and then taking $\Gamma$ to be the 
$\Gamma$ from the fixed point theorem such that $\Gamma x_1x_2=t(\Gamma,x_1,x_2)$. Now, let $A$ be the combinator $V(KI)$. We then take $\bigoplus$ to be
the $\Gamma$ such that $\Gamma x_1x_2=Zx_1x_2(V(KI)(\Gamma (Px_1)x_2))$, that is, $\Gamma \bar{0}\bar{k}=\bar{k}$ and $\Gamma \bar{m^+}\bar{k}=V(KI)(\Gamma\bar{m}\bar{k})$. 
Then, we can show that $\Gamma\overline{m}{n}=\overline{m^++n}$ by induction. Now, the base case when $m=0$ holds, as $\Gamma \bar{0}\bar{n}=\bar{n}=\overline{0+n}$. 
Then suppose the hypothesis holds for some $m$, that is, 
$\Gamma\overline{m}\overline{n}=\overline{m+n}$. Then \[ \Gamma\overline{m^+}{n}=V(KI)(\Gamma\bar{m}\bar{n})=V(KI)\overline{m+n}=\overline{(m+n)+1} \] Thus, in all cases, 
$\Gamma\bar{m}\bar{n}=\overline{m+n}$. 


(b): This can be solved again by making a variation on Problem 6. Consider the realizable term $t(x,x_1,x_2)=Zx_2\bar{0}(\bigoplus x_1(xx_1(Px_2)))$
(It can easily be seen by similar reasoning as below that we could also take $t(x,x_1,x_2)=Zx_1\bar{0}(\bigoplus x_1(xx_1(Px_2)))$ to be the realizable term, only then doing induction on $m$, not $n$). 
By the fixed point theorem, there is some 
$\Gamma$ such that $\Gamma x_1x_2=Zx_2\bar{0}(\bigoplus x_1(\Gamma x_1(Px_2)))$. 
Note that \[ \Gamma\bar{m}\bar{0}=Z\bar{0}\bar{0}(\bigoplus \bar{m}(\Gamma \bar{m}(P\bar{0})))=\bar{0} \] and 
\[ \Gamma\bar{m}\overline{n^+}=Z\overline{n^+}\bar{0}(\bigoplus\bar{m}(\Gamma\bar{m}(P\overline{n^+}))) \] \[ =\bigoplus\bar{m}(\Gamma\bar{m}\bar{n}) \]
This is the combinator we take for $\bigotimes$. Now, we can show that this combinator works by induction on 
$n$. The base case is when $n=0$. Then, as we have seen, $\Gamma\bar{m}\bar{n}=\Gamma\bar{m}\bar{0}=\bar{0}=\overline{n\times 0}$. Now suppose the hypothesis holds for some $n$, that is, 
$\Gamma\bar{m}\bar{n}=\overline{m\times n}$. Then \[ \Gamma\bar{m}\overline{n^+}=\bigoplus\bar{m}(\Gamma\bar{m}\bar{n})=\bigoplus\bar{m}\overline{m\times n} \] 
\[ =\overline{m+(m\times n)}=\overline{m\times (n+1)} \]


(c): Note that this answer assumes $m>0$. We can yet again make a variation of Problem 6. Consider the term $t(x,x_1,x_2)=Zx_2\bar{1}(\bigotimes x_1(xx_1(Px_2)))$. By the fixed point theorem, there is 
some $\Gamma$ such that $\Gamma x_1x_2=Zx_2\bar{1}(\bigoplus x_1(\Gamma x_1(Px_2)))$. Note that $\Gamma\bar{m}\bar{0}=\bar{1}$, and 
$\Gamma\bar{m}\overline{n^+}=\bigotimes x_1(\Gamma \bar{m}\bar{n})$. This is the combinator we take for $\Circled{E}$ (I could not find the exact latex control sequence being used for the 
exponential combinator). 
Now we can prove by induction that $\Gamma\bar{m}\bar{n}=\overline{m^n}$. The base case, when $n=0$, was noted above.
Now suppose the hypothesis holds for some $n$. Then \[ \Gamma\bar{m}\overline{n^+}=\bigotimes\bar{m}(\Gamma\bar{m}\bar{n})=\bigotimes\bar{m}\overline{m^n} \]
\[ =\overline{m\times m^n}=\overline{m^{n^+}} \]
