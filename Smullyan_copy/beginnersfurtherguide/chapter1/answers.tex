\section*{3}
We assume that $S$ is consistent, and $S\vdash X$. We must show that $S,X$ is consistent. Because $S$ is consistent, this means that $S\vdash Z$ is not the 
for at least one formula $Z$. Now suppose that $S,X\vdash Z$ is the case. By $C_3$, this would mean that $S\vdash Z$, which is a contradiction. This means 
that $S,X\vdash Z$ is not the case, meaning $S,X$ does not yield at least one formula $Z$, thus proving that it is consistent.

\section*{5}

$X\in M$ and $X\vdash Y$ and that $M$ is maximally consistent. Suppose that $Y\notin M$. By $C_1$, $M\vdash X$, meaning, by Problem 4(a),

(b): We assume that M is maximally consistent, $X\in M$ and $Y\in M$ and $X,Y\vdash Z$. This means that $M\vdash X$ and $M\vdash Y$ by $C_1$. By

meaning $Z\in M$. 

\section*{Exericse 2}
We need to show that $S\vDash X$ is a Boolean consequence relation, that is, that it satisfies $C_1-C_8$.\newline
$C_1$: Suppose $X\in S$. Because $X\in S$, $X$ is obviously true under all interpretations that satisfy $S$, meaning $S\vDash X$.\newline
$C_2$: Suppose $S_1\vDash X$ and $S_1\subseteq S_2$. This means that $X$ is true under all interpretations that satisfy $S_1$. Well, because 
$S_1\subseteq S_2$, all interpretations that satisfy $S_2$ also satisfy $S_1$, meaning $X$ is also true under all interpreations that satisfy 
$S_2$, thus proving $S_2\vDash X$.\newline
$C_3$: Suppose $S\vDash X$ and $S,X\vDash Y$. This means that $Y$ is true under all interpretations that satisfy $S$ and satisfy $X$. But 
$X$ is true under all interpreations that satisfy $S$, meaning, under all interpreations that satisfy $S$, $S,X$ is also satisfied. Thus, 
$S\vDash Y$.\newline
$C_4$: Suppose $S\vDash X$. Recall the Corollary to the Compactness Theorem for Propositional Logic that states that 
if $X$ is a logical consequence of $S$ then $X$ is a logical consequence of some finite subset of $S$ (logical consequence there means the same 
thing as tautological consequence here), which single-handedly proves $C_4$.\newline
$C_5$: (a-b): By definition of an $\alpha$ formula, it is true iff $\alpha_1,\alpha_2$ are true, meaning that $\alpha\vDash\alpha_1,\alpha\vDash\alpha_2$.
\newline
$C_6$: Again, by definition of an $\alpha$ formula, it is true iff $\alpha_1,\alpha_2$ are true, meaning $\alpha_1,\alpha_2\vDash\alpha$.\newline
$C_7$: By definition, $X,\oldneg X$ is unsatisfiable. Hence, every formula $Y$ is vacuously true under all interpreations that satisfy $X,\oldneg X$ 
(because there aren't any). \newline
$C_8$: Suppose that $S,\oldneg X\vDash X$. This means that, if $\oldneg X$ was true under any interpretations that satisfied $S$, $X$ would also be 
true, yielding a contradiction. Hence, $S\bigcup\oldneg X$ is unsatisfiable, meaning $X$ is true under all interpretations that satisfy $S$.

\section*{6}
We suppose that $\vdash$ is tautologically complete. This means that, whenever $X$ is a tautological consequence of $\oldemptyset$. Because we are considering 
the empty set, this means that all elements of the empty set of vacuously satisfied by every interpretation. Because $X$ is assumed to be a tautology, 
it to is satisfied by every interpretation, meaning $X$ is a tautological consequence of $\oldemptyset$, and thus, because $\vdash$ is tautologically complete, 
$\oldemptyset\vdash X$.

\section*{7}
We must prove that if $\vdash$ is a Boolean consequence relation and $M$ is maximally consistent with respect to $\vdash$, then $M$ is a Boolean truth 
set. Recall that because $\vdash$ is a Boolean consequence realtion, it satisfies $C_1-C_8$. Also, because $M$ is maximally consistent with respect to 
$\vdash$, it is not a proper subset of any consistent set with respect to $\vdash$ such that this set has an element not in $M$. We need to show that 
$M$ is a Boolean truth set, which, by Problem 1, is the same as showing that it satisfies conditions (1) and (2) of that problem. As for condition (1), 
we need to show that $\alpha\in S$ iff $a_1\in S$ and $a_2\in S$. On the one hand, assume that $\alpha\in M$. By $C_1$, $M\vdash\alpha$. By $C_5$, 
$\alpha\vdash\alpha_1$ and $\alpha\vdash\alpha_2$. Hence, by two applications of Problem 5(a), we can conclude that $\alpha_1\in M$ and $\alpha_2\in M$. 
On the other hand, assume that $\alpha_1\in M$ and $\alpha_2\in M$. Again, by $C_1$, $M\vdash\alpha_1,M\vdash\alpha_2$. 
By $C_6$, $\alpha_1,\alpha_2\vdash\alpha$. 
Then, by Problem 5(b), we can conclude that $\alpha\in M$.\newline
Now, we need to show that $M$ satisfies condition (2) of Problem 1. This condition states that either $X\in S$ or $(\oldneg X)\in S$, but not both. 
Suppose both $X$ and $\oldneg X$ were in $M$. By $C_7$, $X,\oldneg X\vdash Y$. Because $M$ is maximally consistent, it is consistent (with repsect to 
$\vdash$), meaning $M\nvdash Z$ for some formula $Z$. However, by $C_7$, $X,\oldneg X\vdash Z$, meaning, if $X,\oldneg X\in M$, then 
$M\vdash Z$ by $C_2$, which is a contradiction.\newline
Next, we need to show that one and only one of $X,\oldneg X$ are in $M$. First, assume that $\oldneg X\notin M$. We need to show that $X\in M$. 
Because $M$ is maximally consistent, $M,\oldneg X$ must be inconsistent (because $\oldneg X\notin M$). Hence, $M,\oldneg X\vdash Y$ holds for 
every $Y$, and in particular, $M,\oldneg X\vdash X$ holds, meaning, by $C_8$, $M\vdash X$ holds. By Problem 5(a), substituting $M$ for $X$, 
it follows that $X\in M$. The contrapositive of this statement is if $X\notin M$ then $\oldneg X\in M$, which completes the proof.\newline
$Alternatively$: To show that $M\vdash X$ means $X\in M$, one can also use $C_3$. In particular, recall that $M\nvdash Z$ for the $Z$ defined above. 
Then, if $X\notin M$, this means $M,X$ must be inconsistent (because $M$ is maximally consistent), and thus $M,X\vdash Z$. By $C_3$, it would follow 
that $M\vdash Z$, which is a contradiction, meaning $X\in M$. 

We can also prove the case where $X\notin M$ directly. For suppose $X\notin M$. Because we have shown that $M$ satisfies condition (1) of Problem 1, 
it follows that $\oldneg\oldneg X\notin M$. Hence, because $M$ is maximally consistent, $M,\oldneg\oldneg X$ is inconsistent, meaning 
$M,\oldneg\oldneg X\vdash \oldneg X$, and thus $M\vdash \oldneg X$ by $C_8$. Then, by Problem 5(a), $\oldneg X\in M$.

\section*{8}
We are to show that for a Boolean consequence relation $\vdash$, consistency is compact. That is, we must show that a $S$ is consistent with 
respect to $\vdash$ iff all finite subsets of $S$ are also consistent with respect to $\vdash$.\newline
Case 1: $S$ is consistent:\newline
In this case, we must show that all finite subsets $F$ of $S$. Suppose that some finite subset $F_1$ of $S$ is inconsistent, that is, 
$F_1\vdash Z$ holds for every formula $Z$. Because $S$ is consistent, there is some $Z_1$ such that $S\nvdash Z_1$. Because $\vdash$ is a Boolean 
consequence relation, \[ S,F_1\vdash Z_1 \] holds by $C_2$. Because $F_1\in S$, $S\vdash F_1$ by $C_1$, meaning $S\vdash Z_1$ holds by $C_3$, which 
is a contradiction, as we assumed $S\nvdash Z_1$, thus completing the proof in this case.\newline
Case 2: All finite subsets $F$ of $S$ are consistent:\newline
In this case, we must show that $S$ is also consistent. Suppose $S$ was inconsistent, that is, $S\vdash Z$ holds for every $Z$. Because every finite 
subset $F$ of $S$ is consistent, there is some formula $Z$ for every $F$ such that $F\nvdash Z$. Because $S$ is inconsistent, $S\vdash X$ and 
$S\vdash \oldneg X$ for every formula $X$. By Problem 2, substituting $X,\oldneg X$ in for $Z$, it follows that $S\vdash X,\oldneg X$, meaning, 
by $C_4$, $F_1\vdash X,\oldneg X$ for some finite subset $F_1$ of $S$. By $C_7$ and $C_3$, it follows that $F_1\vdash Z$ for the $Z$ which 
we assumed $F_1\nvdash Z$ (because $F_1$ is consistent), which yields a contradiction.
$Alternatively$: Picking up from the above, we know that $S\vdash X$ and $S\vdash \oldneg X$ because $S$ is inconsistent. By $C_4$, $F_1\vdash X$ 
and $F_2\vdash\oldneg X$ for some finite subsets $F_1,F_2$ of $S$. Now consider $F=F_1\bigcup F_2$. $F\in S$, as, if $X\in S$ and $Y\in S$, then 
$X,Y\in S$. By $C_1$, $F\vdash F_1$ and $F\vdash F_2$, and therefore $F\vdash X$ and $F\vdash\oldneg X$, meaning, by problem 2, substituting 
$X,\oldneg X$ in for $Z$, we have $F\vdash X,\oldneg X$, which proves $F\vdash Z$ for every $Z$ (by $C_7$), thus yielding a contradiction (as we 
assumed all finite subsets of $S$ were consistent).   

\section*{9}
We are to prove Theorem 1, that is, every Boolean consequence relation is tautologically complete. That is, we must show that, for every set $S$ 
and formula $X$, whenever $X$ is a tautological consequence of $S$, then $S\vdash X$. 
Recall that every Boolean truth set has been shown to be satisfiable, thus meaning $M$ is satisfiable. Because $M$ is satisfiable, so is every 
subset of $M$, that is, every consistent set. Thus, every consistent set is satisfiable, meaning if a set is unsatisfiable, it is inconsistent. Now, 
because $X$ is a tautological consequence of $S$, $S,\oldneg X$ is unsatisfiable, meaning this same set is also inconsistent, meaning 
$S,\oldneg X\vdash X$ holds, and therefore, by $C_8$, $S\vdash X$ holds, completing the proof.

(d): Suppose $X\supset (Y\supset Z)$ is provable. We are to show that $X,Y\vdash Z$. Again, by $C_2$, $X,Y\vdash X\supset (Y\supset Z)$. 
By $C_1$, $X,Y\vdash X$. Thus, $X,Y\vdash X$ and $X,Y\vdash X\supset (Y\supset Z)$, meaning, because $X,X\supset (Y\supset Z)\vdash Y\supset Z$, 
$X,Y\vdash Y\supset Z$ by Problem 2. Then, because $\vdash$ is faithfull to modus ponenes, $Y,Y\supset Z\vdash Z$. By $C_1$, 
$X,Y\vdash Y$, meaning, by Problem 2, $X,Y\vdash Z$.    

\section*{12}
We are to show that $\vdash$ is a consequence relation, where $\vdash$ means that $X$ is deducible from $S$. Thus, we need to show that $\vdash$ 
satisfies $C_1-C_4$.\newline
$C_1$: If $X\in S$, then $X$ is deducible from $S$, as a deduction was defined such that every term $X_i$ could be a member of $S$, meaning 
we could have, for example, just the deduction $X$.\newline
$C_2$: We suppose $S_1\vdash X$, and that $S_1\subseteq S_2$. We need to show that $S_2\vdash X$, that is $X$ is deducible from $S_2$. This is obvious
as, because $X$ is deducible from $S_1$, we can use this same exact deduction to show that $X$ is deducible from $S_2$, as every term $X_i$ that is 
a member of $S_1$ is also a member of $S_2$.\newline
$C_3$: We need to show that if $S\vdash X$ and $S,X\vdash Y$, then $S\vdash Y$. Suppose we have the sequence $X_1,...,X_n$ deducing $X$ from $S$, 
and the deduction $Y_1,...,Y_k$ deducing $Y$ from $S,X$. Thus, the deduction $X_1,...,X_n,Y_1,...,Y_k$ deduces $Y$ from $S$ (because $X$ is a formula).
\newline
$C_4$: We need to show that if $S\vdash X$, then $F\vdash X$ for some finite subset of $X$. Because $X_1,...,X_n$ is a finite sequence, 
we take $F$ to be the set $Y_1\bigcup ...\bigcup Y_k$, the set of the $k$ formulae being subsets of $S$ 
used in the deduction of $X$ from $S$. $F$ is obviously a finite 
subset of $S$, meaning, because $F\vdash X$, the proof is complete.
